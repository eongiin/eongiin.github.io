## ✏️ JavaScript

### 변수
- 변수(Variable)는 값(value)을 저장(할당)하고 그 저장된 값을 참조하기 위해 사용한다  
- 변수는 메모리 상의 주소를 기억하는 저장소다  
즉, 변수란 메모리 주소(Memory address)에 접근하기 위해 사람이 이해할 수 있는 언어로 지정한 식별자(identifier)이다
- 문자 _ $ 로 시작 이후에 숫자 가능
- 대소문자 구분, 유니코드 사용 

<b>var</b>  
- 변수를 선언. 추가로 동시에 값을 초기화

<b>let</b>  
- 블록 범위(scope) 지역 변수를 선언. 추가로 동시에 값을 초기화

<b>const</b>  
- 블록 범위 읽기 전용 상수를 선언

**변수 할당**  
- 지정된 초기값 없이 var 혹은 let 문을 사용해서 선언된 변수는 **undefined** 값을 갖는다
- 선언되지 않은 변수에 접근을 시도하는 경우 **ReferenceError** 예외 발생

```javascript
var a;
console.log("a 값은 " + a); // "a 값은 undefined"로 로그가 남음.

console.log('b 값은 ' + b); // b 값은 undefined
var b;

console.log("c 값은 " + c); // ReferenceError 예외 던짐

let x;
console.log('x 값은 ' + x); // x 값은 undefined

console.log('y 값은 ' + y); // ReferenceError 예외 던짐
let y;
```

- 자바스크립트는 C나 Java와는 다르게 변수를 선언할 때 데이터 타입을 미리 지정하지 않는다  
- 변수에 할당된 값의 타입에 의해 동적으로 변수의 타입이 결정된다  -> 동적 타이핑

**변수 호이스팅**

- 예외를 받지 않고도, 나중에 선언된 변수를 참조할 수 있다
- "끌어올려지거"나 함수나 문의 최상단으로 올려지는 것
- 끌어올려진 변수는 undefined 값 반환  
심지어 이 변수를 사용 혹은 참조한 후에 선언 및 초기화 하더라도 여전히 undefined 반환

```javascript
/**
 * Example 1
 */
console.log(x === undefined); // logs "true"
var x = 3;

/**
 * Example 2
 */
// undefined 값을 반환함.
var myvar = "my value";

(function() {
  console.log(myvar); // undefined
  var myvar = "local value";
})();
```
- 호이스팅 때문에, 함수 내의 모든 var 문은 가능한 함수 상단 근처에 두는 것이 좋다
- let (const)는 변수를 블록의 상단으로 올리지 않는다  
변수가 선언되기 전에 블록 안에서 변수를 참조하게 되면 ReferenceError를 발생시킨다

**함수 호이스팅**

- 함수에서는 단지 함수 선언만 상단으로 끌어올려진다  
- 함수 표현식은 그렇지 않다

```javascript
/* 함수 선언 */

foo(); // "bar"
function foo() {
  console.log('bar');
}

/* 함수 표현식 */

baz(); // TypeError: baz is not a function
var baz = function() {
  console.log('bar2');
};
```

### 상수
- const 키워드로 읽기 전용 상수를 만들 수 있다
- 상수 식별자의 구문은 변수 식별자와 같다

```javascript
const PI=3.14;
```
- 상수는 스크립트가 실행 중인 동안 대입을 통해 값을 바꾸거나 재선언될 수 없다. 값으로 초기화해야 한다
- 상수에 대한 범위 규칙은 let 블록 범위 변수와 동일하다
- 만약 const 키워드가 생략된 경우에는, 식별자는 변수를 나타내는 것으로 간주된다
- 상수에 할당된 객체의 속성과 배열의 내용은 보호되지 않아서 다음은 문제 없이 실행된다

```javascript
const MY_OBJECT = {'key': 'value'};
MY_OBJECT.key = 'otherValue';

const MY_ARRAY = ['HTML','CSS'];
MY_ARRAY.push('JAVASCRIPT');
console.log(MY_ARRAY); //logs ['HTML','CSS','JAVASCRIPT'];
```

### 값
- 데이터 타입(Data Type) : 프로그래밍 언어에서 사용할 수 있는 값의 종류
- 변수(Variable) : 값이 저장된 메모리 공간의 주소를 가리키는 식별자(identifier)
- 리터럴(literal) : 소스코드 안에서 직접 만들어 낸 상수 값 자체를 말하며 값을 구성하는 최소 단위

```javascript
var str="Hello World';
```
str이라는 이름의 **변수**를 선언하고 문자열 **리터럴** 'Hello World'를 **값**으로 할당한 모습  
이때 문자열 리터럴 'Hello World'는 문자열 타입의 값이다  

**값**은 프로그램에 의해 조작될 수 있는 대상을 말한다  
값은 다양한 방법으로 생성할 수 있다  
가장 간단한 방법은 리터럴 표기법(literal notation)을 사용하는 것이다  

**리터럴**
```javascript
1234 // 숫자 리터럴
'Hello' // 문자열 리터럴
true // 불리언 리터럴
null // null 리터럴
undefined // undefined 리터럴
{name:'eongiin', age:100} // 객체 리터럴
[1,2,3] // 배열 리터럴
/ab+c/ //정규표현식 리터럴
function(){} //함수 리터럴
```



**undefined vs null**
- undefined
  - 변수가 선언되고 아무것도 할당하지 않은 상태
  - 수치 문맥에서는 NaN으로, boolean 문맥에서는 false로 동작한다
- null
  - 어떤 값이 의도적으로 비어있음을 표현
  - 변수가 아무런 객체를 가리키지 않음을 표현
  - 수치 문맥에서는 0으로, boolean 문맥에서는 false로 동작한다

```javascript
typeof null          // "object" (하위호환 유지를 위해 "null"이 아님)
typeof undefined     // "undefined"
null === undefined   // false
null  == undefined   // true
null === null        // true
null == null         // true
!null                // true
isNaN(1 + null)      // false
isNaN(1 + undefined) // true

```

**Primitive vs Reference**

<b>원시 값 (Primitive)</b>

- null, undefined, boolean, number, string, symbol

<b>참조 값 (Reference)</b>

- Object

변수를 선언하면 JavaScript 엔진은 변수에 대한 메모리를 스택과 힙의 두 가지 메모리 위치에 할당한다.  
정적 데이터는 변하지 않는 크기를 가지기 때문에 자바스크립트 엔진은 고정된 메모리 공간을 정적 데이터에 할당하여 스택에 저장한다

```javascript
let name = 'John';
let age = 25;

let person = {
  name: 'John',
  age: 25,
};
```

- 한 변수의 원시 값을 다른 변수에 복사하면 별도의 값 복사가 생성된다  
한 변수의 값을 변경해도 다른 변수에 영향을 미치지 않는다는 뜻이다
- 한 변수의 참조 값을 다른 변수에 복사하면 두 변수가 동일한 객체를 참조하도록 참조가 생성된다  
이것은 한 변수를 통해 객체를 변경하는 것이 다른 변수에 반영된다는 것을 의미한다


**타입 변환**
- <b>명시적 타입 변환(Explicit coercion) 또는 타입 캐스팅 (Type casting)</b>
  - 개발자에 의해 의도적으로 값의 타입을 변환하는 것
- <b>암묵적 타입 변환 (Implicit coercion) 또는 타입 강제 변환(Type coercion)</b>
  - 개발자의 의도와는 상관없이 자바스크립트 엔진에 의해 암묵적으로 타입이 자동 변환되는 것


명시적 타입 변환도 마찬가지지만, 암묵적 타입 변환이 기존 값(위 예제의 경우, 변수 x의 값)을 직접 변경하는 것은 아니다  
변수 값이 <b>원시 타입</b>의 값인 경우, <b>변수 값을 변경하려면 재할당을 통해 새로운 메모리 공간을 확보하고 그 곳에 원시 값을 저장한 후 변수명이 재할당된 원시 값이 저장된 메모리 공간의 주소를 기억하도록 해야 한다</b>

암묵적 타입 변환은 변수 값을 재할당해서 변경하는 것이 아니라 <b>자바스크립트 엔진이 표현식을 에러없이 평가하기 위해 기존 값을 바탕으로 새로운 타입의 값을 만들어 단 한번 사용하고 버린다</b>

```javascript
var x = 10;

// 암묵적 타입 변환
// 숫자 타입 x의 값을 바탕으로 새로운 문자열 타입의 값을 생성해 표현식을 평가한다.
var str = x + '';

console.log(typeof str, str); // string 10

// 변수 x의 값이 변경된 것은 아니다.
console.log(x); // 10
```
위 예제의 경우, 자바스크립트 엔진은 표현식 x + ‘‘을 평가하기 위해 변수 x의 숫자 값을 바탕으로 새로운 문자열 값 ‘10’을 생성하고 이것으로 표현식 ‘10’ + ‘‘를 평가한다  
이때 자동 생성된 문자열 ‘10’은 표현식의 평가가 끝나면 아무도 참조하지 않으므로 가비지 컬렉터에 의해 메모리에서 제거된다

<b>암묵적 타입 변환</b>  
자바스크립트 엔진은 표현식을 평가할 때 문맥, 즉 컨텍스트(Context)에 고려하여 암묵적 타입 변환을 실행한다  

(자세한 예제들은 [출처](https://poiemaweb.com/js-type-coercion) 참고)  

<b>명시적 타입 변환</b>  

1. 래퍼 객체를 생성하기 위해 사용하는 래퍼 객체 생성자 함수를 new 연산자 없이 호출하는 방법  
ex) String(1), Number('0'), Boolean('x')
2. 자바스크립트에서 제공하는 빌트인 메소드를 사용하는 방법  
ex) (NaN).toString(), parseInt('-1'), parseFloat('10.52')
3. 암묵적 타입 변환을 이용하는 방법  
ex) 1+'', +true, '-1'*1, !!'x', !!Nan, !!1

 **Falsy**  

- `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`

아래의 모든 if 블록은 실행되지 않는다  

```javascript
if (false)
if (null)
if (undefined)
if (0)
if (-0)
if (0n)
if (NaN)
if ("")

```

<b>논리 AND 연산자, &&</b>
첫 번째 객체가 거짓 같은 값이라면, 해당 객체를 반환한다

```javascript
false && "dog"
// ↪ false

0 && "dog"
// ↪ 0
```

### 숫자

**NaN**  
Not-A-Number(숫자가 아님)
- 숫자로서 읽을 수 없음 (`parseInt("문자")`,`Numver(undefined)`)
- 결과가 허수인 수한 계산식 (`Math.sqrt(-1)`)
- 피연산자가 NaN (`7**NaN`)
- 정의할 수 없는 계산식 (`0*infinity`)
- 문자열을 포함하면서 덧셈이 아닌 계산식 (`"가"/3`)

<b> NaN 판별 </b>  

Number.isNaN() 또는 isNaN() 사용
- `isNaN`은 현재 값이 `NaN`이거나, 숫자로 변환했을 때 `NaN`이 되면 참을 반환
- `Number.isNaN`은 현재 값이 `NaN`이어야만 참을 반환

```javascript
isNaN('hello world'); // true
Number.isNaN('hello world'); // false
```
<https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/NaN>{:target="_blank"}

**BigInt**
- `BigInt`는 `Number` 원시 값이 안정적으로 나타낼 수 있는 최대치인 2^53-1 보다 큰 정수를 표현할 수 있는 내장 객체
- 정수 리터럴 뒤에 n을 붙이거나 (`10n`) 함수 `BigInt()`를 호출해 생성할 수 있다
- 소수점 결과를 포함하는 연산을 BigInt와 사용하면 소수점 이하는 사라진다
- `BigInt`는 `Number`와 일치하지 않지만 동등하다

```javascript
0n === 0
// ↪ false

0n == 0
// ↪ true
```
- `BigInt`는 다음의 상황에서 `Number`처럼 행동한다
  - `Boolean` 함수를 사용해 `Boolean` 객체로 변환
  - 논리 연산자 `||`,`&&`,`!`와 함께 사용
  - `if`문 등 조건 판별 시

```javascript
if (0n) {
  console.log('if에서 안녕!');
} else {
  console.log('else에서 안녕!');
}
// ↪ "else에서 안녕!"

0n || 12n
// ↪ 12n

0n && 12n
// ↪ 0n

Boolean(0n)
// ↪ false

Boolean(12n)
// ↪ true

!12n
// ↪ false

!0n
// ↪ true
```
- BigInt를 Number로 변환하는 과정에서 정확도를 유실할 수 있으므로, 2^53보다 큰 값을 예상할 수 있는 경우 BigInt만 사용하는 것이 좋다

<https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/BigInt>{:target="_blank"}

**parseInt()**  
```javascript
parseInt(string)
parseInt(string, radix)
```

`string` 
- 파싱할 값
- 문자열이 아닐 경우 `ToString` 추상 연산을 사용해 문자열로 변환한다  
문자열의 선행 공백은 무시한다

`radix` (Optional)
- `string`의 진수를 나타내는 2부터 36까지의 정수
- 기본 값이 10이 아니다
- Number 자료형이 아닌경우 Number로 변환한다


모두 15를 반환하는 예제
```javascript
parseInt('0xF', 16)
parseInt('F', 16)
parseInt('17', 8)
parseInt(021, 8)
parseInt('015', 10)    // parseInt('015', 8)이었다면 13을 반환
parseInt(15.99, 10)
parseInt('15,123', 10)
parseInt('FXX123', 16)
parseInt('1111', 2)
parseInt('15 * 3', 10)
parseInt('15e2', 10)
parseInt('15px', 10)
parseInt('12', 13)
parseInt('15','10')
```

NaN을 반환하는 예제
```javascript
parseInt('Hello', 8); // 숫자가 전혀 아님
parseInt('546', 2);   // 0과 1을 제외한 숫자는 2진법에서 유효하지 않음
```
