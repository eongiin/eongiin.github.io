#### HTML
- Hyper Text Markup Language

제목, 단락, 목록 등과 같은 본문을 위한 구조적 의미를 나타내는 것뿐만 아니라 링크, 인용과 그 밖의 항목으로 구조적 문서를 만들 수 있는 방법을 제공  

시맨틱 HTML은 주어진 목적을 위해 요소를 사용하기 때문에 사람과 기계가 읽고 이해하기가 더 쉽다  

**Emmet**


#### CSS
- Cascading Style Sheets

마크업 언어가 실제 표시되는 방법을 기술하는 스타일 언어  

**box-sizing**  
- box-sizing 기본 속성은 content-box로 되어 있지만 border-box로 해두는 것이 좋다  
- 그래야 box 사이즈를 고정하고 padding 값을 변경할 때 편하다

<https://developer.mozilla.org/ko/docs/Web/CSS/box-sizing>{:target="_blank"}

**선택자**
1. 기본 선택자
  - 전체 : \*
  - 요소 : div, span, body …
  - 클래스 : .
  - 아이디 : #
  - 특성 : [attr]
2. 그룹 선택자
  - ,
3. 결합자
  - 자손 : (한 칸 띄어쓰기)
  - 자식 : >
  - 일반 형제 : ~
  - 인접 형제 : +
4. 가상 클래스 선택자
  - :hover, :focus, :focus-visible, :active, :checked, :disabled, :not()
  - :first-child, :last-child, :nth-child, :only-child
5. 가상 요소 선택자
 - ::before, ::after, ::placeholder

#### Sass
- Syntactically Awesome StyleSheets

CSS pre-processor로서 CSS의 한계와 단점을 보완하여 보다 가독성이 높고 코드의 재사용에 유리한 CSS를 생성하기 위한 CSS의 확장(extension)  

**Sass 7-1 패턴**
- base/
- components/
- layout/
- pages/
- themes/
- abstracts/
- vendors/

파일명에 _가 붙은 경우 @import 되어 사용될 것으로 파악

**Variables**
```scss
$h1-color: blue;
h1 {
	color: $h1-color;
}
```

**@mixin**
```scss
@mixin ellipsis {
  text-overflow: ellipsis;
  white-space: nowrap;
  overflow: hidden;
}
div {
  @include ellipsis;
}
```

**@function**
```scss
@function half-opacity($color) {
	$color: rgba($color, 0.5);
	@return $color;
}

div {
	color: half-opacity(red);
}
```
