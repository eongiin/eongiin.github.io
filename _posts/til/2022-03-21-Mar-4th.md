### 예외 처리

```java
try{
  //예외가 생길 수 있는 부분
}catch (Exception e){
  //처리
}finally{
  //예외 발생 여부와 상관없이 항상 실행되는 부분
}
```

```java
try {
    int a = 5 / 0;
} catch (ArithmeticException e) {
    System.out.println("0으로 나누는 예외 발생");
    System.out.println("e = " + e);//e = java.lang.ArithmeticException: / by zero
} finally {
    System.out.println("예외 발생 여부와 상관없이 실행");
}
```

**사용자 정의 Exception**  

```java
class NotTenException extends RuntimeException {}
```

- Exception 클래스를 상속 받으면 checked Exception이 되어 예외 처리를 하지 않으면 컴파일 오류를 발생시킨다
- RuntimeException 클래스를 상속 받으면 unChecked Exception이 되어 예외 처리를 하지 않아도 컴파일 시에는 오류를 발생시키지 않는다


**throw**  
- 강제로 오류를 발생시킴

**throws**  
- 예외가 발생했을 때 예외를 호출한 쪽에서 처리하도록 던짐

```java
public static boolean checkTenWithThrows(int ten) throws NotTenException {
  if(ten!=10){
      throw new NotTenException();
  }
  return true;
}
```

이렇게 작성하면 호출한 쪽에서 예외 처리를 해줘야 한다


```java
boolean checkResult=true;
try{
  checkResult=Main.checkTenWithThrows(5);
}catch(NotTenException e){
  System.out.println("e = " + e);
  checkResult=false;
}finally{
  System.out.println("checkResult = " + checkResult);
}
```

### 컬렉션 프레임워크
#### Collection interface
- 중복 허용
- 순서 기억 x

#### List
- 순서가 있는 데이터의 집합 -> get으로 n번째 자료를 꺼낼 수 있다
- 데이터 중복 허용
- Collection 인터페이스 상속 받음
- 대표 구현 클래스
  - ArrayList
  - LinkedList
  - Vector

```java
//ArrayList
ArrayList list1 = new ArrayList();
list1.add(1);
list1.add(2);
list1.add(3);
list1.remove(Integer.valueOf(2));//값이 2인 것 삭제
list1.add(0, 10);//0번쨰 index에 10 추가
list1.contains(1)//1있으면 true
list1.indexOf(10)//있으면 해당 값 인덱스 반환 없으면 -1

//LinkedList
LinkedList list2=new LinkedList();
list2.add(1);
list2.add(2);
list2.add(3);

//위와 마찬가지로 remove,contains,indexOf등 사용가능

//다른 점
list2.addFirst(10);//[10,1,2,3]
list2.addLast(20);//[10,1,2,3,20].
list2.removeFirst();//[1,2,3,20]
list2.removeLast();//[1,2,3]
```

#### Set
- 순서가 없는 데이터의 집합
- 데이터 중복 x
- Collection 인터페이스 상속 받음
- 대표 구현 클래스
  - HashSet
  - TreeSet

```java
//HashSet
HashSet set=new HashSet();
set.add(1);
set.add(2);
set.add(3);
set.add(3);//중복은 거름

set.remove(1);// 해당 값 삭제 [2,3]
set.size();//2
set.contains(2);//true
set.clear();//[]

//TreeSet
TreeSet set2=new TreeSet();
set2.add(5);
set2.add(1);
set2.add(2);
set2.add(4);
set2.add(4);

//다른 점
set2.first();//1 가장 작은 값
set2.last();//5 가장 큰 값
set2.lower(3);//2 3보다 작은 값 중에 가장 큰 값
set2.higher(2);//4 2보다 큰 값 중에 가장 작은 값
```

#### Map
- 키와 값의 쌍으로 이루어진 데이터 집합 -> 키 값으로 접근
- 똑같은 키 값을 넣으면 나중에 넣은 값으로 바뀜
- 순서 없음
- 대표 구현 클래스
  - HashMap
  - TreeMap

```java
//HashMap
HashMap map1 = new HashMap();
map1.put(1, "one");
map1.put(2, "two");
map1.put(3, "three");

map1.remove(2);//{1=one, 3=three}
map1.get(1);//one
map1.get(2);//null

//TreeMap
TreeMap map2=new TreeMap();
map2.put(5,"five");
map2.put(1,"one");
map2.put(3,"three");
map2.put(4,"four");
map2.put(2,"two");

//다른 점
map2.firstEntry();//1=one
map2.firstKey();//1
map2.lastEntry();//5=five 
map2.lastKey();//5
map2.lowerEntry(3);//2=two
map2.higherEntry(1);//2=two
```

### 람다식
- 익명 메소드
- 메소드를 하나의 식으로 표현한 것
- 메소드를 람다 표현식으로 표현하면, 클래스를 작성하고 객체를 생성하지 않아도 메소드를 사용할 수 있다

```java
(매개변수 목록) -> {함수몸체}
```

- Runnable을 이용하여 쓰레드를 만드는 방법

```java
new Thread(new Runnable(){public void run(){
  for(int i = 0; i < 10; i++){
      System.out.println("Runnable");
  }
}}).start();
```

- 람다식을 이용해서 수정

```java
new Thread(()->{
  for(int i = 0; i < 10; i++){
      System.out.println("람다식");
  }
}).start();
```

**함수형 인터페이스**
- 인터페이스 중에서 메소드를 <b>하나</b>만 가지고 있는 인터페이스
- 람다 표현식을 하나의 변수에 대입할 때 사용하는 참조 변수의 타입
- @FunctionallInterface 를 사용하여 함수형 인터페이스임을 명시할 수 있다



```java
//함수형 인터페이스
interface ComputeTool {
    public abstract int compute(int x, int y);
}
```

```java
//익명 클래스 이용
ComputeTool cTool1=new ComputeTool() {
  @Override
  public int compute(int x, int y) {
      return x+y;
  }
};

//람다식
ComputeTool cTool2= (x,y)->{return x+y;};
System.out.println(cTool2.compute(1,2));
```

### 스트림

- 배열, 컬렉션 등의 데이터를 하나씩 참조하여 처리 가능한 기능
- 스트림은 원본 데이터를 변경하지 않는다
- 스트림은 최종 연산을 하면 더 이상 stream 연산을 할 수 없고 종료된다


<http://www.tcpschool.com/java/java_stream_concept>{:target="_blank"}  

#### 스트림 생성

- 배열 스트림

```java
String[] arr = new String[]{"a", "b", "c"};
Stream stream = Arrays.stream(arr);
stream.forEach(System.out::println);
```

- 컬렉션 스트림

```java
ArrayList list = new ArrayList(Arrays.asList(1, 2, 3));
Stream stream = list.stream();
stream.forEach(System.out::println);
```

- 스트림 builder

```java
Stream streamBuilder=Stream.builder().add(1).add(2).add(3).build();
streamBuilder.forEach(System.out::println);
```

- 스트림 generate

```java
Stream streamGenerate=Stream.generate(()->"abc").limit(5);//abc 5번 반복
streamGenerate.forEach(System.out::println);
```

- 스트림 iterate

```java
Stream streamIterate= Stream.iterate(10,n->n*2).limit(3);
streamIterate.forEach(System.out::println);
//10
//20
//40
```

- 기본 타입 스트림

```java
IntStream intStream=IntStream.range(1,5);
intStream.forEach(System.out::println);
```

#### 중개 연산

- Filtering

```java
IntStream.range(1,10).filter(n->n%2==0).forEach(System.out::println);
```

- Mapping

```java
IntStream.rage(1,10).map(n->n+1).forEach(System.out::println);
```

- Sorting

```java
IntStream.builder().add(5).add(1).add(3).add(2).add(4).build().sorted().forEach(System.out::println);
```

#### 최종 연산

```java
int sum=IntStream.range(1,5).sum();
```

- average

```java
double average=IntStream.range(1,5).average().getAsDouble();
```

- min

```java

```

- max

```java

```

- reduce

```java
System.out.println(IntStream.range(1,5).reduce((x,y)->x*y).getAsInt());
// 순서대로 (((1*2)*3)*4)=24
```

- forEach

```java
new ArrayList<Integer>(Arrays.asList(10, 3, 16, 20, 45, 14)).stream().filter(n -> n % 5 == 0).forEach(System.out::println);
//10
//20
//45
```
