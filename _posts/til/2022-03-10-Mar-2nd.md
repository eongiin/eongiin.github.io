#### 브루트 포스 vs 백트래킹
- 브루트 포스 
  - 꼭 '깊이'나 '탐색'의 개념이 아니더라도, 모든 경우의 수를 다 대입해보는 것. 완전 탐색  
  - 항상 답을 구할 수 있으나 시간상 매우 비효율적이다
- 백트래킹
  -  모든 가능한 경우의 수 중에서 특정한 조건을 만족하는 경우만 살펴보는 것 (가지치기)
  - 어떤 노드의 유망성, 즉 해가 될 만한지 판단한 후 유망하지 않다고 결정되면 그 노드의 부모로 돌아가(Backtracking) 다음 자식 노드 이동한다
  - 반드시 DFS만으로 가능한 게 아니고 BFS 등으로도 가능하지만 일반적으로 DFS와 연관이 깊다

DFS는 여러지점을 한 단계씩 거쳐가면서 탐색하고 스택의 개념을 이용해서 이전 단계로 돌아가는 기법이다  
백트래킹은 하나의 문제 해결 방법론이고 이러한 백트래킹을 구현하는 방법론 중 하나가 DFS

#### java 에서 배열 비교

- 같은 값을 가진 배열인지 확인하고 싶을 때는 Arrays.equals(a,b)를 쓴다  
  - 이 방법은 병렬로 위치별로 배열을 반복  하고 모든 요소 쌍에 대해 == 연산자를 적용한다  
  - 순서에 상관없이 같은 값들을 가지고 있는지 확인하려면 정렬 후 비교해야 한다
- Object 배열을 비교할 때는 Arrays.deepEquals(a,b)를 쓰면 된다
