### 투 포인터

- 문자열 s 거꾸로 출력하기 (단, 각 단어의 알파벳 순서는 그대로)
  - ex) `red orange yellow` → `yellow orange red`
  - 단어 사이에 공백이 여러 개 있다면 한 개만
  - 문자열을 단순히 뒤집는 건 `StringBuilder`로 만들고 `reverse()`를 이용해 간단히 뒤집을 수 있지만 여기서는 그것도 다 구현
    - `StringBuilder sb=new StringBuilder(s);`
    - `sb.reverse().toString()`  

  1. 여러 개인 공백 제거  
  2. 문자열 전체 뒤집기  
  3. 단어 별로 다시 뒤집기 (원래대로)  
    
```java
public static String solution(String s) {
    s = removeSpaces(s);

    char[] cArr = s.toCharArray();
    reverseString(cArr, 0, cArr.length - 1);

    reverseWords(cArr, s.length());

    return new String(cArr);
}

public static String removeSpaces(String s) {
    int p1 = 0;
    int p2 = 0;

    char[] cArr = s.toCharArray();
    int length = s.length();

    while (p2 < length) {
        //단어 앞 공백 skip
        while (p2 < length && cArr[p2] == ' ') {
            p2++;
        }

        while (p2 < length && cArr[p2] != ' ') {
            cArr[p1++] = cArr[p2++];
        }

        //단어 뒤 공백 skip
        while (p2 < length && cArr[p2] == ' ') {
            p2++;
        }

        //단어 앞 뒤 공백을 모두 삭제하고 넣었으므로 단어 사이의 공백 추가
        if (p2 < length) {
            cArr[p1++] = ' ';
        }
    }
    return new String(cArr).substring(0, p1);
}

public static void reverseString(char[] cArr, int i, int j) {
    while (i < j) {
        char tmp = cArr[i];
        cArr[i++] = cArr[j];
        cArr[j--] = tmp;
    }
}

public static void reverseWords(char[] cArr, int length) {

    int p1 = 0;
    int p2 = 0;

    while (p1 < length) {
        p1 = p2;
        while (p1 < length && cArr[p1] == ' ') {
            p1++;
        }
        p2 = p1;
        while (p2 < length && cArr[p2] != ' ') {
            p2++;
        }

        reverseString(cArr, p1, p2 - 1);
    }
}
```
- 주어진 배열에서 세 숫자의 합이 0이 되는 숫자 조합 모두 구하기 (중복 X)
  - ex) `{-1, 0, 1, 2, -1, -4}` → `[[-1, -1, 2], [-1, 0, 1]]`

  1. 주어진 배열 오름차순 정렬
  2. for 문으로 `0`부터 `배열.length-2`까지 돌면서 (`p1=i+1`, `p2=배열length-1`)

    - `배열[i]+배열[p1]+배열[p2]` 값이
      - 0이면 리스트에 추가
      - 0보다 작으면 `p1++;`
      - 0보다 크면 `p2--;`

  - 중복 값을 거르기 위해 인덱스 이동할 때 전의 값과 같은지 확인하고 같으면 다를 때까지 이동

```java
public static ArrayList<ArrayList<Integer>> solution(int[] nums) {

    Arrays.sort(nums);
    ArrayList<ArrayList<Integer>> result = new ArrayList<>();

    for (int i = 0; i < nums.length - 2; i++) {
        if (i == 0 || nums[i] != nums[i - 1]) {//중복 피하기 위해
            int p1 = i + 1;
            int p2 = nums.length - 1;

            while (p1 < p2) {
                if (nums[i] + nums[p1] + nums[p2] == 0) {
                    result.add(new ArrayList<>(Arrays.asList(nums[i], nums[p1], nums[p2])));

                    //중복 피하기 위해
                    while (p1 < p2 && nums[p1] == nums[p1 + 1]) {
                        p1++;
                    }
                    while (p1 < p2 && nums[p2] == nums[p2 - 1]) {
                        p2--;
                    }
                    p1++;
                    p2--;
                } else if (nums[i] + nums[p1] + nums[p2] < 0) {
                    p1++;
                } else {
                    p2--;
                }
            }
        }
    }
    return result;
}
```
