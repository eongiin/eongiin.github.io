# 16 Mon

## ✏️ DB
- 데이터베이스에 루트로 접속
  - `mysql -u root -p` (비밀번호 입력)
- 데이터베이스 목록 확인
  - `SHOW DATABASES;`
- 데이터베이스 인스턴스 생성과 삭제
  - `CREATE DATABASE DB명;`
  - `DROP DATABASE DB명;`
- 데이터베이스 선택
  - `USE DB명;`
- 테이블 목록 확인
  - `SHOW TABLES;`
- 사용중인 계정 조회
  - `SELECT host, user, password FROM user;`
- 계정 생성
  - `CREATE USER 'username'@'%' IDENTIFIED BY 'password';`
  - `'id'@'localhost'`로 생성하면 로컬 호스트에서만 접속 가능
  - `%`는 외부 접근 모두 허용
- 권한 부여
  - `GRANT ALL PRIVILEGES ON DB명.* TO 'username'@'%' IDENTIFIED BY 'password';`
- 새로고침
  - `FLUSH PRIVILEGES;`
- 계정 삭제
  - `DROP USER 'username'@'host';`
- DBeaver로 접속  
  - (DB - testdb1, user - testuser1)
  - host, port, database, username, password

![image](https://user-images.githubusercontent.com/90626691/168601435-783154ef-7243-4106-ab5a-c8ac0cb47abf.png)

- 자주 쓰는 자료형 
  - `INT`, `DOUBLE`, `CHAR`, `VARCHAR`, `BIT`, `DATETIME`, `TIMESTAMP`, `TEXT`
- 테이블 생성

```sql
create table member(
	id varchar(50),
	name varchar(20),
	password varchar(20),
	old_year int,
	birth_date date,
	sms_send_yn bit,
	register_date datetime
);
```
