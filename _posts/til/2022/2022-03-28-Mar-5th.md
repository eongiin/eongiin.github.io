## 🐾 Git

### WSL 설치

- SSH키를 생성하다가 리눅스 명령어로 실행하고 싶어서 WSL를 설치했다
- WSL은 Windows Subsystem for Linux의 줄임말로, 윈도우의 가상화 기능을 활용해서 윈도우 위에서 리눅스를 사용할 수 있게해준다
- 단순히 가상머신으로 리눅스를 사용할 수 있는 것이 아니라, 윈도우 시스템과 통합되어 마치 하나의 머신처럼 자연스럽게 리눅스를 활용하는 것이 가능하다
- 오류가 발생해서 [이전 버전의 수동 설치 단계](https://docs.microsoft.com/ko-kr/windows/wsl/install-manual){:target="_blank"}탭에 있는대로 했다
- 참고
  - [Microsoft Docs](https://docs.microsoft.com/ko-kr/windows/wsl/install){:target="_blank"}
  - [[Windows 10] WSL2 설치 및 사용법](https://www.lainyzine.com/ko/article/how-to-install-wsl2-and-use-linux-on-windows-10/){:target="_blank"}

## 🐾 Git

- 계정 인증
  - 여전히 계정 인증하는 부분을 정확히 모르겠다  
  어제 SSH 키를 이용해서 인증을 했지만 그 전에 나는 어떤식으로 인증한거지? 하는 생각과  
  소스트리로 진행했는데 CLI 환경에서는 SSH 키로 어떻게 인증하는지, 다른 계정을 사용하고 싶을 때는 어떻게 전환해야하는지 등이 궁금하다  
  이 부분에 대해서는 앞으로 차근차근 알아보겠다
  - 오늘도 역시 오류가 있었다  
  fork 실습을 하면서 테스트 계정을 하나 만들어서 소스트리에도 계정을 추가했는데  
  - ![image](https://user-images.githubusercontent.com/90626691/160755865-5f5fed0a-7eb4-44b8-9be6-9439ffb6ad72.png)
    - 인증하는 방법에서 OAuth를 선택하여 웹브라우저를 띄워 로그인하는 방식으로는 잘 되는데 Basic을 선택해서 github 닉네임과 암호를 입력하는 방식으로 로그인하면 인증이 되지 않는다
    - 인증 부분에 대해 좀 더 알아보고 다시 해결해보겠다  
    일단은 OAuth 방식으로 인증을 했다
  - 테스트 계정은 나의 원래 이메일에 +test를 붙여서 만들었다(eongiin+test@gmail)  
  이렇게 +을 이용해서 만들면 모두 같은 계정으로 메일을 받을 수 있다고 한다
- Pull Request
  - 나는 그동안 혼자서 commit-push만 계속 반복하다 보니까 pull request를 써본 적이 없는데, 앞으로는 혼자 하더라도 브랜치를 만들어서 거기에 추가하고 나중에 main에 합치는 식으로 해 볼 예정이다
  - 일단 지금은 나 혼자 하는 상황이다 보니 나밖에 없지만.. 나중에 팀 프로젝트 할 때를 대비하여 혼자 풀 리퀘스트를 보내고.. 스스로 확인하고.. main에 합치며.. 이런 과정들을 좀 연습해 봐야겠다
