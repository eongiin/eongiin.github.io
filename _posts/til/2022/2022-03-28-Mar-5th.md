## 🐾 Git

### WSL 설치

- SSH키를 생성하다가 리눅스 명령어로 실행하고 싶어서 WSL를 설치했다
- WSL은 Windows Subsystem for Linux의 줄임말로, 윈도우의 가상화 기능을 활용해서 윈도우 위에서 리눅스를 사용할 수 있게해준다
- 단순히 가상머신으로 리눅스를 사용할 수 있는 것이 아니라, 윈도우 시스템과 통합되어 마치 하나의 머신처럼 자연스럽게 리눅스를 활용하는 것이 가능하다
- 오류가 발생해서 [이전 버전의 수동 설치 단계](https://docs.microsoft.com/ko-kr/windows/wsl/install-manual){:target="_blank"}탭에 있는대로 했다
- 참고
  - [Microsoft Docs](https://docs.microsoft.com/ko-kr/windows/wsl/install){:target="_blank"}
  - [[Windows 10] WSL2 설치 및 사용법](https://www.lainyzine.com/ko/article/how-to-install-wsl2-and-use-linux-on-windows-10/){:target="_blank"}

### 계정 별 SSH키 생성하고 인증하기
- 3.29 TIL을 보면 SSH키를 만들었었지만 삭제하고, 다시 한 번 만들었다  
  - 보통 id_rsa_이름 or id_ed25519_이름 이런식으로 만드는 것 같길래 나도 id_ed25519_eongiin으로 만들었다
  - 그리고 어제 test github계정을 만들었었는데 여기서 사용할 SSH키도 id_ed25519_eongiin_test로 만들었다
    - **git bash** 열고  
      ```bash
      $ ssh-keygen -t ed25519 -C "eongiin@gmail.com"
      id_ed25519_eongiin
      (비밀번호는 생략하고 enter 두 번)
      ```

      ```bash
      $ ssh-keygen -t ed25519 -C "eongiin+test@gmail.com"
      id_ed25519_eongiin_test
      (비밀번호는 생략하고 enter 두 번)
      ```
- ssh agent를 백그라운드로 실행 시켜주고
```bash
$ eval "$(ssh-agent -s)"
```
- ssh agent에 키를 등록해준다
```bash
$ ssh-add ~/.ssh/id_ed25519_eongiin
```
  - ![image](https://user-images.githubusercontent.com/90626691/160979479-62d44934-8344-4bc3-9d8b-3e4d61bb5f99.png)
  - eongiin_test도 이런식으로 같이 등록
- ssh-agent 쓰는 이유 
  - ssh-agent 없이도 ssh 키를 가지고 아이디, 비밀번호 없이 원격 서버에 접속할 수 있지만, ssh키 생성시 비밀번호를 입력했다면 키를 이용해 원격 서버에 접속할 때 비밀번호를 물어본다
  - ssh-agent를 쓰면 개인키의 비밀번호를 암호화 해 기억해두고 처음 한 번만 개인키 비밀번호를 입력하면 다음부터는 기억한 비밀번호를 이용해서 사용자는 또 비밀번호를 입력하지 않아도 된다
  - [출처](https://devlog.jwgo.kr/2019/04/17/ssh-keygen-and-ssh-agent/){: target="_blank"}
- GitHub에 계정 별로 ssh 키 등록
  - `cat id_ed25519_eongiin.pub` , `cat id_ed25519_eongiin_test.pub`을 사용해 얻은 키 값을 각 github 계정에 등록해준다
- ssh config 수정 (config 파일이 없다면 `$ echo "Host github.com" >> ~/.ssh/config`로 만들어 줄 것) (touch config)
  ```
  Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_eongiin

  Host github.com-eongiin_test
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_eongiin_test
  ```
  - 첫 번째는 eongiin 계정용 키 두 번째는 eongiin-test 계정용 키
  - 주목해야 할 부분은 두 번째에 github.com-eongiin_test 이 부분!  
  여러 개의 키를 구분하기 위해 저렇게 -eongiin_test를 붙여줬다  
  이렇게 해줬으면 remote url 설정할 때 `git@github.com:eongiin-test/test0331.git` 에서 github.com뒤에 eongiin_test를 붙여서 `git@github.com-eongiin_test:eongiin-test/test0331.git`로 설정해야 한다  
    ```bash
    $ git remote set-url origin git@github.com-eongiin_test:eongiin-test/test0331.git
    ```
  - ~~그리고 이렇게 설정을 했으면 소스트리를 이용해서 클론할 때 자동으로 인증이 안돼서 3.29일에 했던 것처럼 ppk 만들어서 인증하는 작업을 해줘야 한다~~  
    - 터미널에서 작업하면 편하다 그냥 url 수정해서 클론하면 된다

- 18-1 3번문제 (replace 구현) 
  - 해설 강의를 보다가 제공된 코드대로 하면, 나중에 훨씬 더 많은 바꿀 데이터가 있을 때 너무 시간이 오래 걸리게 되지 않을까?하는 생각이 들었다
  - findIndex 함수도 매번 처음부터 바꿀 문자열의 위치를 찾는 방식이고, 바꿀 문자열의 위치를 찾고나서 바꾸는 과정도 한 번에 한 단어(문자)씩만 바꾸면서 매번 전체 문자열을 복사하고 (전체 문자열이 길수록 복사하는 시간도 많이 증가할 것이고..) 이걸 계속 반복하는 것이라 바꿔야하는 데이터가 많다면 시간이 굉장히 오래 걸릴 것 같다
  - 내가  짠 코드는  문자열 돌면서 찾는 문자와 완전히 일치하는지 검사하고  
  완전히 일치한다면 바로 newStr을 추가하고 find 크기만큼 인덱스를 증가시킨다  
  일치하지 않는다면 그냥 현재 인덱스에 해당하는 값을 추가하고 다음 인덱스로 넘어간다  
  처음으로 돌아가서 반복하지 않는다
  - 근데 내가 짠 코드는 가독성이 떨어지긴 해서 좀 더 수정을 해봤다
    - 일단 찾는 문자열과 완전히 일치하는지 확인하는 부분을 isMatch 함수로 분리했다
    - 어디선가 조건문을 중첩해서 쓰는 것보다는 아닌 케이스를 걸러내는 게 (continue) 더 좋다고 본 것 같아서  
      - 첫 문자가 일치하지 않는경우
      - 바꿀 문자열의 크기만큼 인덱스가 남아있지 않은 경우

      를 먼저 걸러냈는데, 걸러내고 보니까 나중에 최종적으로 일치하지 않는 경우까지 합쳐서 똑같이 append 하는 코드가 3번 반복돼서 그냥 일치하는 경우를 찾아내고  나머지 경우는 한 번에 다 처리하는 식으로 했다

    ```java
      public static String solution(char[] str, char[] find, char[] to) {

          String newStr=new String(to);
          StringBuilder replaceStr=new StringBuilder();

          for(int i=0;i<str.length;i++){
              if(i+find.length<=str.length && str[i]==find[0]){
                  if(isMatch(i,find,str)){
                      replaceStr.append(newStr);
                      i+=find.length-1;
                      continue;
                  }
              }
              replaceStr.append(str[i]);
          }
          return replaceStr.toString();
      }
      public static boolean isMatch(int idx,char[] find,char[] str){
          for (int j = 1; j < find.length; j++) {
              if(str[idx+j]!=find[j]){
                  return false;
              }
          }
          return true;
      }
    ```

  - 양쪽에서 인덱스를 옮겨가며 구해야 O(n)에 구할 수 있다
