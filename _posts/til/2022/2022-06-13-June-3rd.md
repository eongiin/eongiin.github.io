```java
private String buildDistQuery(double lat, double lnt) {

  final double myCosLat = Math.cos(Math.toRadians(lat));
  final double myCosLnt = Math.cos(Math.toRadians(lnt));
  final double mySinLat = Math.sin(Math.toRadians(lat));
  final double mySinLnt = Math.sin(Math.toRadians(lnt));
  
  return "6371*acos(" + myCosLat + "*cos_lat*(cos_lnt*" + myCosLnt + "+sin_lnt*" + mySinLnt + ")+" + mySinLat + "*sin_lat) ";
}
```

### 데이터 누락 오류 (LAT,LNG)
- 어제 위도, 경도 값이 누락된 경우에 대해 확실히 처리하고 넘어가지 않아 찜찜해서 조금 더 생각해 봤다
- 일단 Dto는 전부 String으로 만들고 숫자로 변형해야 하는 값에 대해서만 Dto ->  Entity로 변경할 때 값이 제대로 있는지 확인을 하고 변경했다  
(누락되어 있으면 null을 집어넣음)
- 그리고 데이터베이스에 넣을 때 어제는 setDouble로 해서 계속 NullPointerException이 발생했는데 setObject로 하니 DB에 null 값이 잘 들어갔다
- 데이터를 보여주는 부분에 대해서는 위도, 경도를 기준으로 계산한 결과를 보여주는 것이기 때문에 쿼리를 수행할 때 두 개 모두 있는 값에 대해서만 계산을 해서 위도, 경도 값이 null인 경우를 보여줄 일이 없다. 그래서 null값인 경우 화면에 어떻게 보여줄지는 따로 처리하지 않았다
- YEAR 값도 같이 Integer로 바꾸고 싶었으나 이미 String 타입으로 DB 만든 것을 제출해서.. 이건 그냥 String으로 놔뒀다
  - 만약 Integer 값으로 진행했다면 null 값이 있는 경우 ResponseDto를 모두 String 타입으로 만들고 ResponseDto를 생성할 때 int로 받아온 값이 0이면 공백을 출력하도록 하는 처리를 해주면 된다
    - getInt()의 반환값이 int라 그런지 기본 값이 0이다.
    - 연도는 0이 유효하지 않은 값이니까 상관없는데, 경도 위도는 null 값을 0으로 판단하면 안 될 것 같아서 만약 위도, 경도 값이 null 값이 포함될 수 있는 정보라면 위도, 경도를 getObject로 받아온 후 ResponseDto에서도 일단 Object로 받고 null 값 처리를 하고 String 값으로 바꾸면 될 것 같다
