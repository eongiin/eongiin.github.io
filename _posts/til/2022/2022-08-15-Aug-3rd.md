### 이메일 보내기

#### Mailgun (with Feign)
- <https://www.mailgun.com/>{:target="_blank"}
- 가입을하고 sending쪽에 들어가보면 도메인이 하나 만들어져 있음
- API를 통해 만들 예정
- Sample code가 있는데 그대로 활용하지는 않고 feign과 함께 사용할 예정
  - [feign 참고](https://techblog.woowahan.com/2630/){:target="_blank"}
  - feign dependency 추가
    
    ```
    ext{
      set('springCloudVersion',"2021.0.1")
    }
    ```
    - `implementation 'org.springframework.cloud:spring-cloud-starter-openfeign'`

    ```
    dependencyManagement{
      imports{
        mavenBom 'org.springframework.cloud:spring-cloud-dependencies:' + springCloudVersion
      }
    }
    ```  
    - ![image](https://user-images.githubusercontent.com/90626691/184058965-a5ed0b5c-9a6d-41c0-b4e1-bf88a1177541.png)
  - UserApplication에 `@EnableFeignClients` 붙이기
- client/MailgunClient
    - `YOUR_DOMAIN_NAME`에는 base url에서 sandbox 부분부터 복사한 값을 넣어주면 된다
  ```java
    @FeignClient(name = "mailgun", url = "https://api.mailgun.net/v3/")
    @Qualifier("mailgun")
    public interface MailgunClient {

        @PostMapping("YOUR_DOMAIN_NAME/messages")
        ResponseEntity<String> sendEmail(@SpringQueryMap SendMailForm form);
    }
  ```
- API Key 설정
  - config/FeignConfig
    - API Key는 노출되면 안되므로 따로 관리
    - ![image](https://user-images.githubusercontent.com/90626691/185545994-cd7a8d37-f710-40fb-a012-ee1ce84732a3.png)
    - `-Dmailgun.key=`뒤에 API Key 입력
  ```java
    @Configuration
    public class FeignConfig {
        @Value(value = "${mailgun.key}")
        private String mailgunKey;

        @Qualifier(value = "mailgun")
        @Bean
        public BasicAuthRequestInterceptor basicAuthRequestInterceptor() {
            return new BasicAuthRequestInterceptor("api", mailgunKey);
        }
    }
  ```

- client/SendMailForm
  - 보내는 사람(메일 주소), 받는 사람(메일 주소), 제목, 내용
- client/service/EmailSendService
    - 무료 계정으로 메일을 정상적으로 보내기 위해서는 받는 사람의 메일 주소를 mailgun 사이트에 등록해두어야 한다

```java
@Service
@RequiredArgsConstructor
public class EmailSendService {
    private final MailgunClient mailgunClient;

    public String sendEmail() {
        SendMailForm form = SendMailForm.builder()
                .from("보내는 사람 메일 주소")
                .to("받는 사람 메일 주소")
                .subject("제목")
                .text("내용")
                .build();
        return mailgunClient.sendEmail(form).getBody();
    }
}
```
