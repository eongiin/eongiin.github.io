### 비밀번호 찾기(초기화)
1. 아이디(메일)과 이름을 입력하고 비밀번호 초기화를 누르면 해당 정보가 있는지 확인하고, 있으면 그 메일로 초기화할 수 있는 페이지 링크 주소가 담긴 메일을 보낸다
2. 메일을 보낼 때, UUID를 생성해서 `ResetPasswordKey`로 설정하고, 현재 날짜에서 +1한 날짜를 `ResetPasswordLimitDt`로 설정해서 저장한다
3. 메일로 받은 링크로 접속했을 때 유효한 UUID 값인지 확인하고(`checkResetPassword`) 맞으면 초기화할 수 있는 폼을 보여주고 아니면 메인으로 돌아갈 수 있는 링크를 보여준다
4. 초기화 폼이 성공적으로 나오면 비밀번호를 입력한 후, 비밀번호를 맞게 입력했는지 확인 후 지정한 값으로 비밀번호를 재설정한다 (DB에 저장되어 있는 UUID, 초기화-날짜 초기화 )


- 비밀번호 초기화 버튼 눌렀을 때 초기화할 수 있는 페이지 링크를 메일로 보내는 부분

public String findPasswordSubmit(

        result = memberService.sendResetPassword(parameter);

`MemberServiceImpl.java`

```java
@Override
public boolean sendResetPassword(ResetPasswordInput parameter) {
    Optional<Member> optionalMember =
            memberRepository.findByUserIdAndUserName(
                    parameter.getUserId(),
                    parameter.getUserName()
            );

    if (optionalMember.isEmpty()) {
        throw new UsernameNotFoundException("회원 정보가 존재하지 않습니다.");
    }

    Member member = optionalMember.get();
    String uuid = UUID.randomUUID().toString();

    member.setResetPasswordKey(uuid);
    member.setResetPasswordLimitDt(LocalDateTime.now().plusDays(1));
    memberRepository.save(member);

    return mailComponents.sendMail(
            parameter.getUserId(),
            "[fastlms] 비밀번호 초기화 메일 입니다",
            "<p>fastlms 비밀번호 초기화 메일 입니다.</p>"
                    + "<p>아래 링크를 클릭하셔서 비밀번호를 초기화 해주세요.</p>"
                    + "<div><a target='_blank' href='http://localhost:8080/member/reset/password?id="
                    + uuid
                    + "'>비밀번호 초기화 링크</a></div>"
    );
}
```

- 사용자가 설정한 비밀번호로 설정  
`MemberController.java`

```java
@PostMapping("/member/reset/password")
public String resetPasswordSubmit(Model model, ResetPasswordInput parameter) {

    boolean result = false;
    try {
        result = memberService.resetPassword(parameter.getId(), parameter.getPassword());
    } catch (Exception e) {
    }

    model.addAttribute("result", result);
    return "member/reset_password_result";
}
```

`MemberServiceImpl`

```java
@Override
public boolean resetPassword(String uuid, String password) {

    Optional<Member> optionalMember = memberRepository.findByResetPasswordKey(uuid);
    if (optionalMember.isEmpty()) {
        throw new UsernameNotFoundException("회원 정보가 존재하지 않습니다");
    }

    Member member = optionalMember.get();

    if (member.getResetPasswordLimitDt() == null) {
        throw new RuntimeException("유효한 날짜가 아닙니다.");//나중에 수정
    }

    if (member.getResetPasswordLimitDt().isBefore(LocalDateTime.now())) {
        throw new RuntimeException("유효한 날짜가 아닙니다.");//나중에 수정
    }

    String encPassword = BCrypt.hashpw(password, BCrypt.gensalt());
    member.setPassword(encPassword);
    member.setResetPasswordKey("");
    member.setResetPasswordLimitDt(null);
    memberRepository.save(member);

    return true;
}
```
