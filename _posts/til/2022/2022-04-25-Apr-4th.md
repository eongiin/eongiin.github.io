## ✏️ 선형 자료구조 (Java)
### 해시 테이블 (HashTable)

- key, value를 대응시켜 저장하는 데이터 구조
  - 키를 통해 해당 데이터에 빠르게 접근 가능
- 해싱
  - 키를 특정 계산식에 넣어 나온 결과를 사용하여 값에 접근하는 과정
- HashMap과 유사, 차이점은? 
  - 동기화 지원 여부
    - HashTable : Thread-safe O (멀티 스레드 환경에서 우수)
    - HashMap : Thread-safe X (싱글 스레드 환경에서 우수)
      - synchronizedMap, ConcurrentHashMap 을 사용하면 Thread-safe 하게 사용 가능
  - Null 값 허용 여부
    - HashTable : key에 null 값  X
    - HashMap : key에 null 값 O
  - Enumeration 여부
    - HashTable : not fail-fast Enumeration 제공
    - HashMap : Enumeration 제공 X
  - HashTable은 구현에 거의 변화가 없지만, HashMap은 현재까지도 지속적으로 개선되고 있다 
  -> HashMap 이용하자 (멀티 스레드 환경에서는 synchronizedMap, ConcurrentHashMap)

- 해시 충돌
  - 서로 다른 키의 해시 함수를 통한 해시 값이 동일한 경우
  - 해결 방법
    - <b>개방 주소법 </b>: 충돌 시, 테이블에서 비어 있는 공간의 hash를 찾아 데이터를 저장, hash와 value가 1:1 매핑
      - 선형 탐사법 : 충돌 발생 지점부터 이후의 빈 공간을 순서대로 탐사
        - 일차 군집화 문제 발생 : 반복된 충돌 발생 시 해당 지점 주변에 데이터가 몰리는 경우 발생
        - `newIdx = (newIdx + 1) % this.table.length;`
      - 제곱 탐사법 : 충돌 발생 지점부터 이후의 빈 공간을 n 제곱 간격으로 탐사
        - 일차 군집화 문제 일부 보완
        - 이차 군집화 문제 발생 가능성
        - `newIdx = (newIdx + (int)Math.pow(2, cnt)) % this.table.length;`
      - 이중 해싱 : 해싱 함수를 이중으로 사용
        - 선형 탐사, 제곱 탐사에 비해 데이터가 골고루 분포됨
        - `newIdx = (newIdx + this.getHash2(newIdx) * cnt) % this.table.length;`
    - <b>분리 연결법</b> 
      - 해시 테이블을 연결 리스트로 구성해서 충돌 발생 시, 테이블 내의 다른 위치를 탐색하는 것이 아닌 연결 리스트를 이용하여 해당 
    테이블에 데이터를 연결  
      - 하나의 키값에 대해 동일한 해시 위치에 여러 데이터가 있을 수 있어 데이터에 접근할 때 상대적으로 오래 걸림

```java
public static void solution(int[] data) {
  int visitCnt = 0;
  int idx = 0;
  int cmd = 0;
  boolean[] visited = new boolean[data.length];

  while (visitCnt != data.length) {
      idx = (idx + cmd + data.length) % data.length;
      if (visited[idx]) {
          while (visited[idx]) {
              if (cmd < 0) {
                  idx = (idx - 1 + data.length) % data.length;
              } else {
                  idx = (idx + 1) % data.length;
              }
          }
      }

      cmd = data[idx];
      System.out.print(idx + 1 + " ");
      visitCnt++;
      visited[idx] = true;
  }
  System.out.println();
}
```

```java
public static Integer solution(int n, int k, int l, ArrayList<ArrayList> apples, Queue<ArrayList> moves) {
  int time = 0;
  int[][] board = new int[n + 1][n + 1];
  int[] dx = {0, 1, 0, -1};
  int[] dy = {1, 0, -1, 0};
  int dIdx = 0;
  int x = 1;
  int y = 1;
  Queue<int[]> snake = new LinkedList<>();
  snake.add(new int[]{x, y});

  for (ArrayList apple : apples) {
      board[(int) apple.get(0)][(int) apple.get(1)] = 1;
  }

  while (true) {

      time++;
      x += dx[dIdx];
      y += dy[dIdx];

      if (1 <= x && x <= n && 1 <= y && y <= n) {
          for (int[] dot : snake) {
              if (dot[0] == x && dot[1] == y) {
                  return time;
              }
          }
          snake.add(new int[]{x, y});

          if (board[x][y] == 0) {
              snake.poll();
          } else {
              board[x][y] = 0;
          }
      } else {
          return time;
      }


      if (moves.size() > 0 && (int) moves.peek().get(0) == time) {
          if ((char) moves.peek().get(1) == 'D') {
              dIdx = (dIdx + 1) % 4;
          } else {
              dIdx = (dIdx + 3) % 4;
          }
          moves.poll();
      }
  }
}
```

## ✏️ 비선형 자료구조 (Java)
### 트리

- 노드(Node) : 트리 구조의 자료 값을 담고 있는 단위
- 에지(Edge) : 노드 간의 연결선 (=link, branch)
- 루트 노드(Root) : 부모가 없는 노드, 가장 위의 노드
- 잎새 노드(Leaf) : 자식이 없는 노드 (=단말)
- 내부 노드(Internal) : 잎새 노드를 제외한 모든 노드
- 부모(Parent) : 연결된 두 노드 중 상위의 노드
- 형제(Sibling) : 같은 부모를 가지는 노드
- 깊이(Depth) : 루트에서 어떤 노드까지의 간선의 수
- 레벨(Level) : 트리의 특정 깊이를 가지는 노드 집합
- 높이(Height) : 트리에서 가장 큰 레벨 값
- 크기(Size) : 자신을 포함한 자식 노드의 개수
- 차수(Degree) : 각 노드가 지닌 가지의 수
- 트리의 차수 : 트리의 최대 차수

**특징**

- 하나의 노드에서 다른 노드로 이동하는 경로는 유일
- 노드가 n개의 트리의 edge의 수는 n-1
- Acyclic (Cycle이 존재하지 않음)
- 모든 노드는 서로 연결되어 있음
- 하나의 edge를 끊으면 2개의 sub-tree로 분리됨

#### 이진 트리(Binary Tree)
- 각 노드는 최대 2개의 자식을 가질 수 있음
- 자식 노드는 좌우를 구분함
- <b>종류</b>
  - 포화 이진 트리(Perfect binary tree)
    - 모든 레벨에서 노드들이 꽉채워져 있는 트리
  - 완전 이진 트리(Complete binary tree)
    - 마지막 레벨을 제외하고 노드들이 모두 채워져 있는 트리
  - 정 이진 트리(Full binary tree)
    - 모든 노드가 0개 또는 2개의 자식 노드를 갖는 트리
  - 편향 트리(Skewed binary tree) = 사향 트리
    - 한쪽으로 기울어진 트리
  - 균형 이진 트리(Balanced binary tree)
    - 모든 노드의 좌우 서브 트리 높이가 1이상 차이 나지 않는 트리
- <b>특징</b>
  - 포화 이진 트리의 높이가 h일 때, 노드의 수는 2^(h+1)-1개
  - 포화(or 완전) 이진 트리의 노드가 N개 일 때, 높이는 logN
  - 이진 트리의 노드가 N개 일 때, 최대 가능 높이는 N-1 (0부터 시작)

  ```java
  class Node {
    char data;
    Node left;
    Node right;
    Node parent;

    public Node(char data) {
        this.data = data;
    }

    public Node(char data, Node left, Node right, Node parent) {
        this.data = data;
        this.left = left;
        this.right = right;
        this.parent = parent;
    }
  }
  
  class BinaryTree {
    Node head;

    public BinaryTree(char[] arr) {
        Node[] nodes = new Node[arr.length];
        for (int i = 0; i < nodes.length; i++) {
            nodes[i] = new Node(arr[i]);
        }

        for (int i = 0; i < nodes.length; i++) {
            int left = i * 2 + 1;
            int right = i * 2 + 2;

            if (left < nodes.length) {
                nodes[i].left = nodes[left];
                nodes[left].parent = nodes[i];
            }

            if (right < nodes.length) {
                nodes[i].right = nodes[right];
                nodes[right].parent = nodes[i];
            }
        }

        this.head = nodes[0];
    }

    public Node searchNode(char data) {
        Queue<Node> queue = new LinkedList<>();
        queue.add(this.head);

        while (!queue.isEmpty()) {
            Node cur = queue.poll();
            if (cur.data == data) {
                return cur;
            }

            if (cur.left != null) {
                queue.offer(cur.left);
            }

            if (cur.right != null) {
                queue.offer(cur.right);
            }
        }
        return null;
    }

    public int checkDepth(char data) {
        Node cur = this.searchNode(data);
        int cnt = 0;
        while (cur.parent != null) {
            cur = cur.parent;
            cnt++;
        }
        return cnt;
    }

    public int checkSize(char data) {
        Node node = this.searchNode(data);

        if (node == null) {
            return 0;
        }

        Queue<Node> queue = new LinkedList<>();
        queue.add(node);
        int size = 1;
        while (!queue.isEmpty()) {
            Node cur = queue.poll();

            if (cur.left != null) {
                queue.offer(cur.left);
                size++;
            }

            if (cur.right != null) {
                queue.offer(cur.right);
                size++;
            }
        }
        return size;
    }
  }
  ```

#### 이진 탐색 트리(Binary Search Tree)
- 왼쪽 자식 노드의 키는 부모 노드의 키보다 작음
- 오른쪽 자식 노드의 키는 부모 노드의 키보다 큼
- 각각의 서브 트리도 이진 탐색 트리 유지
- 중복된 키를 허용하지 않음
- 중위 순회를 하면 오름차순 데이터를 얻을 수 있음
- 이진 트리에 비해 탐색 빠름 (균형 유지 필요)
  - 균형 상태 : O(logN)
  - 불균형 상태 : O(N)

- <b>삽입</b>
  1. root부터 비교 시작 (중복 키 발견 시 노드 추가하지 않고 종료)
  2. 삽입할 키가 현재 노드의 키보다 작으면 왼쪽으로 이동
  3. 삽입할 키가 현재 노드의 키보다 크면 오른쪽으로 이동
  4. leaf 노드에 도달 후 키 비교하여 작으면 왼쪽, 크면 오른쪽에  삽입
- <b>삭제</b>
  - 삭제 대상 노드가 leaf 노드인 경우
    1. 삭제 대상 노드 삭제
    2. 부모 노드의 해당 자식 링크 null로 변경
  - 삭제 대상 노드에 자식 노드가 하나 있는 경우
    1. 자식 노드를 삭제 대상 노드의 부모 노드에 연결
    2. 삭제 대상 노드 삭제
  - 삭제 대상 노드에 자식 노드가 둘인 경우
    1. 삭제 대상 노드(cur)의 <under>왼쪽 서브 트리에서 가장 큰 노드</under> or <under>오른쪽 서브 트리에서 가장 작은 노드</under> 선택(successor)
    2. 선택한 노드(successor)를 삭제 대상 노드(cur) 위치로 올림  
    위로 올리는 과정에서 다른 노드들의 링크 연결 작업 진행  
    (아래는 successor를 왼쪽 서브 트리에서 가장 큰 노드로 선택한 경우)
    - 선택한 값(successor)의 부모(predecessor)가 삭제 대상 노드(cur)가 아니라면  
      - predecessor의 오른쪽 자식을 successor의 왼쪽 자식으로 설정  
      - successor의 왼쪽 자식은 cur의 왼쪽 자식으로 설정  
      - succerssor의 오른쪽 자식은 cur의 오른쪽 자식으로 설정
    - 선택한 값의 부모가 삭제 대상 노드라면  
      - successor의 오른쪽 자식을 cur의 오른쪽 자식으로 설정하는 작업만 진행
    - 삭제 대상(cur)의 부모(parent)가 null이라면 head를 successor로 설정
    - 삭제 대상의 부모가 null이 아니라면  
      - parent의 왼쪽 자식이 삭제 대상 노드(cur)였던 경우는 왼쪽 자식에 successor를 넣어주고  
      - parent의 오른쪽 자식이 삭제 대상 노드였던 경우는 오른쪽 자식에 successor를 넣어준다

```java
class BinarySearchTree {
  Node head;

  BinarySearchTree(int key) {
      this.head = new Node(key, null, null);
  }

  public void addNode(int key) {
      if (this.head == null) {
          this.head = new Node(key, null, null);
      } else {
          Node cur = this.head;

          while (true) {
              Node pre = cur;

              if (key == cur.key) {//중복 거르기
                  break;
              }

              if (key < cur.key) {
                  cur = cur.left;

                  if (cur == null) {
                      pre.left = new Node(key, null, null);
                      break;
                  }
              } else {
                  cur = cur.right;

                  if (cur == null) {
                      pre.right = new Node(key, null, null);
                      break;
                  }
              }
          }
      }
  }

  public void removeNode(int key) {
      Node parent = null;//삭제 대상의 부모
      Node successor = null;//삭제 위치로 옮겨질 애
      Node predecessor = null;//successor의 부모
      Node child = null;//successor의 자식

      Node cur = this.head;
      while (cur != null) {
          if (key == cur.key) {
              break;
          }
          parent = cur;
          if (key < cur.key) {
              cur = cur.left;
          } else {
              cur = cur.right;
          }
      }

      if (cur == null) {
          System.out.println("key에 해당하는 노드가 없습니다.");
          return;
      }

      if (cur.left == null && cur.right == null) { // Leaf 노드인 경우
          if (parent == null) {
              this.head = null;
          } else {
              if (parent.left == cur) {
                  parent.left = null;
              } else {
                  parent.right = null;
              }
          }
      } else if (cur.left != null && cur.right == null || cur.left == null && cur.right != null) { 
          // 자식노드가 하나인 경우

          if (cur.left != null) {
              child = cur.left;
          } else {
              child = cur.right;
          }

          if (parent == null) {
              this.head = child;
          } else {
              if (parent.left == cur) {
                  parent.left = child;
              } else {
                  parent.right = child;
              }
          }
      } else {
          // 자식이 둘인 경우 (왼쪽 서브트리에서 가장 큰 값을 올림, 오른쪽 서브트리에서 가장 작은 값을 올려도 됨)

          predecessor = cur;
          successor = cur.left;

          while (successor.right != null) {
              predecessor = successor;
              successor = successor.right;
          }
          
          if (predecessor != cur) {
              predecessor.right = successor.left;
              successor.left = cur.left;
          }
          successor.right = cur.right;

          if (parent == null) {
              this.head = successor;
          } else {
              if (parent.left == cur) {
                  parent.left = successor;
              } else {
                  parent.right = successor;
              }
          }
      }
  }

  public void levelOrder(Node node) {
      Queue<Node> queue = new LinkedList();
      queue.add(node);
      while (!queue.isEmpty()) {
          Node cur = queue.poll();

          System.out.print(cur.key + " ");
          if (cur.left != null) {
              queue.offer(cur.left);
          }

          if (cur.right != null) {
              queue.offer(cur.right);
          }
      }
      System.out.println();
  }

}
```

```java
          return new Node(key, null, null);
      }
      if (key < cur.key) {
          cur.left = addNodeRecursive(cur.left, key);
      } else if (key > cur.key) {//중복 거르기
          cur.right = addNodeRecursive(cur.right, key);
      }

          return null;

      if (key < cur.key) {
          cur.left = removeNodeRecursive(cur.left, key);
      } else if (key > cur.key) {
          cur.right = removeNodeRecursive(cur.right, key);

          if (cur.left == null) {//삭제 대상이 오른쪽 자식만 있거나 leaf 노드인 경우
```

## 💻 Operating System

### Thread
- Light Weight Process
- 하나의 프로세스에 여러 개의 스레드 생성 가능
- 스레드들은 동시에 실행 가능
- 프로세스 안에 있으므로, 프로세스의 데이터를 모두 접근 가능
- 멀티 프로세스는 처음 구조를 잡을 때 만들어야 하지만, 쓰레드는 프로그램의 일부 동작에서만 사용하도록 일부 코드 수정으로 가능하기 때문에 멀티 프로세스보다 쓰레드를 자연스럽게 더 많이 사용함
- 장점
    - 사용자에 대한 응답성 향상
    - 자원 공유 효율 (IPC 안 써도 됨)
- 단점
    - 스레드 중 한 스레드만 문제가 있어도, 전체 프로세스가 영향을 받음
    - 스레드를 많이 생성하면 Context Switching이 많이 일어나 성능 저하됨
    - 동기화 이슈로 비정상적으로 동작 될 수 있음


**동기화 이슈**
- 동기화 : 작업들 사이에 실행 시기를 맞추는 것
- 여러 스레드가 동일한 자원(데이터) 접근 시 동기화 이슈 발생
    -   동일 자원을 여러 스레드가 동시 수정 시, 각 스레드 결과에 영향을 줌
-  해결 방안
    - Mutual exclusion (상호 배제)
        - 쓰레드는 프로세스 모든 데이터를 접근할 수 있으므로 여러 스레드가 변경하는 공유 변수에 대해 Exclusive Access 필요
        - binary semaphore
        - 임계 구역에 하나의 스레드만 들어갈 수 있음
    - Semaphore
        - 임계 구역에 여러 스레드가 들어갈 수 있음
        - counter를 두어 동시에 리소스에 접근할 수 있는 허용 가능한 스레드 수 제어

### 가상 메모리 (Virtual Memory System)

- 메모리가 실제 메모리보다 많아 보이게 하는 기술
- 프로세스 간 공간 분리로, 프로세스 이슈가 전체 시스템에 영향을 주지 않을 수 있음
- 프로세스는 가상 주소(virtual address)를 사용하고, 실제 해당 주소(physical address)에서 데이터를 읽고/쓸 때만 물리 주소로 바꿔줌
- MMU (Memory Management Unit)
    - CPU에 코드 실행 시 가상 주소 메모리 접근이 필요할 때, 해당 주소를 물리 주솟값으로 변환해 주는 하드웨어 장치
    - 하드웨어 장치를 이용해야 주소 변환이 빠르기 때문에 별도 장치를 둠

### 페이징 시스템 (paging system)
- 페이징 : 크기가 동일한 페이지로 가상 주소 공간과 이에 매칭하는 물리 주소 공간을 관리
- 하드웨어 지원이 필요
- 페이지 번호를 기반으로 가상 주소/물리 주소 매핑 정보를 기록/사용
- Page Table에 가상 주소와 물리 주소 간 매핑 정보가 있음
- 가상 주소 v=(p, d)
    - p : 가상 메모리 페이지
    - d : p 안에서 참조하는 위치 

- TLB(Translation Lookaside Buffer) : 페이지 정보 캐시
    - MMU가 물리 주소를 확인하기 위해 메모리를 갔다 와야 하는데 시간이 오래 걸리므로 TLB에 저장해둠
    - TLB를 먼저 확인하고 없으면 메모리로

- 요구 페이징 (Demand Paging or Demanded Paging)
    - 프로세스 모든 데이터를 메모리로 적재하지 않고, 실행 중 필요한 시점에서만 메모리로 적재함
    - 더 이상 필요하지 않은 페이지 프레임은 다시 저장매체에 저장 (페이지 교체 알고리즘 필요)
- 페이지 폴트 (page fault)
    - 어떤 페이지가 실제 메모리에 없을 때 일어나는 인터럽트
- 페이지 교체 정책 (page replacement policy)
    - FIFO : 가장 먼저 들어온 페이지 교체
    - OPT(OPTimal Replacement Algorithm) : 앞으로 가장 오랫동안 사용하지 않을 페이지 교체
        - 일반 OS에서는 구현 불가
    - LRU(Least Recently Used) : 가장 오래전에 사용된 페이지 교체
    - LFU(Least Frequently Used) : 가장 적게 사용된 페이지 교체
    - NUR(Not Used Recently) : 최근에 사용하지 않은 페이지 교체
        - 각 페이지마다 참조 비트(R), 수정 비트(M)을 둠 (R, M)
