## ✏️ 선형 자료구조 (Java)
### 해시 테이블 (HashTable)

- key, value를 대응시켜 저장하는 데이터 구조
  - 키를 통해 해당 데이터에 빠르게 접근 가능
- 해싱
  - 키를 특정 계산식에 넣어 나온 결과를 사용하여 값에 접근하는 과정
- HashMap과 유사, 차이점은? 
  - 동기화 지원 여부
    - HashTable : Thread-safe O (멀티 스레드 환경에서 우수)
    - HashMap : Thread-safe X (싱글 스레드 환경에서 우수)
      - synchronizedMap, ConcurrentHashMap 을 사용하면 Thread-safe 하게 사용 가능
  - Null 값 허용 여부
    - HashTable : key에 null 값  X
    - HashMap : key에 null 값 O
  - Enumeration 여부
    - HashTable : not fail-fast Enumeration 제공
    - HashMap : Enumeration 제공 X
  - HashTable은 구현에 거의 변화가 없지만, HashMap은 현재까지도 지속적으로 개선되고 있다 
  -> HashMap 이용하자 (멀티 스레드 환경에서는 synchronizedMap, ConcurrentHashMap)

- 해시 충돌
  - 서로 다른 키의 해시 함수를 통한 해시 값이 동일한 경우
  - 해결 방법
    - <b>개방 주소법 </b>: 충돌 시, 테이블에서 비어 있는 공간의 hash를 찾아 데이터를 저장, hash와 value가 1:1 매핑
      - 선형 탐사법 : 충돌 발생 지점부터 이후의 빈 공간을 순서대로 탐사
        - 일차 군집화 문제 발생 : 반복된 충돌 발생 시 해당 지점 주변에 데이터가 몰리는 경우 발생
        - `newIdx = (newIdx + 1) % this.table.length;`
      - 제곱 탐사법 : 충돌 발생 지점부터 이후의 빈 공간을 n 제곱 간격으로 탐사
        - 일차 군집화 문제 일부 보완
        - 이차 군집화 문제 발생 가능성
        - `newIdx = (newIdx + (int)Math.pow(2, cnt)) % this.table.length;`
      - 이중 해싱 : 해싱 함수를 이중으로 사용
        - 선형 탐사, 제곱 탐사에 비해 데이터가 골고루 분포됨
        - `newIdx = (newIdx + this.getHash2(newIdx) * cnt) % this.table.length;`
    - <b>분리 연결법</b> 
      - 해시 테이블을 연결 리스트로 구성해서 충돌 발생 시, 테이블 내의 다른 위치를 탐색하는 것이 아닌 연결 리스트를 이용하여 해당 
    테이블에 데이터를 연결  
      - 하나의 키값에 대해 동일한 해시 위치에 여러 데이터가 있을 수 있어 데이터에 접근할 때 상대적으로 오래 걸림

### 연습 문제 14-1
- 1번 어떠한 함수를 거쳐 순서가 달라진 배열을 다시 원래대로 되돌리기
  - 함수를 거쳐서 어떤 규칙으로 값이 옮겨졌는지 판단 후 되돌림
- 2번 행렬의 원소 중 0이 있으면 해당 행과 열 모두 0으로 변경하기
  - 이중 for 문으로 이차원 배열을 돌면서 0을 발견하면 해당 첫 번째 행과 열을 0으로 바꾸고 다시 한번 돌면서 해당 첫 번째 행과 열을 확인해서 둘 중 하나라도 0이면 0으로 바꾸면 된다
  - 첫 번째 행과 열은 따로 첫 번째 행과 열이 원래 0인 값이 있었는지 확인하는 boolean 변수 (firstRowZero,firstColZero)를 두어 위에서 배열을 돌 때 행이나 열이 첫 번째 인지 확인하고 0이면 변숫값을 true로 바꾸고, 나머지를 다 바꾼 뒤 변숫값이 true라면 첫 번째 행 or 0을 전부 0으로 바꿔주면 된다
- 3번 1~N의 N 개의 풍선 터지는 순서 구하기
  - 해당 배열 (1번이면 0번 인덱스) 값으로 이동할 값이 들어 있음 (음수이면 왼쪽으로 양수이면 오른쪽으로 이동)
  - 풍선은 1부터 N까지 정렬되어 있음
  - 1번부터 출력하고 배열에 들어있는 값만큼 이동한 후 해당 배열 인덱스(+1) 출력 반복
  - 강의에서는 연결 리스트로 풀었는데 나는 배열로 한 번 풀어봤다
  - idx 구하는 방법도 바꿔봤다

```java
public static void solution(int[] data) {
  int visitCnt = 0;
  int idx = 0;
  int cmd = 0;
  boolean[] visited = new boolean[data.length];

  while (visitCnt != data.length) {
      idx = (idx + cmd + data.length) % data.length;
      if (visited[idx]) {
          while (visited[idx]) {
              if (cmd < 0) {
                  idx = (idx - 1 + data.length) % data.length;
              } else {
                  idx = (idx + 1) % data.length;
              }
          }
      }

      cmd = data[idx];
      System.out.print(idx + 1 + " ");
      visitCnt++;
      visited[idx] = true;
  }
  System.out.println();
}
```

- 4번 문자열 속 괄호들이 올바른 괄호 짝을 갖고 있는지 확인하기
  - 스택 이용
  - HashMap을 사용해서 괄호 짝을 확인하면 좀 더 편리하다
  - `map.containsKey(s)`로 `(, {, [` 중 하나인지 확인
    - 이 경우엔 그냥 stack에 push 하면 된다
  - `map.containsValue(s)`로 `), }, ]` 중 하나인지 확인
    - 이 경우엔 stack이 empty인지 확인하고 (empty 면 false) empty가 아니라면 stack에서 pop을 해서 그 pop 한 값으로 map에서 값을 얻어와서 이 값이 현재 값이랑 같지 않으면 false
  - 문자열을 다 돌고 나서 false가 아니고 <b>stack이 비어있다면</b> 올바른 괄호짝이다
- 5번은 [뱀](https://www.acmicpc.net/problem/3190){:target="_blank"} 문제였다
  - snake를 큐로 규현하고 뱀이 있는 좌표들을 집어넣으면 된다
  - 좌표값을 ArrayList로 만들어서 넣길래 왜 항상 크기가 2로 고정된 값인데 ArrayList를 썼을까? 생각해 보니 나중에 snake에 포함되는지 확인할 때 contains로 확인하려고 그랬던 것 같다
  - contains로 특정 배열이 포함되어 있는지 비교하면 false가 나온다 (참조 값을 비교하니까..)
  - 그래도 좌표값을 배열로 넣고 싶어서 비교하는 건 for 문으로 직접 비교하기로 하고 배열로 바꿔봤다
  - direction 부분도 굳이 ArrayList로 만들 필요 없이 평소에 하던 대로 했다
    - 처음 오른쪽 방향으로 시작, 시계방향으로 90도 회전하는 순서대로 넣는 것 주의

```java
public static Integer solution(int n, int k, int l, ArrayList<ArrayList> apples, Queue<ArrayList> moves) {
  int time = 0;
  int[][] board = new int[n + 1][n + 1];
  int[] dx = {0, 1, 0, -1};
  int[] dy = {1, 0, -1, 0};
  int dIdx = 0;
  int x = 1;
  int y = 1;
  Queue<int[]> snake = new LinkedList<>();
  snake.add(new int[]{x, y});

  for (ArrayList apple : apples) {
      board[(int) apple.get(0)][(int) apple.get(1)] = 1;
  }

  while (true) {

      time++;
      x += dx[dIdx];
      y += dy[dIdx];

      if (1 <= x && x <= n && 1 <= y && y <= n) {
          for (int[] dot : snake) {
              if (dot[0] == x && dot[1] == y) {
                  return time;
              }
          }
          snake.add(new int[]{x, y});

          if (board[x][y] == 0) {
              snake.poll();
          } else {
              board[x][y] = 0;
          }
      } else {
          return time;
      }


      if (moves.size() > 0 && (int) moves.peek().get(0) == time) {
          if ((char) moves.peek().get(1) == 'D') {
              dIdx = (dIdx + 1) % 4;
          } else {
              dIdx = (dIdx + 3) % 4;
          }
          moves.poll();
      }
  }
}
```
