CustomException

```java
@Getter
public class CustomException extends RuntimeException {
    private final ErrorCode errorCode;
    private final int status;
    private final String errorMessage;

    public CustomException(ErrorCode errorCode) {
        this.errorCode = errorCode;
        this.status = errorCode.getHttpStatus().value();
        this.errorMessage = errorCode.getErrorMessage();
    }
}
```

<b>양방향 연관관계</b>

- 관계형 데이터베이스 테이블은, 서로 일대다 다대일 관계일 때 항상 다(N)쪽에 외래 키가 있다

  - 연관관계 편의 메소드를 생성하는 것 권장
    - 편의 메소드에서는 주인쪽에서 연관관계의 값을 설정할 때, 역방향 값도 함께 설정
    - 메소드를 원자적으로 사용해서 세트로 움직이면 실수 적어짐
  - 무한루프 주의

  - JSON 생성 라이브러리

ProjectTech


- `(mappedBy="techStack")`은 TechStack의 projects 필드가 ProjectTech 엔티티의 techStack 필드에 의해 매핑 되었다는 의미다  
(연관관계의 주인 필드 선택)

- 연관관계를 저장할 때 무한 루프 주의

ProjectTech
```java
public void setProject(Project project) {
    //기존 연관관계 끊어주기
    if (this.project != null) {
        this.project.getProjectTechs().remove(this);
    }
    this.project = project;
    //무한 루프 주의
    if (!project.getProjectTechs().contains(this)) {
        project.addProjectTech(this);
    }
}
```

Project
```java
public void addProjectTech(ProjectTech projectTech) {
    this.projectTechs.add(projectTech);
    //무한 루프 주의
    if (projectTech.getProject() != this) {
        projectTech.setProject(this);
    }
}
```
