### 예외 처리

CustomException

```java
@Getter
public class CustomException extends RuntimeException {
    private final ErrorCode errorCode;
    private final int status;
    private final String errorMessage;

    public CustomException(ErrorCode errorCode) {
        this.errorCode = errorCode;
        this.status = errorCode.getHttpStatus().value();
        this.errorMessage = errorCode.getErrorMessage();
    }
}
```

ErrorCode
```java
@Getter
@RequiredArgsConstructor
public enum ErrorCode {

    NOT_MATCH_MEMBER_PROJECT(HttpStatus.BAD_REQUEST,"해당 게시글에 대한 권한이 없습니다"),
    NOT_FOUND_MEMBER(HttpStatus.BAD_REQUEST,"회원을 찾을 수 없습니다"),
    NOT_FOUND_PROJECT(HttpStatus.BAD_REQUEST,"프로젝트를 찾을 수 없습니다");

    private final HttpStatus httpStatus;
    private final String errorMessage;
}
```

GlobalExceptionHandler

```java
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(CustomException.class)
    public ErrorResponse exceptionHandler(CustomException e){
        log.error("{} is occured",e.getErrorCode());
        return new ErrorResponse(e.getStatus(), e.getErrorCode(),e.getErrorMessage());
    }
}
```

ErrorResponse

```java
@Getter
@Setter
@AllArgsConstructor
@NoArgsConstructor
@Builder
public class ErrorResponse {
    private int status;
    private ErrorCode errorCode;
    private String errorMessage;
}
```

### JPA 
#### 연관관계

<b>다대다 관계</b>

- 연결 테이블용 엔티티 추가 (사실상 연결 테이블을 엔티티로 승격)
  - ProjectTech
  - 독립적으로 generated되는 id 사용 권장
  - 연관관계의 주인

Project(일대다) - ProjectTech(다대일)  - TechStack(일대다)


<b>양방향 연관관계</b>

- 관계형 데이터베이스 테이블은, 서로 일대다 다대일 관계일 때 항상 다(N)쪽에 외래 키가 있다
- 연관관계의 주인은 외래 키가 있는 곳으로 정할 것
- 주의사항
  - 연관관계의 주인에 값을 입력해야 한다
    - 주인이 아닌 mappdBy가 설정 되어있는 Project의 ProjectStack은 조회 권한만 가지고 있고, DB에 영향을 주지 못한다
    - 순수 객체 상태를 고려해서 양쪽에 값을 설정하자
  - 연관관계 편의 메소드를 생성하는 것 권장
    - 편의 메소드에서는 주인쪽에서 연관관계의 값을 설정할 때, 역방향 값도 함께 설정
    - 메소드를 원자적으로 사용해서 세트로 움직이면 실수 적어짐
  - 무한루프 주의
    - lombok이 자동으로 만드는 toString() 사용하지 말자  
  - JSON 생성 라이브러리
    - 컨트롤러에서는 엔티티를 절대 직접 반환 X  
    → DTO로 변환해서 반환

<b>발생한 오류</b>

TechStack (Entity)

```java
@OneToMany(mappedBy = "techStack")
    private List<ProjectTech> projects = new ArrayList<>();
```

ProjectTech

```java
@ManyToOne
@JoinColumn(name = "tech_stack_id")
private TechStack techStack;
```

- `(mappedBy = "techStack")` 이 부분에서 `tech_stack`으로 써서 계속 실행이 제대로 안됐었다
- `(mappedBy="techStack")`은 TechStack의 projects 필드가 ProjectTech 엔티티의 techStack 필드에 의해 매핑 되었다는 의미다

<b> 코드 정리 </b>

```java
public class Project {
    ...

    @OneToMany(mappedBy = "project")
    private List<ProjectTech> techStacks = new ArrayList<>();

    ...
}
```

```java
public class TechStack {
    ...

    @OneToMany(mappedBy = "techStack")
    private List<ProjectTech> projects = new ArrayList<>();

    ...
}
```

```java
public class ProjectTech {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne
    @JoinColumn(name = "project_id")
    private Project project;

    @ManyToOne
    @JoinColumn(name = "tech_stack_id")
    private TechStack techStack;
}
```
