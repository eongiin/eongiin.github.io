- <b>회원가입을 할 때 인증 메일 보내기</b>
  - 인증 코드
    - 인증 코드 10자리 만들기 위해서 `RandomStringUtrils.random` 사용
    - `implementation 'org.apache.commons:commons-lang3:3.12.0'` 추가해줘야 함
  - 이메일 중복 확인
    - 중복이면 `ALREADY_REGISTER_USER` Exception 발생
    - 중복이 아니면 정상적으로 회원 정보 저장하고 이메일 전송
  - 이메일 전송
    ```java
    public String customerSignUp(SignUpForm form) {
        if (signUpCustomerService.isEmailExist(form.getEmail())) {
            throw new CustomException(ALREADY_REGISTER_USER);
        } else {
            Customer c = signUpCustomerService.signUp(form);

            String code = getRandomCode();
            SendMailForm sendMailForm = SendMailForm.builder()
                    .from("tester@ecms.com")
                    .to(form.getEmail())
                    .subject("Verification Email!")
                    .text(getVerificationEmailBody(c.getEmail(), c.getName(), code))
                    .build();

            log.info("Send email result : "
                    + mailgunClient.sendEmail(sendMailForm).getBody());

            signUpCustomerService.changeCustomerValidEmail(c.getId(), code);
            return "회원 가입에 성공하였습니다";
        }
    }
    ```
    - 이메일 보내고 customer 정보에 인증 코드와 만료 날짜 업데이트
    ```java
    @Transactional
    public LocalDateTime changeCustomerValidEmail(Long customerId, String verificationCode) {
        Optional<Customer> customerOptional =
                customerRepository.findById(customerId);

        if (customerOptional.isPresent()) {
            Customer customer = customerOptional.get();
            customer.setVerificationCode(verificationCode);
            customer.setVerifyExpiredAt(LocalDateTime.now().plusDays(1));
            return customer.getVerifyExpiredAt();
        }
        throw new CustomException(NOT_FOUND_USER);
    } 
    ```
- <b>가입한 메일로 받은 이메일 주소와 코드가 담긴 url 접속</b>
- <b>검사 </b>(`SignUpCustomerService - verifyEmail`)
  - 해당 계정이 있는지 먼저 검사
  - 이미 검사 완료된 상태라면 `ALREADY_VERIFY`
  - 인증 코드가 일치하지 않는다면 `WRONG_VERIFICATION`
  - 인증 시간이 만료되었다면 `EXPIRE_CODE`
  - 모두 통과 됐으면 `customer.setVerify(true)`
