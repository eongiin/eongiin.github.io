### 집합

- 교집합 $$ A\cap\; B $$
  - retainAll
  - `집합A.retainAll(집합B)`
  - 집합 A가 집합 A,B의 교집합으로 바뀜

- 합집합 $$A\cup\; B$$
  - addAll
  - `집합A.addAll(집합B)`
  - 집합 A가 집합 A,B의 합집합으로 바뀜

- 차집합 A-B
  - removeAll
  - `집합A.removeAll(집합B)`
  - 집합 A가 집합 A에 대한 B의 차집합(A-B)으로 바뀜

### 순열과 조합

**순열**  

$$ _n P _r  = \frac{n!}{(n-r)!} = n(n-1)(n-2)(n-3)\dots(n-r+1) \; (단, 0<r\leq n)$$


 - 방법 1

```java
static void permutation(int[] arr, int cnt, int n, int r) {
    if (cnt == r) {
        for (int i = 0; i < r; i++) {
            System.out.print(arr[i] + " ");
        }
        System.out.println();
        return;
    }

    for (int i = cnt; i < n; i++) {
        swap(arr, cnt, i);
        permutation(arr, cnt + 1, n, r);
        swap(arr, cnt, i);
    }
}

static void swap(int[] arr, int cnt, int idx) {
    int tmp = arr[cnt];
    arr[cnt] = arr[idx];
    arr[idx] = tmp;
}

public static void main(String[] args) {
    int[] arr = {1, 2, 3, 4};
    permutation(arr, 0, arr.length, 3);
}
```

### 최대공약수와 최소공배수

- 최대공약수 : GCD(Greatest Common Divisor)
- 최소공배수 : LCM(Least Common Multiple)

```java
static int getGCD(int a, int b) {
    if (a % b == 0) {
        return b;
    }
    return getGCD(b, a % b);
}


public static void main(String[] args) {
    int a = 8;
    int b = 12;
    int gcd = getGCD(a, b);
    int lcm = a * b / gcd;
    System.out.printf("%d과 %d의 최대 공약수 : %d 최소 공배수 : %d", a, b, gcd, lcm);
}
```
```
8과 12의 최대 공약수 : 4 최소 공배수 : 24
```

- 4번 행복한 수 만들기  (행복한 수 - 각 자릿수를 제곱한 것을 더하는 과정을 반복했을 때 1로 끝나는 수)
    - 행복한 수가 아니라면 1에 도달하지 못하고 같은 수열이 반복하게 된다 -> 이것은 set으로 처리  
    set.add(값) 했을 때 이미 값이 존재한다면 false를 반환한다 -> while(set.add(n)){}
    - 현재 숫자의 각 자릿수를 제곱한 것의 합을 담을 int 변수(squareSum)를 0으로 초기화하고 현재 값을 10으로 나눈 나머지 (일의 자리)를 제곱하여 squareSum에 더하고 n을 10으로 나눈 값으로 교체하면서 0이 될 때까지 반복한다 -> 각 자릿수의 모든 합을 구할 수 있음
    - 각 자릿수를 더한 값(squareSum)이 1이면 return true, 아니면 n을 squareSum 값으로 바꾸고 위의 과정을 반복한다
    - n 값이 전에 나왔던 값과 같은 값이 나온다면(set.add(값) 할 때 false를 반환한 경우)  
    1에 도달하지 못하고 반복되는 것이므로 return false


    ```java
    public static boolean solution(int n) {
        HashSet<Integer> set =new HashSet<>();
        while(set.add(n)){
            int squareSum=0;
            while(n>0){
                int remain=n%10;
                squareSum+=remain*remain;
                n/=10;
            }
            if(squareSum==1){
                return true;
            }
            n=squareSum;
        }
        return false;
    }
    ```

    ```java
    public static int recursion(int[][] grid, int[][] directions, int i, int j) {
        int row = grid.length;
        int col = grid[0].length;
        
        grid[i][j] = -1;
        int result = 0;
        for (int[] d : directions) {
            int nx = i + d[0];
            int ny = j + d[1];
            if (nx < 0 || ny < 0 || nx >= row || ny >= col || grid[nx][ny] == 0) {
                result++;
            } else {
                if (grid[nx][ny] == 1) {
                    result+= recursion(grid, directions, nx, ny);
                }
            }
        }
        return result;
    }
    ```
