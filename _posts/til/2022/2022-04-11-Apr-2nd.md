### 집합

- 교집합 $$ A\cap\; B $$
  - retainAll
  - `집합A.retainAll(집합B)`

**순열**  

$$ _n P _r  = \frac{n!}{(n-r)!} = n(n-1)(n-2)(n-3)\dots(n-r+1) \; (단, 0<r\leq n)$$


 - 방법 1

~~~java
static void permutation(int[] arr, int cnt, int n, int r) {
    if (cnt == r) {
        for (int i = 0; i < r; i++) {
            System.out.print(arr[i] + " ");
        }
        System.out.println();
        return;
    }

    for (int i = cnt; i < n; i++) {
        swap(arr, cnt, i);
        permutation(arr, cnt + 1, n, r);
        swap(arr, cnt, i);
    }
}

static void swap(int[] arr, int cnt, int idx) {
    int tmp = arr[cnt];
    arr[cnt] = arr[idx];
    arr[idx] = tmp;
}

public static void main(String[] args) {
    int[] arr = {1, 2, 3, 4};
    permutation(arr, 0, arr.length, 3);
}
~~~

### 최대공약수와 최소공배수

- 최대공약수 : GCD(Greatest Common Divisor)
- 최소공배수 : LCM(Least Common Multiple)

```java
static int getGCD(int a, int b) {
    if (a % b == 0) {
        return b;
    }
    return getGCD(b, a % b);
}


public static void main(String[] args) {
    int a = 8;
    int b = 12;
    int gcd = getGCD(a, b);
    int lcm = a * b / gcd;
    System.out.printf("%d과 %d의 최대 공약수 : %d 최소 공배수 : %d", a, b, gcd, lcm);
}
```

    ```java
        HashSet<Integer> set =new HashSet<>();
        while(set.add(n)){
            int squareSum=0;
            while(n>0){
                int remain=n%10;
                squareSum+=remain*remain;
                n/=10;
            }
            if(squareSum==1){
                return true;
            }
            n=squareSum;
        }
        return false;
    ```

    ```java
    public static int recursion(int[][] grid, int[][] directions, int i, int j) {
        int row = grid.length;
        int col = grid[0].length;
        
        grid[i][j] = -1;
        int result = 0;
        for (int[] d : directions) {
            int nx = i + d[0];
            int ny = j + d[1];
            if (nx < 0 || ny < 0 || nx >= row || ny >= col || grid[nx][ny] == 0) {
                result++;
            } else {
                if (grid[nx][ny] == 1) {
                    result+= recursion(grid, directions, nx, ny);
                }
            }
        }
        return result;
    }
    ```

### 연습 문제 2 (1~3)

- 1번 카탈랑 수 구하기
    - 아래 점화식대로 재귀함수로 구현하면 된다

$$ C_0=1, C_{n+1}=\sum_{i=0}^{n} C_iC_{n-i} \;(n\geq0) $$

$$ \begin{align} \\
&C_0=1 \\ 
&C_1=C_0C_0=1 \\ 
&C_2=C_0C_1+C_1C_0=2 \\ 
&C_3=C_0C_2+C_1C_1+C_2C_0=5 \\ 
&C_4=C_0C_3+C_1C_2+C_2C_1+C_3C_0=14 \\ 
&\vdots \\
\end{align} $$



```java
public static int solution(int n) {
    int result=0;
    if(n==0){
        return 1;
    }
    for (int i = 0; i < n; i++) {
        result+= solution(i)*solution(n-1-i);
    }
    return result;
}
```

메모이제이션

```java
static int[] memo;

public static void main(String[] args) {
    int n = 11;
    memo = new int[n + 1];
    System.out.println(recursive(n));
}

public static int recursive(int n) {
    if (memo[n] > 0) {
        return memo[n];
    }
    if (n < 2) {
        return memo[n] = 1;
    }

    for (int i = 0; i < n; i++) {
        memo[n] += recursive(i) * recursive(n - 1 - i);
    }
    return memo[n];
}
```

- 2번 회문, 유사회문 구분하기 (회문 0, 유사회문 1, 기타 2)
    - 회문 또는 팰린드롬(palindrome)은 앞뒤 방향으로 같은 순서의 문자로 구성된 문자열
    - 유사회문 : 한 문자를 삭제하면 회문이 되는 문자열

    - left=0, right=arr.length-1로 시작해서 left >= right가 될 때까지 반복한다
    - left와 right 위치의 값이 일치하지 않는 경우
        - delCnt가 0인 경우(그동안 다 일치한 경우)   
        left+1 혹은 right-1 (문자 하나 삭제) 하고 delCnt의 값을 1로 바꾼 뒤 palindrome 함수를 호출하고 실행한 결괏값을 확인했을 때 여전히 delCnt가 1이라면 한 번 삭제한 것 말고는 전부 일치했다는 말이므로 1을 반환한다  
        함수 호출 결괏값이 1이 아니라면 (일치하지 않는 경우가 또 발생하여 2가 반환된 경우) 2를 반환한다
        - delCnt가 0이 아닌 경우  
        이미 일치하지 않아서 문자 삭제를 한 적이 있는데 또 일치하지 않은 경우가 발생한 것이므로 2를 반환한다 (기타)
    - left와 right 위치의 값이 일치하는 경우  
    left와 right를 1씩 좁혀가며 계속 재귀 함수를 호출하면 된다

    ```java
    public static int solution(String str) {
        return palindrome(0, str.length() - 1, str.toCharArray(), 0);
    }

    public static int palindrome(int left, int right, char[] arr, int delCnt) {
        if (left >= right) {
            return delCnt;
        }

        if (arr[left] != arr[right]) {
            if (delCnt == 0) {
                if (palindrome(left + 1, right, arr, 1) == 1
                        || palindrome(left, right - 1, arr, 1) == 1) {
                    return 1;
                } else {
                    return 2;
                }

            } else {
                return 2;
            }
        }
        left++;
        right--;
        return palindrome(left, right, arr, delCnt);
    }
    ```

- 3번 문자열로 주어진 1차 방정식 풀기
    - 먼저 =를 기준으로 좌변과 우변을 나누고, 계산하는 함수를 만들어 각각 호출한다
    - 함수에서는 다음과 같이 계산한다
        - 문자열에는 '+ - x'만 포함되므로, x의 계수와 상수항을 계산할 값을 담을 int 배열(result)을 만들어 준다  
        result[0]에는 x의 계수, result[1]에는 상수항 값을 담을 예정
        - 문자열을 돌면서 x의 계수 값과 상수항을 계산한다
            - 방법 1 : for 문으로 `char c=s.charAt(i)` 문자 하나하나 접근해서 각 케이스(+, -, x, 숫자)에 맞춰서 계산
            - 방법 2 : 문자열을 정규 표현식을 이용하여 +,- 을 포함하여 나누고 각 케이스에 맞춰서 계산

            ```java
            int[] result = new int[2];

            for (String s : str.split("(?=[+-])")) {
                if (s.equals("+x") || s.equals("x")) {
                    result[0]++;
                } else if (s.equals("-x")) {
                    result[0]--;
                } else if (s.contains("x")) {
                    result[0] += Integer.parseInt(s.substring(0, s.length() - 1));
                } else {//숫자만
                    result[1] += Integer.parseInt(s);
                }
            }
            return result;
            ```

    - 좌변과 우변의 x의 계수가 같고 상수항도 같은 경우 : Infinite solutions
    - 좌변과 우변의 x의 계수만 같고 상수항은 다른 경우 : No solution
    - 나머지 경우는 x의 값이 있는 경우로,` x=(우변의 상수항-좌변의 상수항)/(좌변의 x 계수-우변의 x 계수)` 해주면 된다

    - 재귀로 구현하는 것 연습 필요
    - `recursion(5, (n + 1) / 2) * recursion(4, n / 2) % mod` 호출

    ```java
    public static long recursion(long x, long y) {
        if (y == 0) {
            return 1;
        }
        long p = recursion(x, y / 2);
        return p * p * (y % 2 > 0 ? x : 1) % mod;
    }
    ```

    - [참고](https://st-lab.tistory.com/96){: target="_blank"}

    ```java
    public static void hanoi(int n, int start, int mid, int to) {
        if (n == 1) {

        }

    }
    ```
