##  ✏️ DB

### DDL
<b>Data Definition Language</b>

- CREATE

```sql
CREATE TABLE 회원테이블 (
회원번호 INT NOT NULL AUTO_INCREMENT,
이름 VARCHAR(20),
가입일자 DATETIME NOT NULL,
수신동의 BIT
);
```

- ALTER

```sql
-- 테이블 열 추가
ALTER TABLE 회원테이블 ADD 성별 VARCHAR(2);
-- 테이블 열 데이터 타입 변경
ALTER TABLE 회원테이블 MODIFY 성별 VARCHAR(20);
-- 테이블 열 이름 변경
ALTER TABLE 회원테이블 CHANGE 성별 성 VARCHAR(2);
-- 테이블 이름 변경
ALTER TABLE 회원테이블 RENAME 회원정보;

ALTER TABLE 테이블명 ADD CONSTRAINT PRIMARY KEY pk_테이블명 (칼럼명);
-- 제약조건 삭제
ALTER TABLE 테이블명 DROP PRIMARY KEY;
```
- DROP

```sql
DROP TABLE 회원정보;
```

### DCL
<b> Data Control Language</b>

- 사용자 추가 및 삭제
  - `'userid'@'localhost'`로 생성하면 로컬 호스트에서만 접속 가능
  - `%` 는 외부 접근 모두 허용

```sql
-- 사용자 아이디 및 비밀번호 생성
CREATE USER 'userid'@'host' IDENTIFIED BY 'password';
-- 사용자 비밀번호 변경
SET PASSWORD FOR 'userid'@'host' = 'password';
-- 사용자 삭제
DROP USER 'userid'@'host';
```

- 권한 부여 및 제거

```sql
-- 모든 권한 부여
GRANT ALL ON DB명.테이블명 TO 'userid'@'host';
-- 모든 권한 제거
REVOKE ALL ON DB명.테이블명 FROM 'userid'@'host';
-- 특정 권한 부여
GRANT SELECT,DELETE ON DB명.테이블명 TO 'userid'@'host';
-- 특정 권한 제거
REVOKE DELETE ON DB명.테이블명 FROM 'userid'@'host';
-- 권한 조회
SHOW GRANTS FOR 'userid'@'host';
```

## ✏️ Backtracking

- 모든 경우의 수를 탐색하며 최적해를 구하는 과정에서 유망하지 않은 쪽은 더 이상 구하지 않는 방법
- 유망 (Promising) : 해가 될 가능성이 있는 경우 → 유망하다
- 가지치기 (Pruning) : 해가 될 가능성이 없는 경우 해당 노드를 제외하는 것
- 백트래킹 (Backtracking) : 유망하지 않은 쪽으로 가지 않고 되돌아오는 것

- 11-1
    - 연속된 부분 배열의 합 중 가장 큰 값 구하기
    - 아직 조금 헷갈린다

```java
public static int solution(int[] nums) {
    if (nums == null || nums.length == 0) {
        return 0;
    }
    return divide(nums, 0, nums.length - 1);
}

public static int divide(int[] nums, int left, int right) {
    if (left == right) {
        return nums[left];
    }

    int mid = left + (right - left) / 2;
    int maxLeft = divide(nums, left, mid);
    int maxRight = divide(nums, mid + 1, right);

    int maxArr = getMaxSubArray(nums, left, mid, right);

    return Math.max(maxLeft, Math.max(maxRight, maxArr));
}

public static int getMaxSubArray(int[] nums, int left, int mid, int right) {
    int sumLeft = 0;
    int maxLeft = Integer.MIN_VALUE;

    for (int i = mid; i >= left; i--) {
        sumLeft += nums[i];
        maxLeft = Math.max(maxLeft, sumLeft);
    }

    int sumRight = 0;
    int maxRight = Integer.MIN_VALUE;

    for (int i = mid + 1; i <= right; i++) {
        sumRight += nums[i];
        maxRight = Math.max(maxRight, sumRight);
    }
    return maxLeft + maxRight;
}
```
### 백트래킹

- 15-2
    - n이 주어졌을 때 n 자릿수 중에 아래와 같은 소수를 모두 찾기
        - ex) 7193 → 7, 71, 719, 7193 모두 소수
    - 수정한 부분
        - 두 번째 자리부터는 홀수만 검사하고 5만 따로 `continue` 처리
        - 소수 검사할 때 `Math.sqrt(n)` 까지만

```java
public static ArrayList<Integer> result;

public static ArrayList<Integer> solution(int n) {
    result = new ArrayList<>();

    int[] first = new int[]{2, 3, 5, 7};
    for (int i = 0; i < first.length; i++) {
        backtracking(1, n, first[i]);
    }

    return result;
}

public static void backtracking(int cnt, int n, int making) {
    if (cnt == n) {
        result.add(making);
        return;
    }

    int calc;
    for (int i = 1; i <= 9; i += 2) {
        if (i == 5) {
            continue;
        }
        calc = making * 10 + i;

        if (isPrime(calc)) {
            backtracking(cnt + 1, n, calc);
        }
    }
}

public static boolean isPrime(int n) {
    for (int i = 2; i <= Math.sqrt(n); i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}
```
- 15-3
  - 5지 선다 10문제를 풀 때 5점이 넘는 경우의 수 구하는 문제
  - 연속 3번 같은 정답이 나오는 경우는 없다는 걸 알고 있다

```java
final static int numOfProblems = 10;
final static int PASS = 5;
static int answer;

public static void solution(int[] sols) {
    if (sols == null || sols.length != numOfProblems) {
        return;
    }
    answer = 0;
    backtracking(0, 0, sols, new int[numOfProblems]);
    System.out.println(answer);
}

public static void backtracking(int cnt, int score, int[] sols, int[] my) {
    if (cnt == numOfProblems) {
        if (score >= PASS) {
            answer++;
        }
        return;
    }

    if (score + numOfProblems - cnt < PASS) {
        return;
    }

    int idx = 0;
    if (cnt >= 2 && my[cnt - 2] == my[cnt - 1]) {
        idx = my[cnt - 1];
    }

    for (int i = 1; i <= 5; i++) {
        if (idx == i) {
            continue;
        }
        my[cnt] = i;
        if (my[cnt] == sols[cnt]) {
            backtracking(cnt + 1, score + 1, sols, my);
        } else {
            backtracking(cnt + 1, score, sols, my);
        }
    }
}
```

- 15-4
  - 두 개의 동전이 함께 이동하다가 둘 중 하나만 떨어지는 경우의 최소 이동 횟수 구하기
  - `o`: 동전, `.` : 빈칸, `#` : 벽
  - 수정 & 추가한 부분
    -  배열로 동전 위치 담기
    - 동전 두 개 모두 이동하려는 방향으로 벽이 있는 경우 `continue` 처리

```java
final static int[][] dirs = { {1, 0}, {-1, 0}, {0, 1}, {0, -1} };
static int answer;

public static void solution(char[][] board) {
    if (board == null || board.length == 0 || board[0].length == 0) {
        return;
    }

    answer = Integer.MAX_VALUE;
    int[][] coins = new int[2][2];
    int cnt = 0;

    int n = board.length;
    int m = board[0].length;
    findCoin:
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (board[i][j] == 'o') {
                coins[cnt][0] = i;
                coins[cnt][1] = j;
                cnt++;
            }
            if (cnt == 2) {
                break findCoin;
            }
        }
    }

    move(board, n, m, coins[0][0], coins[0][1], coins[1][0], coins[1][1], 0);
    System.out.println(answer == Integer.MAX_VALUE ? -1 : answer);

}

static void move(char[][] board, int n, int m, int x1, int y1, int x2, int y2, int cnt) {

    if (cnt >= 10) {
        return;
    }

    for (int[] dir : dirs) {
        int drop = 0;

        int nx1 = x1 + dir[0];
        int ny1 = y1 + dir[1];

        int nx2 = x2 + dir[0];
        int ny2 = y2 + dir[1];

        if (nx1 < 0 || nx1 >= n || ny1 < 0 || ny1 >= m) {
            drop++;
        }

        if (nx2 < 0 || nx2 >= n || ny2 < 0 || ny2 >= m) {
            drop++;
        }

        if (drop == 2) {
            continue;
        }

        if (drop == 1) {
            answer = Math.min(answer, cnt + 1);
            return;
        }

        if (board[nx1][ny1] == '#' && board[nx2][ny2] == '#') {
            continue;
        }

        if (board[nx1][ny1] == '#') {
            nx1 = x1;
            ny1 = y1;
        }
        if (board[nx2][ny2] == '#') {
            nx2 = x2;
            ny2 = y2;
        }
        move(board, n, m, nx1, ny1, nx2, ny2, cnt + 1);
    }
}
```
