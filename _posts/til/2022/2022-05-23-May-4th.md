# 23 Mon

##  ✏️ DB

### DDL
<b>Data Definition Language</b>

- CREATE

```sql
CREATE TABLE 회원테이블 (
회원번호 INT NOT NULL AUTO_INCREMENT,
이름 VARCHAR(20),
가입일자 DATETIME NOT NULL,
수신동의 BIT
);
```

- ALTER

```sql
-- 테이블 열 추가
ALTER TABLE 회원테이블 ADD 성별 VARCHAR(2);
-- 테이블 열 데이터 타입 변경
ALTER TABLE 회원테이블 MODIFY 성별 VARCHAR(20);
-- 테이블 열 이름 변경
ALTER TABLE 회원테이블 CHANGE 성별 성 VARCHAR(2);
-- 테이블 이름 변경
ALTER TABLE 회원테이블 RENAME 회원정보;
-- 제약조건 추가
ALTER TABLE 테이블명 ADD CONSTRAINT PRIMARY KEY pk_테이블명 (칼럼명);
-- 제약조건 삭제
ALTER TABLE 테이블명 DROP PRIMARY KEY;
```
- DROP

```sql
DROP TABLE 회원정보;
```
### DML
<b>Data Manipulation Language</b>

- INSERT

`INSERT INTO 테이블명(컬럼1, 컬럼2, ...) VALUES (값1, 값2, ...);`

```sql
INSERT INTO 회원테이블 (이름, 가입일자, 수신동의) VALUES ('eongiin', NOW(), TRUE);
```

- SELECT

```sql
SELECT * FROM 회원테이블;
SELECT 회원번호, 이름 AS 성명 FROM 회원테이블;
```
- UPDATE

```sql
UPDATE 회원테이블 
SET 수신동의 = FALSE, 이름 = 'IIN'
WHERE 이름 = 'eongiin';
```

- DELETE

```sql
DELETE 
FROM 회원테이블
WHERE 이름 = 'eongiin';
```

### DCL
<b> Data Control Language</b>

- 사용자 추가 및 삭제
  - `'userid'@'localhost'`로 생성하면 로컬 호스트에서만 접속 가능
  - `%` 는 외부 접근 모두 허용

```sql
-- 사용자 아이디 및 비밀번호 생성
CREATE USER 'userid'@'host' IDENTIFIED BY 'password';
-- 사용자 비밀번호 변경
SET PASSWORD FOR 'userid'@'host' = 'password';
-- 사용자 삭제
DROP USER 'userid'@'host';
```

- 권한 부여 및 제거

```sql
-- 모든 권한 부여
GRANT ALL ON DB명.테이블명 TO 'userid'@'host';
-- 모든 권한 제거
REVOKE ALL ON DB명.테이블명 FROM 'userid'@'host';
-- 특정 권한 부여
GRANT SELECT,DELETE ON DB명.테이블명 TO 'userid'@'host';
-- 특정 권한 제거
REVOKE DELETE ON DB명.테이블명 FROM 'userid'@'host';
-- 권한 조회
SHOW GRANTS FOR 'userid'@'host';
```

### 기타

나중에 따로 정리하겠다

```sql
SELECT member_type, user_id, name,
  CASE
    WHEN LENGTH(password) > 2 
    THEN CONCAT(SUBSTRING(password,1,2,), '**')
    ELSE ''
  END AS password_mask
FROM member;
```

```sql
select now() as now,
	date_format(now(),'%Y-%m-01') as start_date,
	date_add(date_add(str_to_date(date_format(now(),'%Y-%m-01'), '%Y-%m-%d'), interval 1 month), interval -1 day) as end_date
from dual;
```

```sql
select a.*,
 (row_number() over (order by a.code desc)) as row_index
from actor as a
order by a.code desc
limit 0, 10;
```

## ✏️ Backtracking

- 모든 경우의 수를 탐색하며 최적해를 구하는 과정에서 유망하지 않은 쪽은 더 이상 구하지 않는 방법
- 유망 (Promising) : 해가 될 가능성이 있는 경우 → 유망하다
- 가지치기 (Pruning) : 해가 될 가능성이 없는 경우 해당 노드를 제외하는 것
- 백트래킹 (Backtracking) : 유망하지 않은 쪽으로 가지 않고 되돌아오는 것
