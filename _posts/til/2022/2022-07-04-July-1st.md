### MariaDB 
- 언어셋 설정
    - DB 서버 중지하고 `C:\Program Files\MariaDB 10.6\data` - `my.ini` 아래와 같이 수정
    - [참고](https://nakanara.tistory.com/230){:target="_blank"}

    ```
    [mysqld]
    datadir=C:/Program Files/MariaDB 10.6/data
    port=3306
    innodb_buffer_pool_size=4061M

    init_connect = "SET collation_connection = utf8_general_ci"
    init_connect = "SET NAMES utf8"
    character-set-server = utf8mb4
    collation-server = utf8mb4_general_ci
    skip-character-set-client-handshake

    [client]
    port=3306
    plugin-dir=C:\Program Files\MariaDB 10.6/lib/plugin

    default-character-set = utf8mb4

    [mysqldump]
    default-character-set = utf8mb4

    [mysql]
    default-character-set = utf8mb4
    ```
    - 다시 DB 서버 실행
- minicampus DB 생성하고 전용 계정(minicampus_user) 만들어줌
    
    ```sql
    create database minicampus;
    use mysql;
    create user 'minicampus_user'@'%' identified by 'pw';
    grant all privileges on minicampus.* to 'minicampus_user'@'%' identified by 'pw';

    flush privileges;
    ```
