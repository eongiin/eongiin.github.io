### Test Code
#### 오류 상황

```java
given(projectRepository.save(any()))
                .willReturn(project);
```

1.  willReturn 넣은 project 값이 제대로 안 나오는 상황
  - ProjectService에서 Project를 Project(member,form)으로 만들고 그 project를 save함
  - save 할 때 어떤 project를 넣어도 return은 테스트 코드에서 작성한 project로 나올 것을 기대했는데 그 project가 아닌 form 정보로 만든 project가 반환됨  
    (when 절에서 `projectService.createProject`를 호출하며 넣어준 form 정보)
  - project를 제외한 다른 값들은 willReturn에 넣어준 값들로 잘 나옴 (member, techStack,)
2. 시도해 본 것
  - ~~테스트에서도 willReturn에 넣을 project를 Project(member,form)방식으로 만들어봄 -> 여전히 다른 project 값 나옴~~
  - ~~테스트 코드에 `given(Project.of(any(),any())).willReturn(project)` 추가해 봄 -> NullPointerException~~
3. 해결
  - 디버깅해봤을 때 아무리 생각해도 save 하는 시점전에 project가 먼저 만들어서 변수에 담에 놓는 게 문제 같았다
  - 그런데 생각해 보니까 save 하면 project를 반환하니까 굳이 project를 먼저 만들어서 변수로 빼둔걸 save 하지 말고 바로 save 인자로 집어넣어서 반환값을 변수로 받으면 되는 것이었다..
  - 정말 기본적인.. 것인데 이걸 이렇게 헤맸다
  - `Project project = projectRepository.save(Project.of(member, form));`로 하니 해결됐다
