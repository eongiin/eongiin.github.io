## ✏️ Java
### 연습문제 18-3 (3)
- 주어진 배열에서 기준 값 x와 가장 차이가 적은 값들 k 개를 오름차순으로 출력하는 문제
- HashMap에 key 값으로 차이를 넣고 value로 ArrayList<Integer>를 이용하여 해당 값들을 넣었다
- `map.keySet().stream().min((a,b)->a-b).get()`을 이용하여 key 값 들 중 가장 작은 값부터 먼저 꺼내와서 해당 list를 정렬해 주고 k 개가 될 때까지 결과 list에 추가하는 식으로 풀었다 (마지막에 결과 list 한 번 더 정렬)
- 나중에 알고리즘 수업을 듣고 이 문제를 다시 풀러 오겠다

## ✏️ Java
### 연습문제 18-3 (4,5)

- 4번 문제는 2차원 배열이 주어지고 그 2차원 배열을 나선형 모양으로 출력하는 문제
  - 반복문 네 개로 오른쪽, 아래, 왼쪽, 위 방향으로 이동했을 때 좌표를 각각 출력을 해줘도 되지만  
  나는 출력은 다 똑같은 방식으로 하되 dx {0, 1, 0, -1}, dy {1, 0, -1, 0} 배열을 만들어서 이동방향에 따라 움직일 수 있게 했고 네 꼭짓점에 도달했을 때 방향을 바꿔주고, 꼭짓점 좌표를 옮기는 식으로 문제를 풀었다
- 5번 문제는 물이 담길 수 있는 크기 구하기
  - 나는 또 왼쪽에서 시작해서 같거나 더 큰 벽이 나타나면 구해두었던 크기를 더하는 식으로 문제를 풀었는데, 이것도 양쪽에서 구하면 훨씬 계산을 효율적으로 할 수 있었다
  - 내가 푼 방식으로 하면 같거나 더 큰 벽이 나타나지 않는 경우도 일단 계산을 해서 낭비가 된다
- 드디어 연습문제 풀이가 끝났는데 나중에 다시 풀어보면 좋을 것 같다
