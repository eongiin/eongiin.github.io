## ✏️ Java
### 미니 과제 5
- 사용자로부터 입력받은 날짜에 대한 캘린더 출력 문제
  - `LocalDate date= LocalDate.of(year,month,day);`(day는 1을 넣어줬음)
  - 내게 필요한 건 해당 월이 무슨 요일에 시작하는지, 해당 월 마지막 날이 언제인지였다
    - 위에서 만든 date에 `date.getDayOfWeek()`로 접근하면 시작 요일을 알 수 있고 `.getValue()`까지 붙이면 숫자 값으로 알 수 있다 ( 7 : SUNDAY, 1 : MONDAY, ...)
    - 마지막 날은 `date.lengthOfMonth()`로 알 수 있었다
  
```java
LocalDate date= LocalDate.of(year,month,day);
int start=date.getDayOfWeek().getValue();
int end=date.lengthOfMonth();

System.out.println(String.format("[%d년 %02d월]",year,month));
System.out.println("일\t월\t화\t수\t목\t금\t토");

int cnt=0;
for(int i=0;i<start%WEEK;i++){
    System.out.print("\t");
    cnt++;
}
for(int i=1;i<=end;i++){
    System.out.printf("%02d\t",i);
    cnt++;

    if(cnt%WEEK==0){
        System.out.println();
    }
}
```

### 미니 과제 (6~8)

- 6번 : 가상 대선 당선 시뮬레이션 프로그램
  - 먼저 후보 이름을 가진 배열(candidate)을 만들었고, 후보 별 득표 상황을 알 수 있도록 HashMap(count)을 만들었다
  - `String name = candidate[random.nextInt(4)];` (후보 4명)
  - `count.put(name, count.get(name) + 1);`
  - 2를 02로 표현할 때는 `%02d`를 쓰니까, 0.02도 00.02로 나타내고 싶을 때 `%02.2f`라고 썼더니 적용이 안 돼서 구글링 해보니 02가 아닌 05로 써보라고 나와있었다 `%05.2f`
  - 마지막에 가장 득표수가 많은 사람을 찾아야 하는 상황  
  물론 map을 다 돌면서 가장 큰 값과 그때의 이름을 구하는 방법도 있지만 정렬 기준을 정하고 Collections.max를 이용하여 가장 큰 value 값을 가지고 있는 Entry를 찾았다
```java
Entry<String, Integer> winner = Collections.max(count.entrySet(), new Comparator<Entry<String, Integer>>() {
    @Override
    public int compare(Entry<String, Integer> o1, Entry<String, Integer> o2) {
        return o1.getValue().compareTo(o2.getValue());
    }
});
```
- 7번 : 로또 당첨 프로그램
  - ArrayList로 바꾸지 않고 Set으로만 풀고 싶어서 좀 더 찾아봤다 (전체 로또 리스트를 보관할 때는 ArrayList를 이용했다)
  - TreeSet은 값을 순서대로 보관할 수 있길래 TreeSet을 이용했고 고려해야 했던 것은 다음 2개였다
  - 1.문제에 나와 있는 대로 어떻게 출력할 것인지
    - 처음엔 이 부분 때문에 그냥 ArrayList로 바꿔서 편하게 출력할까 생각했지만  
    ArrayList로 바꿔도 []을 없애고, 매 값마다 `,` 를 붙이고 마지막엔 붙이지 말아야 함+ 한자리 숫자 포맷팅 해야함  
    이 부분에 대해서 더 찾아보다가 stream을 이용해서 할 수 있었다
    - stream을 이용하다 보니 굳이 ArrayList로 바꿀 필요가 없어서 그대로 set으로 진행했고 다음과 같이 출력했다
    - `System.out.println(set.stream().map(x -> String.format("%02d", x)).collect(Collectors.joining(",")));`
  - 2.몇 개 일치하는지
    - 차례로 돌면서 일치하면 cnt++하는 식말고 set과 set사이 교집합을 쉽게 구할 수 없을까하고 찾아보니 set의 메소드 중에 `retainAll`라는 게 있었다
```java
TreeSet<Integer> clone = new TreeSet<>(lottoNum);
clone.retainAll(myLottoList.get(i));
```
    - 이렇게 하면 lottoNum Set을 복사하고 내가 비교하고 싶은 Set을 넣어 retainAll을 하면 boolean 값을 반환하고 저 clone Set에는 두 Set 사이에 겹치는 것만 남게 되는 듯하다  
    그래서 clone.size()로 몇 개 일치하는지 구할 수 있었다

## ✏️ Java
### 미니 과제 제출
- 8번 문제에서 입력을 좀 더 큰 값을 받을 수 있도록 int -> long 수정했고 과제 문제들 대부분이 사용자로부터 값을 입력받는 형식인데 이에 대한 예외 처리 부분을 추가했다  
- 오늘 계속 고민했던 부분은 `String.format("%-10s%d","abcde",22)` 이었다
  - `-`는 왼쪽 정렬이고 `10`은 크기인데 `%-10s`면 저 abcde 문자열을 10 크기를 가지고 출력을 하는 것으로 알고 있다
  - 크기가 10이니까 abcde 뒤에 바로 22가 오지 않고 어느 정도 공백 후에 22가 오게 된다
  - 그런데 여기서 문제는! 길이가 다른 문자열을 맞춰서 출력하고 싶어서 다음과 같이 했는데 예상대로 안 나왔다
  ```java
  System.out.println(String.format("%-15s1111","안녕하세요"));
	System.out.println(String.format("%-15s1111","가나다라마바사"));
  ```
  ![image](https://user-images.githubusercontent.com/90626691/162578500-73218f82-d799-4826-a9b2-870e64e63906.png)
  - 왜 저렇게 나올까? 첫 번째는 글자 5 + 공백 10, 두 번째는 글자 7 + 공백 8 해서 똑같이 크기가 15가 되어야 하지 않나? 똑같은데 글자가 차지하는 칸보다 공백이 차지하는 칸이 작아서 저렇게 보이는 걸까?
  - 일단은 탭으로 처리했다
  ```java
  System.out.println(String.format("%s\t\t1111","안녕하세요"));
	System.out.println(String.format("%s\t1111","가나다라마바사"));
  ```
