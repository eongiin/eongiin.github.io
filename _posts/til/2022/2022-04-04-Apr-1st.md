## ✏️ Java
### 미니 과제 5
- 사용자로부터 입력받은 날짜에 대한 캘린더 출력 문제
  - `LocalDate date= LocalDate.of(year,month,day);`(day는 1을 넣어줬음)
  - 내게 필요한 건 해당 월이 무슨 요일에 시작하는지, 해당 월 마지막 날이 언제인지였다
    - 위에서 만든 date에 `date.getDayOfWeek()`로 접근하면 시작 요일을 알 수 있고 `.getValue()`까지 붙이면 숫자 값으로 알 수 있다 ( 7 : SUNDAY, 1 : MONDAY, ...)
    - 마지막 날은 `date.lengthOfMonth()`로 알 수 있었다
  
```java
LocalDate date= LocalDate.of(year,month,day);
int start=date.getDayOfWeek().getValue();
int end=date.lengthOfMonth();

System.out.println(String.format("[%d년 %02d월]",year,month));
System.out.println("일\t월\t화\t수\t목\t금\t토");

int cnt=0;
for(int i=0;i<start%WEEK;i++){
    System.out.print("\t");
    cnt++;
}
for(int i=1;i<=end;i++){
    System.out.printf("%02d\t",i);
    cnt++;

    if(cnt%WEEK==0){
        System.out.println();
    }
}
```
