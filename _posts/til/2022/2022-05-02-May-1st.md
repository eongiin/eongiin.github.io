## ✏️ 비선형 자료구조 (Java)
### 우선순위 큐
#### 정렬 기준
<b>Comparable</b>
- 자기 자신과 매개변수 객체 비교

```java
static class Person implements Comparable<Person> {
    String name;
    int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    @Override
    public int compareTo(Person o) {
        return this.age - o.age;
    }
}

public static void main(String[] args) {

    String[] name = {"A", "B", "C", "D", "E"};
    int[] age = {30, 20, 45, 62, 35};

    PriorityQueue<Person> pq = new PriorityQueue();

    for (int i = 0; i < name.length; i++) {
        pq.offer(new Person(name[i], age[i]));
    }

    while (!pq.isEmpty()) {
        Person p = pq.poll();
        System.out.println(p.name + " " + p.age);
    }
}
```

<b>Comparator</b>
- 두 매개변수 객체 비교

```java
static class Person {
    String name;
    int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

public static void main(String[] args) {

    String[] name = {"A", "B", "C", "D", "E"};
    int[] age = {30, 20, 45, 62, 35};

    PriorityQueue<Person> pq = new PriorityQueue(new Comparator<Person>() {
        @Override
        public int compare(Person p1, Person p2) {
            return p1.age - p2.age;
        }
    });

    for (int i = 0; i < name.length; i++) {
        pq.offer(new Person(name[i], age[i]));
    }

    while (!pq.isEmpty()) {
        Person p = pq.poll();
        System.out.println(p.name + " " + p.age);
    }
}
```

람다식으로 간단하게

```java
PriorityQueue<Person> pq = new PriorityQueue<>((Person p1, Person p2) -> p1.age - p2.age);
```

모두 age를 기준으로 오름차순 정렬을 하고 있어서 결과는 아래와 같다

```
B 20
A 30
E 35
C 45
D 62
```

<b>정리</b>

- A - B의 결과가 양수면 바꿈, 아니면 (0 or 음수) 그대로
  - 자바에서는 오름차순을 디폴트 기준으로 삼고 있음
  - 이 말은 선행 원소가 후행 원소보다 '작다'라는 뜻
  - 즉, compare 혹은 compareTo를 사용하여 객체를 비교할 경우 음수가 나오면 두 원소의 위치를 바꾸지 않음
- 위와 같이 if문 없이 -로 단순하게 계산하면 오버플로우 위험이 있음
  - 안전하게 하려면 if문으로 처리

  ```java
  @Override
  public int compareTo(Person p) {
      if (this.age>p.age){
          return 1;
      }else if(this.age<p.age){
          return -1;
      }else{
          return 0;
      }
  }
  ```

- 내림차순으로 정렬하려면 A, B위치를 바꿔주면 됨
- 문자열 비교는 `A.compareTo(B)`
- 정렬 기준이 여러개 일 때
  - ex) 정렬 기준 1 : 문자열 길이순, 정렬 기준 2 : 문자열 사전순
  
  ```java
  @Override
  public int compareTo(Person p) {
      if (this.name.length() == p.name.length()) {
          return this.name.compareTo(p.name);
      }
      return this.name.length() - p.name.length();
  }
  ```
  - ex) 정렬 기준 1 : HashMap의 value 값 (내림차순), 정렬 기준 2 : HashMap의 key 값 (오름차순)

  ```java
    PriorityQueue<Map.Entry<Integer, Integer>> pq =
        new PriorityQueue<>((x, y) -> y.getValue() == x.getValue() ?
                x.getKey() - y.getKey() : y.getValue() - x.getValue());  
  ```
