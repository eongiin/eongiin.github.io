- 일단 이렇게 프로젝트 만듦
- 스프링 배치가 실행될 수 있도록 `@EnableBatchProcessing` 어노테이션 붙이기
  - 그래야 테이블들이 정상적으로 생성 됨
- mysql docker에 새로 띄워놓고 demo database 생성
  - `docker run -it --name spring-batch-mysql-test -e MYSQL_ROOT_PASSWORD=1234 -p 3305:3306 -d mysql`
  - `docker exec -it spring-batch-mysql-test bash`
  - `mysql -y root -p`
  - `create database demo;`
```yml
spring:
  datasource:
    url: jdbc:mysql://localhost:3305/demo
    username: root
    password: 1234
    driver-class-name: com.mysql.cj.jdbc.Driver
  batch:
    jdbc:
      initialize-schema: always
    job:
      names: ${job.name:NONE}
```
- initialize-chema는 embedded가 default 인데 always로 해야 수행 됨 
  - 안하면 테이블이 자동생성 안 되는 듯?
  - 그런데 `spring.batch.initialize-schema`는 deprecated 되어서 `spring.batch.jdbc.initialize-schema`로 했는데 되는 것 같으니 일단 진행
- `names: ${job.name:NONE}`
  - job name이 파라미터로 넘어오면 job을 실행하고 넘어오지 않으면 아무것도 실행되지 않는다
- job.enabled=true로 하면 무조건 실행 (default)
  - default가 아닐 떄는 Web Dependency를 추가했을 때나 스케쥴링을 적용했을 때
  - table.prefix나 schema 커스텀하게 수정할 수 있음
    - schema-mysql.sql 일단 여기 있는 테이블 생성 해보자
    - default라 그냥 앱 실행하면 테이블 생성됨

@Bean
public FlatFileItemReader<ArticleModel> createArticleReader() {
    return new FlatFileItemReaderBuilder<ArticleModel>()
            .name("createArticleReader")
            .resource(new ClassPathResource("Articles.csv"))
            .delimited()
            .names("title", "content")
            .fieldSetMapper(new BeanWrapperFieldSetMapper<>())
            .targetType(ArticleModel.class)
            .build();
}

(6) step에 방금 작성한 reader, processor, writer 연결
  - chunk앞에 클래스 타입 설정해줘야 함
    - Processor 부분과 동일하게
  - 아래 코드는 10개씩 끊어 읽음

```java
@Bean
public Step createArticleStep() {
    return stepBuilderFactory.get("createArticleStep")
            .<ArticleModel, Article>chunk(10)
            .reader(createArticleReader())
            .processor(createArticleProcessor())
            .writer(createArticleWriter())
            .build();
}
```

  public void onApplicationEvent(ContextRefreshedEvent event) {
      log.info("Stop running jobs.");
      for (String jobName : jobExplorer.getJobNames()) {
          Set<JobExecution> runningJobExecutions = jobExplorer.findRunningJobExecutions(jobName);

          for (JobExecution jobExecution : runningJobExecutions) {
              jobExecution.setStatus(BatchStatus.STOPPED);
              jobExecution.setEndTime(new Date());
              for (StepExecution stepExecution : jobExecution.getStepExecutions()) {
                  if (stepExecution.getStatus().isRunning()) {
                      stepExecution.setStatus(BatchStatus.STOPPED);
                      stepExecution.setEndTime(new Date());
                      jobRepository.update(stepExecution);
                  }
              }
              jobRepository.update(jobExecution);
              log.info("Update job execution status: {}", jobExecution.getJobId());
          }
      }
      log.info("Stopped running jobs.");
  }
