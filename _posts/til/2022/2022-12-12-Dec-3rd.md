###  [Lv1] Stack
- [같은 숫자는 싫어](https://school.programmers.co.kr/learn/courses/30/lessons/12906){:target="_blank"}
    
```java
import java.util.Stack;
public class Solution {
    public int[] solution(int[] arr) {

        Stack<Integer> stack = new Stack<>();
        stack.push(arr[0]);

        for (int i = 1; i < arr.length; i++) {
            if (stack.peek() == arr[i]) {
                continue;
            }
            stack.push(arr[i]);
        }

        int[] answer = new int[stack.size()];
        for (int i = stack.size() - 1; i >= 0; i--) {
            answer[i] = stack.pop();
        }
        return answer;
    }
}
```
 - 일단 스택으로 한 번 풀어보고 굳이 직접 넣었다 뺐다 하지 않아도 돼서 아래와 같이 수정

```java
import java.util.ArrayList;
import java.util.List;

public class Solution {
    public int[] solution(int[] arr) {

        List<Integer> list = new ArrayList<>();
        int prev = -1;
        for (int num : arr) {
            if (prev == num) {
                continue;
            }
            list.add(num);
            prev = num;
        }

        int[] answer = new int[list.size()];
        for (int i = 0; i < answer.length; i++) {
            answer[i] = list.get(i);
        }
        return answer;
    }
}
```
 - 효율성 테스트 46ms → 22ms

### [Lv2] BFS

- [게임 맵 최단거리](https://school.programmers.co.kr/learn/courses/30/lessons/1844){:target="_blank"}

```java
import java.util.LinkedList;
import java.util.Queue;

public class Solution {

    static int[][] check;
    static int n, m;
    static final int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };

    public int solution(int[][] maps) {

        n = maps.length;
        m = maps[0].length;

        check = new int[n][m];
        check[0][0] = 1;
        bfs(0, 0, maps);
        return check[n - 1][m - 1] == 0 ? -1 : check[n - 1][m - 1];
    }

    private void bfs(int r, int c, int[][] maps) {

        Queue<int[]> q = new LinkedList<>();
        q.offer(new int[]{r, c});

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int cr = cur[0];
            int cc = cur[1];

            for (int[] dir : dirs) {
                int nr = cr + dir[0];
                int nc = cc + dir[1];

                if (nr < 0 || nr >= n || nc < 0 || nc >= m) {
                    continue;
                }

                if (maps[nr][nc] == 0 || check[nr][nc] != 0) {
                    continue;
                }

                check[nr][nc] = check[cr][cc] + 1;
                q.offer(new int[]{nr, nc});
            }
        }
    }
}
```
- 대표적인 BFS 문제

### [Lv3] Heap

- [디스크 컨트롤러](https://school.programmers.co.kr/learn/courses/30/lessons/42627){:target="_blank"}

```java
import java.util.PriorityQueue;

class Solution {

    public int solution(int[][] jobs) {
        PriorityQueue<Job> waitPQ = new PriorityQueue<>((x, y) -> x.call == y.call ? x.time - y.time : x.call - y.call);
        PriorityQueue<Job> readyPQ = new PriorityQueue<>((x, y) -> x.time == y.time ? x.call - y.call : x.time - y.time);

        for (int[] job : jobs) {
            waitPQ.offer(new Job(job[0], job[1]));
        }

        Job first = waitPQ.poll();

        int time = first.call + first.time;
        int sum = time - first.call;

        while (!waitPQ.isEmpty() || !readyPQ.isEmpty()) {
            while (!waitPQ.isEmpty() && waitPQ.peek().call <= time) {
                readyPQ.offer(waitPQ.poll());
            }

            if (readyPQ.isEmpty() && !waitPQ.isEmpty()) {
                readyPQ.offer(waitPQ.poll());
            }

            Job cur = readyPQ.poll();

            if (cur.call > time) {
                time = cur.call;
            }

            time += cur.time;
            sum += time - cur.call;
        }
        return sum / jobs.length;
    }

    class Job {
        int call;
        int time;

        public Job(int call, int time) {
            this.call = call;
            this.time = time;
        }
    }
}
```

        ```java
        import java.util.ArrayList;
        import java.util.List;

        public class Solution {
            static final int[][] STUDENTS = { 
                1, 2, 3, 4, 5}, 
                {2, 1, 2, 3, 2, 4, 2, 5}, 
                {3, 3, 1, 1, 2, 2, 4, 4, 5, 5}
            };

            public int[] solution(int[] answers) {
                List<Integer> list = new ArrayList<>();
                int[] score = new int[3];

                int max = 0;
                for (int i = 0; i < answers.length; i++) {

                    for (int j = 0; j < STUDENTS.length; j++) {
                        if (STUDENTS[j][i % STUDENTS[j].length] == answers[i]) {
                            score[j]++;
                        }
                    }
                }

                for (int j : score) {
                    max = Math.max(max, j);
                }

                for (int i = 0; i < score.length; i++) {
                    if (score[i] == max) {
                        list.add(i + 1);
                    }
                }

                int[] answer = new int[list.size()];
                for (int i = 0; i < answer.length; i++) {
                    answer[i] = list.get(i);
                }
                return answer;
            }
        }
        ```
