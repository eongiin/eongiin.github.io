## 나의 풀이

### 완전 탐색
#### 실패
완전탐색으로 푼 첫 번째 코드  
메모리 초과가 나온다  

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
	static String answer;
	static final int num = 3;

	public static void main(String[] args) throws IOException {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		int n = Integer.parseInt(br.readLine());
		answer = "";
		make(0, n, new StringBuilder());
		System.out.println(answer);
	}

	static void make(int cnt, int n, StringBuilder making) {
		if (!answer.equals(""))
			return;
		if (cnt == n) {
			String made = making.toString();
			if (isGood(made, n)) {
				answer = made;
				return;
			}
			return;
		}

		for (int i = 1; i <= num; i++) {
			make(cnt + 1, n, making.append(i));
			making.deleteCharAt(cnt);
		}
	}

	static boolean isGood(String made, int n) {
		for (int step = 1; step <= n / 2; step++) {
			for (int i = 0; i < n - (step * 2) + 1; i++) {
				if (made.substring(i, i + step).equals(made.substring(i + step, i + step * 2)))
					return false;
			}
		}
		return true;
	}

}

```

### 백트래킹
#### 통과
isGood 호출 시점을 옮기고 미리 검사를 해서 걸러냈더니 통과됐다  

```java
package test;

import org.junit.jupiter.api.Assertions;
import org.junit.jupiter.api.Test;

class Solution {
	static String answer;
	static final int num = 3;

	public String solution(int n) {
		answer = "";
		make(0, n, new StringBuilder());
		return answer;
	}

	void make(int cnt, int n, StringBuilder making) {
		if (cnt == n) {
			answer = making.toString();
			return;
		}

		for (int i = 1; i <= num; i++) {

			if (!isGood(making.append(i).toString(), cnt + 1)) {
				making.deleteCharAt(cnt);
				continue;
			}
			making.deleteCharAt(cnt);
			make(cnt + 1, n, making.append(i));
			if (!answer.equals(""))
				return;
			making.deleteCharAt(cnt);
		}
	}

	boolean isGood(String made, int n) {
		for (int step = 1; step <= n / 2; step++) {
			for (int i = 0; i < n - (step * 2) + 1; i++) {
				if (made.substring(i, i + step).equals(made.substring(i + step, i + step * 2)))
					return false;
			}
		}
		return true;
	}

	@Test
	void test() {
		Assertions.assertEquals("12131231", solution(8));
	}

}
```
## 최종 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
	static final int num = 3;

	public static void main(String[] args) throws IOException {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		int n = Integer.parseInt(br.readLine());
		make(0, n, new StringBuilder());
	}

	static void make(int cnt, int n, StringBuilder making) {

		if (cnt == n) {
			System.out.println(making.toString());
			System.exit(0);
		}

		for (int i = 1; i <= num; i++) {

			if (isGood(making.append(i).toString())) {
				make(cnt + 1, n, making);
			}
			making.deleteCharAt(cnt);
		}
	}

	static boolean isGood(String made) {
		int length = made.length() / 2;

		for (int i = 1; i <= length; i++) {
			if (made.substring(made.length() - i).equals(made.substring(made.length() - 2 * i, made.length() - i))) {
				return false;
			}
		}
		return true;
	}
}

```

가장 먼저 완성된 값이 가장 작은 값이므로 System.exit(0)로 바로 종료한다  

다른 사람들의 코드를 보니 좋은 수열인지 판별하는 함수에서 끝에서 부터 계산을 해서 훨씬 간단하게 풀었길래 참고했다  
만들면서 검사하는 거라 앞에서 부터 전부 검사할 필요 없이 가장 뒷 부분과 그 직전 부분만 개수를 늘려가면서 검사하면 된다
