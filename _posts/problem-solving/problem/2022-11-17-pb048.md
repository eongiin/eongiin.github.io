**문제**  
N×M의 행렬로 표현되는 맵이 있다. 맵에서 0은 이동할 수 있는 곳을 나타내고, 1은 이동할 수 없는 벽이 있는 곳을 나타낸다. 당신은 (1, 1)에서 (N, M)의 위치까지 이동하려 하는데, 이때 최단 경로로 이동하려 한다. 최단경로는 맵에서 가장 적은 개수의 칸을 지나는 경로를 말하는데, 이때 시작하는 칸과 끝나는 칸도 포함해서 센다.

만약에 이동하는 도중에 한 개의 벽을 부수고 이동하는 것이 좀 더 경로가 짧아진다면, 벽을 한 개 까지 부수고 이동하여도 된다.

한 칸에서 이동할 수 있는 칸은 상하좌우로 인접한 칸이다.

맵이 주어졌을 때, 최단 경로를 구해 내는 프로그램을 작성하시오.

**입력**  
첫째 줄에 N(1 ≤ N ≤ 1,000), M(1 ≤ M ≤ 1,000)이 주어진다. 다음 N개의 줄에 M개의 숫자로 맵이 주어진다. (1, 1)과 (N, M)은 항상 0이라고 가정하자.

**출력**  
첫째 줄에 최단 거리를 출력한다. 불가능할 때는 -1을 출력한다.

**예제 입력1**

```
6 4
0100
1110
1000
0000
0111
0000
```

**예제 출력1**

```
15
```

**예제 입력2**

```
4 4
0111
1111
1111
1110
```

**예제 출력2**

```
-1
```

## 나의 풀이
### int[][] visited

- visited 처리 주의
  - 부순 경우와 안 부순 경우의 visted를 같이 할 수 없어서 boolean으로 단순히 체크하면 안 됨
  -  int 중 가장 큰 값으로 모두 초기화하고 나중에 방문할 때 smash 값으로 갱신
    - 벽을 안 부순 경우에는 현재 smash 값 (0이 될 수도 1이 될 수도 있음)
    - 벽을 부순 경우에는 1 (무조건 smash가 0인 경우에서 +1 했으니까)
  - 방문 체크할 때 visited 값이 현재 smash 값보다 큰 경우만 진행
    - 처음 초기화 값이 그대로 남아있는 상태 (아무도 지나가지 않은 경우)
    - 다른 경로에서 한 번 부수고 지나간 적 있지만(1) 현재 경로에서는 부순 적이 없는 상태(0)
      - 후에 다른 곳에서 부수고 더 빨라질 수 있다
- smash - 부순 개수 (0이면 한 번 부술 기회가 남아 있음)

```java
import java.util.Arrays;
import java.util.LinkedList;
import java.util.Queue;

public class Solution {

    int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    int[][] visited;

    public int solution(int n, int m, int[][] map) {

        visited = new int[n][m];
        for (int i = 0; i < n; i++) {
            Arrays.fill(visited[i], Integer.MAX_VALUE);
        }

        Queue<Pos> q = new LinkedList<>();
        q.offer(new Pos(0, 0, 1, 0));

        while (!q.isEmpty()) {
            Pos cur = q.poll();
            visited[0][0] = 0;

            if (cur.r == n - 1 && cur.c == m - 1) {
                return cur.move;
            }

            for (int[] dir : dirs) {
                int nr = cur.r + dir[0];
                int nc = cur.c + dir[1];

                if (nr < 0 || nr >= n || nc < 0 || nc >= m) {
                    continue;
                }
                if (visited[nr][nc] <= cur.smash) {
                    continue;
                }

                if (map[nr][nc] == 0) {
                    visited[nr][nc] = cur.smash;
                    q.offer(new Pos(nr, nc, cur.move + 1, cur.smash));
                } else if (cur.smash == 0) {
                    visited[nr][nc] = 1;
                    q.offer(new Pos(nr, nc, cur.move + 1, cur.smash + 1));
                }
            }
        }
        return -1;
    }

    class Pos {
        int r;
        int c;
        int move;
        int smash;

        public Pos(int r, int c, int move, int smash) {
            this.r = r;
            this.c = c;
            this.move = move;
            this.smash = smash;
        }
    }
}

```

### int[][][] visited

- visited 배열로 중복, 이동 수 동시 처리
- smash - 부순 개수 (0이면 한 번 부술 기회가 남아 있음)
- 메모리, 시간 증가함

```java
import java.util.LinkedList;
import java.util.Queue;

public class Solution {

    int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    int[][][] visited;

    public int solution(int n, int m, int[][] map) {

        visited = new int[n][m][2];

        Queue<Pos> q = new LinkedList<>();
        q.offer(new Pos(0, 0, 0));
        visited[0][0][0] = 1;

        while (!q.isEmpty()) {
            Pos cur = q.poll();
            int r = cur.r;
            int c = cur.c;
            int smash = cur.smash;

            if (r == n - 1 && c == m - 1) {
                return visited[r][c][smash];
            }

            for (int[] dir : dirs) {
                int nr = r + dir[0];
                int nc = c + dir[1];

                if (nr < 0 || nr >= n || nc < 0 || nc >= m) {
                    continue;
                }
                if (visited[nr][nc][smash] > 0) {
                    continue;
                }

                if (map[nr][nc] == 0) {
                    visited[nr][nc][smash] = visited[r][c][smash] + 1;
                    q.offer(new Pos(nr, nc, smash));
                } else if (smash == 0) {
                    visited[nr][nc][smash + 1] = visited[r][c][smash] + 1;
                    q.offer(new Pos(nr, nc, smash + 1));
                }
            }
        }
        return -1;
    }

    class Pos {
        int r;
        int c;
        int smash;

        public Pos(int r, int c, int smash) {
            this.r = r;
            this.c = c;
            this.smash = smash;
        }
    }
}
```

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.LinkedList;
import java.util.Queue;
import java.util.StringTokenizer;


public class Main {

    static int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    static int n;
    static int m;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        char[][] map = new char[n][m];
        for (int i = 0; i < n; i++) {
            map[i] = br.readLine().toCharArray();
        }

        int[][] visited = new int[n][m];
        for (int i = 0; i < n; i++) {
            Arrays.fill(visited[i], Integer.MAX_VALUE);
        }
        System.out.println(bfs(map, visited));
    }

    private static int bfs(char[][] map, int[][] visited) {
        Queue<Pos> q = new LinkedList<>();
        q.offer(new Pos(0, 0, 1, 0));
        visited[0][0] = 0;

        while (!q.isEmpty()) {
            Pos cur = q.poll();

            if (cur.r == n - 1 && cur.c == m - 1) {
                return cur.move;
            }

            for (int[] dir : dirs) {
                int nr = cur.r + dir[0];
                int nc = cur.c + dir[1];

                if (nr < 0 || nr >= n || nc < 0 || nc >= m) {
                    continue;
                }
                if (visited[nr][nc] <= cur.smash) {
                    continue;
                }

                if (map[nr][nc] == '0') {
                    visited[nr][nc] = cur.smash;
                    q.offer(new Pos(nr, nc, cur.move + 1, cur.smash));
                } else if (cur.smash == 0) {
                    visited[nr][nc] = 1;
                    q.offer(new Pos(nr, nc, cur.move + 1, cur.smash + 1));
                }
            }
        }
        return -1;
    }

    static class Pos {
        int r;
        int c;
        int move;
        int smash;

        public Pos(int r, int c, int move, int smash) {
            this.r = r;
            this.c = c;
            this.move = move;
            this.smash = smash;
        }
    }
}
```
