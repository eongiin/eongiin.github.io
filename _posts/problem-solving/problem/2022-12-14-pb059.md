## 문제

<https://school.programmers.co.kr/learn/courses/30/lessons/42579>{:target="_blank"}

**문제 설명**  
스트리밍 사이트에서 장르 별로 가장 많이 재생된 노래를 <b>두 개</b>씩 모아 베스트 앨범을 출시하려 합니다. 노래는 고유 번호로 구분하며, 노래를 수록하는 기준은 다음과 같습니다.

1. 속한 노래가 많이 재생된 장르를 먼저 수록합니다.
2. 장르 내에서 많이 재생된 노래를 먼저 수록합니다.
3. 장르 내에서 재생 횟수가 같은 노래 중에서는 고유 번호가 낮은 노래를 먼저 수록합니다.

노래의 장르를 나타내는 문자열 배열 genres와 노래별 재생 횟수를 나타내는 정수 배열 plays가 주어질 때, 베스트 앨범에 들어갈 노래의 고유 번호를 순서대로 return 하도록 solution 함수를 완성하세요.

**제한사항**  
- genres[i]는 고유번호가 i인 노래의 장르입니다.
- plays[i]는 고유번호가 i인 노래가 재생된 횟수입니다.
- genres와 plays의 길이는 같으며, 이는 1 이상 10,000 이하입니다.
- 장르 종류는 100개 미만입니다.
- 장르에 속한 곡이 하나라면, 하나의 곡만 선택합니다.
- 모든 장르는 재생된 횟수가 다릅니다.

## 나의 풀이

- 장르별 통합으로도 정렬을 해야 하고 장르 안에서도 정렬해서 높은 수 2개를 구해야 함
  - HashMap 두 개 생성
    - `Map<String, List<int[]>> each` 장르 별 노래 리스트 
    - `Map<String, Integer> total` 장르 별 모든 노래 재생 수의 합
- 해당 점수를 가진 고유 번호도 같이 저장해둬야 함
  - `each`에서 장르별로 리스트를 가지고 있고, 리스트에는 `{고유번호, 점수}` 형태로 int 배열을 갖도록 함
- genres, plays 배열을 순서대로 돌면서 위의 구조에 맞게 정보 저장
- 가장 많이 재생된 장르가 먼저 와야하므로 `total` map을 `value`를 기준으로 내림차순 정렬
  
  ```java
  List<Map.Entry<String, Integer>> entryList = new ArrayList<>(total.entrySet());
  entryList.sort((x, y) -> total.get(y.getKey()) - total.get(x.getKey()));
  ```
- 정렬된 리스트를 돌면서 key 값으로 `each` map에서 해당 장르인 노래들의 리스트를 가져옴
- 이 노래 리스트에서도 가장 많이 재생된 것 2개를 구해야 하므로 정렬을 해줌
  - 정렬 기준 : 1. 재생 수 내림차순 2. 고유 번호 오름차순
- 리스트를 배열로 바꾸고 반환

```java
import java.util.*;

public class Solution {

    public int[] solution(String[] genres, int[] plays) {
        Map<String, List<int[]>> each = new HashMap<>();
        Map<String, Integer> total = new HashMap<>();

        for (int i = 0; i < genres.length; i++) {
            if (!each.containsKey(genres[i])) {
                each.put(genres[i], new ArrayList());
            }
            each.get(genres[i]).add(new int[]{i, plays[i]});
            total.put(genres[i], total.getOrDefault(genres[i], 0) + plays[i]);
        }

        List<Map.Entry<String, Integer>> entryList = new ArrayList<>(total.entrySet());
        entryList.sort((x, y) -> total.get(y.getKey()) - total.get(x.getKey()));

        List<Integer> list = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : entryList) {
            String key = entry.getKey();
            List<int[]> songs = each.get(key);
            Collections.sort(songs, (x, y) -> y[1] == x[1] ? x[0] - y[0] : y[1] - x[1]);

            int max = songs.get(0)[1];
            int cnt = 0;
            for (int i = 0; i < songs.size(); i++) {
                if (cnt >= 2 && songs.get(i)[1] < max) {
                    break;
                }
                list.add(songs.get(i)[0]);
                cnt++;
            }
        }

        int[] answer = new int[list.size()];
        for (int i = 0; i < answer.length; i++) {
            answer[i] = list.get(i);
        }
        return answer;
    }
}
```
