**문제**  
N(2 ≤ N ≤ 10,000)개의 섬으로 이루어진 나라가 있다. 이들 중 몇 개의 섬 사이에는 다리가 설치되어 있어서 차들이 다닐 수 있다.

영식 중공업에서는 두 개의 섬에 공장을 세워 두고 물품을 생산하는 일을 하고 있다. 물품을 생산하다 보면 공장에서 다른 공장으로 생산 중이던 물품을 수송해야 할 일이 생기곤 한다. 그런데 각각의 다리마다 중량제한이 있기 때문에 무턱대고 물품을 옮길 순 없다. 만약 중량제한을 초과하는 양의 물품이 다리를 지나게 되면 다리가 무너지게 된다.

한 번의 이동에서 옮길 수 있는 물품들의 중량의 최댓값을 구하는 프로그램을 작성하시오.

**입력**  
첫째 줄에 N, M(1 ≤ M ≤ 100,000)이 주어진다. 다음 M개의 줄에는 다리에 대한 정보를 나타내는 세 정수 A, B(1 ≤ A, B ≤ N), C(1 ≤ C ≤ 1,000,000,000)가 주어진다. 이는 A번 섬과 B번 섬 사이에 중량제한이 C인 다리가 존재한다는 의미이다. 서로 같은 두 섬 사이에 여러 개의 다리가 있을 수도 있으며, 모든 다리는 양방향이다. 마지막 줄에는 공장이 위치해 있는 섬의 번호를 나타내는 서로 다른 두 정수가 주어진다. 공장이 있는 두 섬을 연결하는 경로는 항상 존재하는 데이터만 입력으로 주어진다.

**출력**  
첫째 줄에 답을 출력한다.

**예제 입력**  
```
3 3
1 2 2
3 1 3
2 3 2
1 3
```
**예제 출력**  
```
3
```

### 틀린 코드(메모리 초과, 오답)
#### 인접 행렬 (완전탐색) - 메모리 초과
```java
import java.util.LinkedList;
import java.util.Queue;

public class Solution {
    int answer;

    public int solution(int n, int m, int[][] bridge, int start, int end) {

        answer = Integer.MIN_VALUE;
        int[][] graph = new int[n + 1][n + 1];

        for (int i = 0; i < m; i++) {
            int a = bridge[i][0];
            int b = bridge[i][1];
            int cost = bridge[i][2];

            graph[a][b] = graph[b][a] = Math.max(graph[a][b], cost);
        }
        bfs(start, end, graph, new boolean[n + 1]);
        return answer;
    }

    public void bfs(int start, int end, int[][] graph, boolean[] visited) {

        Queue<int[]> q = new LinkedList<>();
        q.offer(new int[]{start, Integer.MAX_VALUE});
        visited[start] = true;
        boolean find = false;
        
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int next = cur[0];
            int cost = cur[1];

            if (next == end) {
                answer = Math.max(answer, cost);
                find = true;
                continue;
            }

            for (int i = 1; i < graph.length; i++) {
                if (graph[next][i] > 0 && !visited[i]) {
                    if (find && graph[next][i] <= answer) {
                        continue;
                    }
                    visited[i] = true;
                    q.offer(new int[]{i, Math.min(cost, graph[next][i])});
                }
            }
        }
    }
}
```

```java
public class Solution2 {
    int answer;

    public int solution(int n, int m, int[][] bridge, int start, int end) {

        answer = Integer.MIN_VALUE;

        ArrayList<Node>[] graph = new ArrayList[n + 1];

        for (int i = 1; i <= n; i++) {
            graph[i] = new ArrayList();
        }
        for (int i = 0; i < m; i++) {

            int a = bridge[i][0];
            int b = bridge[i][1];
            int cost = bridge[i][2];

            graph[a].add(new Node(b, cost));
            graph[b].add(new Node(a, cost));

        }
        bfs(start, end, graph, new boolean[n + 1]);
        return answer;
    }

    public void bfs(int start, int end, ArrayList<Node>[] graph, boolean[] visited) {

        PriorityQueue<Node> pq = new PriorityQueue<>();
        pq.offer(new Node(start, Integer.MAX_VALUE));
        visited[start] = true;
        boolean find = false;


        while (!pq.isEmpty()) {
            Node cur = pq.poll();
            int num = cur.num;
            int cost = cur.cost;

            if (num == end) {
                answer = Math.max(answer, cost);
                find = true;
                continue;
            }

            for (Node next : graph[num]) {
                if (visited[next.num]) {
                    continue;
                }
                if (find && next.cost <= answer) {
                    continue;
                }
                visited[next.num] = true;
                pq.offer(new Node(next.num, Math.min(next.cost, cur.cost)));
            }
        }
    }

    class Node implements Comparable<Node> {
        int num;
        int cost;

        public Node(int num, int cost) {
            this.num = num;
            this.cost = cost;
        }

        @Override
        public int compareTo(Node o) {
            return o.cost - this.cost;
        }
    }
}
```

#### 인접 행렬 (이진 탐색) - 메모리 초과
```java
import java.util.LinkedList;
import java.util.Queue;

public class Solution {

    public int solution(int n, int m, int[][] bridge, int start, int end) {

        int[][] graph = new int[n + 1][n + 1];

        int max = 0;
        for (int i = 0; i < m; i++) {
            int a = bridge[i][0];
            int b = bridge[i][1];
            int cost = bridge[i][2];

            graph[a][b] = graph[b][a] = Math.max(graph[a][b], cost);
            max = Math.max(max, cost);
        }

        return binarySearch(graph, max, start, end);
    }


    public int binarySearch(int[][] graph, int rIdx, int start, int end) {
        int left = 1;
        int right = rIdx;

        while (left <= right) {
            int mid = (left + right) / 2;
            if (bfs(graph, start, end, mid)) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return right;
    }

    public boolean bfs(int[][] graph, int start, int end, int limit) {
        boolean[] visited = new boolean[graph.length];

        Queue<Integer> q = new LinkedList<>();
        q.offer(start);
        visited[start] = true;

        while (!q.isEmpty()) {
            int cur = q.poll();

            if (cur == end) {
                return true;
            }

            for (int next = 1; next < graph.length; next++) {
                int cost = graph[cur][next];
                if (cost > 0 && cost >= limit && !visited[next]) {
                    visited[next] = true;
                    q.offer(next);
                }
            }
        }
        return false;
    }
}
```

```java
    public int solution(int n, int m, int[][] bridge, int start, int end) {

            } else {
                right = mid - 1;
            }
```
