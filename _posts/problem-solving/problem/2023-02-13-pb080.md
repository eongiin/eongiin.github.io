**문제**  
수빈이는 동생과 숨바꼭질을 하고 있다. 수빈이는 현재 점 N(0 ≤ N ≤ 100,000)에 있고, 동생은 점 K(0 ≤ K ≤ 100,000)에 있다. 수빈이는 걷거나 순간이동을 할 수 있다. 만약, 수빈이의 위치가 X일 때 걷는다면 1초 후에 X-1 또는 X+1로 이동하게 된다. 순간이동을 하는 경우에는 1초 후에 2*X의 위치로 이동하게 된다.

수빈이와 동생의 위치가 주어졌을 때, 수빈이가 동생을 찾을 수 있는 가장 빠른 시간이 몇 초 후인지 그리고, 가장 빠른 시간으로 찾는 방법이 몇 가지 인지 구하는 프로그램을 작성하시오.

**입력**  
첫 번째 줄에 수빈이가 있는 위치 N과 동생이 있는 위치 K가 주어진다. N과 K는 정수이다.

**출력**  
첫째 줄에 수빈이가 동생을 찾는 가장 빠른 시간을 출력한다.

둘째 줄에는 가장 빠른 시간으로 수빈이가 동생을 찾는 방법의 수를 출력한다.

**예제 입력**

```
5 17
```

**예제 출력**

```
4
2
```

### bfs

- n>k인 경우는 무조건 x-1 해서 가는 경우밖에 없으므로 바로 시간은 n-k , 방법은 1 반환
    - n==k인 경우에는 무조건 시간 0, 방법 1이므로 n>=k로 같이 계산해 줌
- 방문 확인 배열 visited를 LIMIT 크기로 만들어 줌
    - 여기서 LIMIT은 k+2로 설정
    - x*2로 k를 넘어선다 해도 k+1에서 x-1 하는 경우만 유효하므로 그 이후는 고려하지 않음
- 방문 체크는 int로 해서 그 위치에 도달했을 때 시간을 체크하도록 함
    - 이미 방문했던 곳이라도 같은 시간에 도달했으면 답이 될 수 있는 다른 경로이므로
    - visited[i]에는 무조건 i에 도달하는 최소 시간이 담기게 됨
- Queue에 다음에 방문할 위치와, 도달할 때의 시간을 담은 Pos 클래스를 넣음
- n에서부터 시작하여 처음으로 k에 도착했을 때 정답을 담을 time 변수를 현재 시간으로 갱신
    - 이후에 k에 도달했을 때 time 변수와 현재 시간이 같다면 방법+1
- 답이 될 수 없는 경우를 미리미리 제외해 줌
    - k에 도달한 적이 있어서 최소 시간이 구해진 경우에, 현재 k가 아닌데 이미 시간이 time을 넘어섰다면 무조건 최소 시간이 될 수 없으므로 제외
        - `time != 0 && cur.time >= time`
    - 방문한 적이 있는 곳인데, visited[]에 있는 방문 시간이 현재 확인하는 경로에서 도달하는 시간과 다른 경우 제외
        - `visited[next] != 0 && visited[next] != cur.time + 1`
        - 방문한 적이 있다면 그 위치에 최소 시간으로 도달한 경우의 시간이 담겨있을 텐데 그 시간과 같지 않다면 무조건 더 느린 경우임
    - 다음에 방문하는 위치가 유효한 범위를 벗어나는 경우 제외
        - `next < 0 || next >= limit`


```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.LinkedList;
import java.util.Queue;
import java.util.StringTokenizer;

public class Main {

    static int cnt;
    static int time;
    static int limit;

    public static void main(String[] args) throws IOException {

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());
        cnt = 0;
        time = 0;
        limit = k + 2;
        bfs(n, k);
        StringBuilder sb = new StringBuilder();
        sb.append(time).append("\n").append(cnt);
        System.out.println(sb);
    }

    static void bfs(int n, int k) {

        if (n >= k) {
            cnt = 1;
            time = n - k;
            return;
        }

        int[] visited = new int[limit];
        Queue<Pos> q = new LinkedList<>();
        q.offer(new Pos(n, 0));
        visited[n] = 1;

        while (!q.isEmpty()) {
            Pos cur = q.poll();

            if (cur.location == k) {
                if (cnt == 0) {
                    time = cur.time;
                }

                if (time == cur.time) {
                    cnt++;
                }
                continue;
            }

            if (time != 0 && cur.time >= time) {
                continue;
            }

            int[] nextList = {cur.location - 1, cur.location + 1, cur.location * 2};

            for (int next : nextList) {

                if (next < 0 || next >= limit) {
                    continue;
                }
                if (visited[next] != 0 && visited[next] != cur.time + 1) {
                    continue;
                }

                visited[next] = cur.time + 1;
                q.offer(new Pos(next, cur.time + 1));
            }
        }
    }

    static class Pos {
        int location;
        int time;

        public Pos(int location, int time) {
            this.location = location;
            this.time = time;
        }
    }
}
```

### dp

- n<=k인 경우는 바로 반환
- 시간(time)과 방법(cnt)에 대한 배열을 각각 k+1 크기로 만들어줌
- [0, n] 범위에 대해서는 시간 n-i, 방법 1
    - `cnt[n] = 1` 빠뜨리지 말 것
- time[i]에는 i 지점에 도달했을 때 `x+1`로 온 경우와 `x*2` 혹은 `x*2-1`로 온 경우 중에서 더 작은 값을 넣음
    - `x+1`인 경우는 time[i-1]+1
    - i가 짝수인 경우(`x*2`)
        - 어떤 수에 *2를 해서 i가 되었다는 것이니까 i/2 위치였을 때 시간에서 +1
        - `time[i >> 1] + 1`
    - i가 홀수인 경우(`x*2-1`)
        - 어떤 수에 *2를 한 후 -1을 해서 i가 되었다는 것이니까 (i+1)/2 위치였을 때 시간에서 +2
            - 2배 하는 시간과 한 칸 이동하는 시간을 모두 계산해야 하므로 +2
        - `time[ (i+1) >> 1] + 2` 
- *2를 사용하는 경우 먼저 계산해서 넣은 다음에 +1로 오는 경우와 비교해서 더 작은 값 저장  
(순서는 바꿔도 됨)
- i & 1 이 0이면 짝수 1이면 홀수를 의미
- cnt[i]는 예를 들어 +1로 i에 도달하는 경우가 최소 시간이라고 했을 때는 cnt[i-1] 값을 넣어주면 됨
    - i-1에서 +1로 i에 간다면 방법의 개수는 i-1와 i가 같을 테니까
- 다만 +1로 i에 도달하는 경우와 *2를 사용하여 i에 도달하는 경우의 시간이 같을 때는 두 경우의 방법이 모두 최소가 된다는 것이므로 cnt[i-1] 와 (cnt[ i >> 1] 혹은 cnt [(i+1)>>1])를 더해줌


```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());
        solution(n, k);
    }

    static void solution(int n, int k) {
        StringBuilder sb = new StringBuilder();
        if (n >= k) {
            sb.append(n - k).append("\n").append(1);
            System.out.println(sb);
            return;
        }
        int[] time = new int[k + 1];
        int[] cnt = new int[k + 1];

        for (int i = 0; i <= n; i++) {
            time[i] = n - i;
            cnt[i] = 1;
        }

        for (int i = n + 1; i <= k; i++) {

            if ((i & 1) == 0) {
                time[i] = time[i >> 1] + 1;
                cnt[i] = cnt[i >> 1];
            } else {
                time[i] = time[(i + 1) >> 1] + 2;
                cnt[i] = cnt[(i + 1) >> 1];
            }

            int left = time[i - 1] + 1;
            if (time[i] > left) {
                time[i] = left;
                cnt[i] = cnt[i - 1];
            } else if (time[i] == left) {
                cnt[i] += cnt[i - 1];
            }
        }

        sb.append(time[k]).append("\n").append(cnt[k]);
        System.out.println(sb);
    }
}
```
