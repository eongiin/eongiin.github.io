```java
public class Solution {
    public String solution(String input_string) {
        int[] alphaCheck = new int[26];
        int strIdx = 0;
        int arrIdx = 0;
        while (strIdx < input_string.length()) {
            arrIdx = input_string.charAt(strIdx) - 'a';
            alphaCheck[arrIdx]++;
            strIdx++;
            while ((strIdx < input_string.length()) && input_string.charAt(strIdx - 1) == input_string.charAt(strIdx)) {
                strIdx++;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < alphaCheck.length; i++) {
            if (alphaCheck[i] > 1) {
                sb.append(Character.toChars('a' + i));
            }
        }

        return sb.length() == 0 ? "N" : sb.toString();
    }
}
```

```java
import java.util.HashSet;
import java.util.Iterator;

public class Solution {
    public String solution(String input_string) {
        Set<Character> set = new HashSet<>();
        Set<Character> alone = new HashSet<>();
        char top = 'Z';
        for (Character c : input_string.toCharArray()) {
            if (!set.add(c)) {
                if (top != c) {
                    alone.add(c);
                }
            }
            top = c;
        }


        char[] answer = new char[alone.size()];
        Iterator iter = alone.iterator();
        int idx = 0;
        while (iter.hasNext()) {
            answer[idx++] = (char) iter.next();
        }
        Arrays.sort(answer);
        return answer.length == 0 ? "N" : new String(answer);
    }
}
```

## 2번 (Backtracking)

### 나의 풀이
- n 명의 사람 중에서 r 개의 종목 대표 뽑기 (중복 x)

```java
public class Solution {
    int maxSum;
    boolean[] visited;
    int[][] ability;

    public int solution(int[][] ability) {
        int student = ability.length;
        int sport = ability[0].length;
        maxSum = 0;
        visited = new boolean[student];
        this.ability = ability;

        perm(0, student, sport, new int[sport]);
        return maxSum;
    }

    private void perm(int cnt, int student, int sport, int[] making) {
        if (cnt == sport) {
            maxSum = Math.max(maxSum, getSum(making));
            return;
        }

        for (int i = 0; i < student; i++) {
            if (visited[i]) {
                continue;
            }
            visited[i] = true;
            making[cnt] = i;
            perm(cnt + 1, student, sport, making);
            visited[i] = false;
        }
    }

    private int getSum(int[] result) {
        int sum = 0;
        for (int i = 0; i < result.length; i++) {
            sum += ability[result[i]][i];
        }
        return sum;
    }
}

```

## 3번 (재귀)
- 🌻🌼

<https://school.programmers.co.kr/learn/courses/15008/lessons/121685>{:target="_blank"}

### 나의 풀이

- n이 1인 경우 바로 `Rr` 넣음
- 재귀로 부모를 구함 (최종은 2세대의 `RR`,`Rr`,`Rr`,`rr` 중 하나)
- 한 단계씩 위로 올라가면서 `RR`이나 `rr` 위치에 해당하지 않는지 체크해서 `top`에 저장해 놓음
    - 맨 마지막 위치(가장 위)만 가지고 있으면 됨
- 구한 부모가 `RR` or `rr`이면 무조건 그대로 따라감
- `Rr`인 경우면 `top`이 -1인지 아닌지 확인
    - `top`이 -1인 경우 (부모 중에 RR이나 rr인 경우가 없는 경우)
        - p%4 해서 해당 위치에 해당하는 문자 그대로 출력

    - `top`이 -1이 아닌 경우 (부모 중에 `RR`이나 `rr`이 있는 경우)
        - 가장 위에 있는 `RR` 혹은 `rr` 을 기억해 둔 `top`정보를 바탕으로 그 위치에 해당하는 문자 그대로 출력
            - 부모 중에 `RR`이나 `rr`이 있다는 것은 그 아래는 모두 그 문자일 테니까
        - top==0 : rr
        - top==1 : RR
- 답 문자를 저장할 때 배열 순서에 맞게 조정해 주는 작업 추가
    - 첫 번째는(`RR`) 배열의 0번째이므로 +3 하고 4로 나눠줌

```java
class Solution {
    static final String[] type = {"RR", "Rr", "Rr", "rr"};
    int top;

    public String[] solution(int[][] queries) {
        int num = queries.length;
        String[] answer = new String[num];

        for (int i = 0; i < num; i++) {
            int n = queries[i][0];
            int p = queries[i][1];

            if (n == 1) {
                answer[i] = "Rr";
                continue;
            }
            top = -1;
            int parent = (recur(n, p) + 3) % 4;
            if (parent == 0 || parent == 3) {
                answer[i] = type[parent];
            } else {
                if (top != -1) {
                    answer[i] = type[(top + 3) % 4];
                } else {
                    answer[i] = type[((p % 4) + 3) % 4];
                }

            }
        }
        return answer;
    }

    private int recur(int n, int p) {
        if (p % 4 == 1 || p % 4 == 0) {
            top = p % 4;
        }
        if (n == 2) {
            return p;
        }
        return recur(n - 1, (p + 3) / 4);
    }
}
```

## 4번 (Priority Queue)
- 🌻🌼

<https://school.programmers.co.kr/learn/courses/15008/lessons/121686>{:target="_blank"}

### 나의 풀이
- 아무것도 안 하고 있을 때는 시간이 더 빠른 걸 먼저 처리해야 하고, 현재 시각에 할 수 있는 프로그램이 여러 개면 점수가 높은 프로그램을 먼저 처리해야 해서 PQ를 두 개 만듦
    - timePQ : 정렬 기준 - 시간이 더 빠른 것
    - scorePQ : 정렬 기준 - 점수가 더 높은 것
- 먼저 전부 timePQ에 넣고 맨 처음 프로그램을 무조건 실행
    - 현재 시각(time)은 프로그램 실행 시작 시각 + 프로그램 실행 시간으로 설정
- 두 큐 가 완전히 빌 때까지 아래 과정 반복
    - 현재 시각보다 호출 시간이 작은 것들을 모두 빼서 scorePQ에 넣음
        - 실행할 수 있는 프로그램이 여러 개면 점수가 높은 것부터 계산해야 하므로
    - 현재 시각에 실행할 수 있는 게 없다면 가장 호출 시간 빠른 거 빼서 scorePQ에 넣음
        - 무조건 scorePQ에 하나 이상 들어가 있는 상태로 만들어야 함
    - 우선순위에  따라 나오는 프로그램의 호출 시각과 현재 시각(time) 비교
        - 현재 시각이 호출 시각보다 이르다면 시간을 호출 시각에 맞춤
        - 현재 시각이 호출 시각을 지나쳤다면 그 차이만큼 지연 시간 계산
    - 현재 시각에 방금 실행한 프로그램의 실행 시간을 더함
- 마지막 현재 시각(time) 값이 모든 프로그램의 종료 시각이 됨


```java
import java.util.PriorityQueue;

class Solution {
    static final int MAX = 10;

    public long[] solution(int[][] program) {
        long[] answer = new long[11];
        PriorityQueue<Program> timePQ = new PriorityQueue<>((x, y) -> x.call == y.call ? x.score - y.score : x.call - y.call);
        PriorityQueue<Program> scorePQ = new PriorityQueue<>((x, y) -> x.score == y.score ? x.call - y.call : x.score - y.score);
        for (int[] p : program) {
            timePQ.offer(new Program(p[0], p[1], p[2]));
        }

        Program first = timePQ.poll();
        int time = first.call + first.time;

        while (!timePQ.isEmpty() || !scorePQ.isEmpty()) {
            while (!timePQ.isEmpty() && time >= timePQ.peek().call) {
                scorePQ.offer(timePQ.poll());
            }
             if (!timePQ.isEmpty() && scorePQ.isEmpty()) {
                scorePQ.offer(timePQ.poll());
            }
            
            Program cur = scorePQ.poll();
            if (time < cur.call) {
                time = cur.call;
            } else if (time > cur.call) {
                answer[cur.score] += time - cur.call;
            }

            time += cur.time;
        }
        answer[0] = time;
        return answer;
    }

    class Program {
        int score;
        int call;
        int time;

        public Program(int score, int call, int time) {
            this.score = score;
            this.call = call;
            this.time = time;
        }
    }
}
```
