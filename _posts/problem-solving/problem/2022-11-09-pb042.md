**문제**  
적록색약은 빨간색과 초록색의 차이를 거의 느끼지 못한다. 따라서, 적록색약인 사람이 보는 그림은 아닌 사람이 보는 그림과는 좀 다를 수 있다.

크기가 N×N인 그리드의 각 칸에 R(빨강), G(초록), B(파랑) 중 하나를 색칠한 그림이 있다. 그림은 몇 개의 구역으로 나뉘어져 있는데, 구역은 같은 색으로 이루어져 있다. 또, 같은 색상이 상하좌우로 인접해 있는 경우에 두 글자는 같은 구역에 속한다. (색상의 차이를 거의 느끼지 못하는 경우도 같은 색상이라 한다)

예를 들어, 그림이 아래와 같은 경우에

```
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

적록색약이 아닌 사람이 봤을 때 구역의 수는 총 4개이다. (빨강 2, 파랑 1, 초록 1) 하지만, 적록색약인 사람은 구역을 3개 볼 수 있다. (빨강-초록 2, 파랑 1)

그림이 입력으로 주어졌을 때, 적록색약인 사람이 봤을 때와 아닌 사람이 봤을 때 구역의 수를 구하는 프로그램을 작성하시오.


**입력**  
첫째 줄에 N이 주어진다. (1 ≤ N ≤ 100)

둘째 줄부터 N개 줄에는 그림이 주어진다.

**출력**  
적록색약이 아닌 사람이 봤을 때의 구역의 개수와 적록색약인 사람이 봤을 때의 구역의 수를 공백으로 구분해 출력한다.

**예제 입력**

```
5
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

**예제 출력**

```
4 3
```

## 나의 풀이

- 처음에는 정상과, 적록 색맹 두 가지 경우를 따로 함수로 만들어서 각각 구했었는데(나의 풀이),  
정상을 먼저 구하고 적록 색맹 경우를 구할 때는 img의 R을 G로 바꾸거나 G를 R로 바꿔서 똑같이 구할 수 있다(최종 코드)

### DFS
```java
public class Solution {
    char[][] img;
    int n;
    boolean[][] visited;
    int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };

    public int[] solution(int n, char[][] img) {
        this.img = img;
        this.n = n;
        int[] answer = new int[2];

        for (int x = 0; x < 2; x++) {
            visited = new boolean[n][n];
            int count = 0;

            if (x == 0) {
                for (int i = 0; i < n; i++) {
                    for (int j = 0; j < n; j++) {
                        if (!visited[i][j]) {
                            normal(i, j);
                            count++;
                        }
                    }
                }
            } else {
                for (int i = 0; i < n; i++) {
                    for (int j = 0; j < n; j++) {
                        if (!visited[i][j]) {
                            colorBlindness(i, j);
                            count++;
                        }
                    }
                }
            }
            answer[x] = count;
        }


        return answer;
    }

    private void normal(int r, int c) {

        char cur = img[r][c];
        visited[r][c] = true;

        for (int[] dir : dirs) {
            int nr = r + dir[0];
            int nc = c + dir[1];

            if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                if (!visited[nr][nc] && img[nr][nc] == cur) {
                    normal(nr, nc);
                }
            }
        }
    }

    private void colorBlindness(int r, int c) {
        char cur = img[r][c];
        visited[r][c] = true;

        for (int[] dir : dirs) {
            int nr = r + dir[0];
            int nc = c + dir[1];

            if (nr >= 0 && nr < n && nc >= 0 && nc < n) {

                if (visited[nr][nc]) {
                    continue;
                }

                if (cur == 'R' || cur == 'G') {
                    if (img[nr][nc] == 'R' || img[nr][nc] == 'G') {
                        colorBlindness(nr, nc);
                    }
                } else {
                    if (img[nr][nc] == cur) {
                        colorBlindness(nr, nc);
                    }
                }
            }
        }
    }
}
```

### BFS

```java
import java.util.LinkedList;
import java.util.Queue;

public class Solution {
    char[][] img;
    int n;
    boolean[][] visited;
    int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };

    public int[] solution(int n, char[][] img) {
        this.img = img;
        this.n = n;
        int[] answer = new int[2];
        answer[0] = solve();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (this.img[i][j] == 'R') {
                    this.img[i][j] = 'G';
                }
            }
        }
        answer[1] = solve();
        return answer;
    }

    private int solve() {
        visited = new boolean[n][n];
        int count = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (!visited[i][j]) {
                    bfs(i, j);
                    count++;
                }
            }
        }
        return count;
    }

    private void bfs(int r, int c) {
        visited[r][c] = true;
        Queue<int[]> q = new LinkedList<>();
        q.offer(new int[]{r, c});

        while (!q.isEmpty()) {
            int[] pos = q.poll();
            char cur = img[pos[0]][pos[1]];
            for (int[] dir : dirs) {
                int nr = pos[0] + dir[0];
                int nc = pos[1] + dir[1];

                if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                    if (!visited[nr][nc] && img[nr][nc] == cur) {
                        visited[nr][nc] = true;
                        q.offer(new int[]{nr, nc});
                    }
                }
            }
        }
    }
}
```
