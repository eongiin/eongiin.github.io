**문제**  
수 N개 A1, A2, ..., AN이 주어진다. 이때, 연속된 부분 구간의 합이 M으로 나누어 떨어지는 구간의 개수를 구하는 프로그램을 작성하시오.

즉, Ai + ... + Aj (i ≤ j) 의 합이 M으로 나누어 떨어지는 (i, j) 쌍의 개수를 구해야 한다.

**입력**  
첫째 줄에 N과 M이 주어진다. (1 ≤ N ≤ 10^6, 2 ≤ M ≤ 10^3)

둘째 줄에 N개의 수 A1, A2, ..., AN이 주어진다. (0 ≤ Ai ≤ 10^9)

**출력**  
첫째 줄에 연속된 부분 구간의 합이 M으로 나누어 떨어지는 구간의 개수를 출력한다.

**예제 입력**

```
5 3
1 2 3 1 2
```

**예제 출력**

```
7
```

## 나의 풀이

- N의 범위가 10^6까지이므로 단순하게 계산을 하면 O(N^2)이 되어 시간초과가 발생하므로 한 번만 탐색해서 해결하는 쪽으로 생각해야 함
- 나머지 연산 분배법칙 이용

```
(A + B) % p = ((A % p) + (B % p)) % p
(A * B) % p = ((A % p) * (B % p)) % p
(A - B) % p = ((A % p) - (B % p) + p) % p
//뺄셈의 경우 음수가 나오는 것을 방지하기 위해 divisor를 한번 더해줌
```

- 첫 번째부터 현재 위치까지의 합을 구한 배열을 `sum`이라고 했을 때, 어떤 구간 `(a,b)`의 누적합은 `sum[b]-sum[a-1]`로 구할 수 있음
- 문제에서 구해야 할 것은 `(sum[b] - sum[a-1]) % m`이 0이 되는 경우(b가 현재 확인하는 값이라고 하면 a는 지나온 값들 중 하나를 의미)
  - 이것을 분배 법칙을 이용하면 `((sum[b] % m) - (sum[a-1] % m)) % m`이 0이되어야 함
  - 즉 `(sum[b] % m) - (sum[a-1] % m)`이 m이 되거나 0이 되어야 함
    - 0이 되는 경우
      - `(sum[b] % m) == (sum[a-1] % m)`인 경우를 구하면 됨
    - m이 되는 경우
      - 어떤 구간의 합이  m이 되는 경우를 말하는 것인데 0~b까지의 합인 sum[b]가 m이 될 때만 따로 구해주고 나머지 경우는 위의 경우에 포함됨
- 이제 나머지가 같은 경우를 구해줘야 하는데, 지나온 모든 값들(a)의 나머지들을 일일히 비교하면서 구하면 O(N^2)이 되므로 배열을 나머지를 기준으로 개수를 체크하도록 만들어야 함
  - 나머지를 기준으로 배열을 만들면 같은 나머지를 가진 것들의 개수를 바로 체크할 수 있게 됨
- 현재 확인하는 값의 나머지가 바로 0이되는 경우는 따로 +1 해줘야 함

```java
public class Solution {
    public long solution(int n, int m, int[] arr) {

        int sum = 0;
        int[] cnt = new int[m];
        long answer = 0;
        for (int cur : arr) {
            sum += cur;
            sum %= m;
            answer += cnt[sum];
            if (sum == 0) {
                answer++;
            }
            cnt[sum]++;
        }
        return answer;
    }
}
```

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());
        int[] cnt = new int[m];
        long answer = 0;
        int sum = 0;
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            int cur = Integer.parseInt(st.nextToken());
            sum += cur;
            sum %= m;
            answer += cnt[sum];
            if (sum == 0) {
                answer++;
            }
            cnt[sum]++;
        }
        System.out.println(answer);
    }
}
