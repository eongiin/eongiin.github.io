**문제**  
수열 A가 주어졌을 때, 가장 긴 증가하는 부분 수열을 구하는 프로그램을 작성하시오.

예를 들어, 수열 A = {10, 20, 10, 30, 20, 50} 인 경우에 가장 긴 증가하는 부분 수열은 A = {10, 20, 10, 30, 20, 50} 이고, 길이는 4이다.

**입력**  
첫째 줄에 수열 A의 크기 N (1 ≤ N ≤ 1,000,000)이 주어진다.

둘째 줄에는 수열 A를 이루고 있는 Ai가 주어진다. (-1,000,000,000 ≤ Ai ≤ 1,000,000,000)

**출력**  
첫째 줄에 수열 A의 가장 긴 증가하는 부분 수열의 길이를 출력한다.

둘째 줄에는 정답이 될 수 있는 가장 긴 증가하는 부분 수열을 출력한다.

**예제 입력**

```
6
10 20 10 30 20 50
```

**예제 출력**

```
4
10 20 30 50
```

## 나의 풀이

최장 증가 부분 수열(LIS, Longest Increasing Subsequence)

### DP

- 먼저 lis 배열을 만들어서 그 위치까지의 LIS 크기 구함
    - lis[i] : 처음부터 i번째까지 LIS 크기
    - lis 배열 모든 원소의 최솟값은 1이므로 1로 모두 초기화
- LIS 크기 만큼 배열(answer)을 생성하여 lis배열을 뒤에서부터 탐색하면서 LIS 값(curLIS) 과 일치하면 그 인덱스에 해당하는 원소의 값(arr[i])을 answer에 뒤부터 넣어줌
    - 하나 넣어줄 때마다 LIS 값 하나씩 줄임
- 시간 복잡도는 LIS를 구할 때 매번 처음부터 현재 위치까지 모두 계산하므로 $$1+ 2+ 3+ \dots + N-1 = \frac{n(n-1)}{2} = O(N^2)$$

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        int[] arr = new int[n];
        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        int max = 1;
        int[] lis = new int[n];
        Arrays.fill(lis, 1);
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (arr[j] < arr[i]) {
                    lis[i] = Math.max(lis[i], lis[j] + 1);
                }
            }
            max = Math.max(lis[i], max);
        }

        StringBuilder sb = new StringBuilder();
        sb.append(max).append("\n");

        int[] answer = new int[n];
        int curLIS = max;
        for (int i = n - 1; i >= 0; i--) {
            if (lis[i] == curLIS) {
                answer[--curLIS] = arr[i];
            }
        }

        for (int i = 0; i < max; i++) {
            sb.append(answer[i]).append(" ");
        }

        System.out.println(sb);
    }
}
```

### 이분 탐색

- [가장 긴 증가하는 부분 수열 5](https://www.acmicpc.net/problem/14003){:target="_blank"}는 N의 범위가 백만까지 늘어나서 $$O(N^2)$$으로 풀면 시간초과 발생
- 이분탐색으로  LIS 구하기 
    - 배열을 하나 만들고(asc) arr 배열을 돌면서 아래 규칙에 맞게 저장
        - asc 배열의 가장 오른쪽 원소 A와 arr 배열의 현재 원소 B를 비교하여 B가 더 크면 바로 asc 배열에 집어 넣음(오름차순으로 정렬됨)
            - right 변수로 가장 오른쪽 인덱스 저장
        - 더 작다면 이분 탐색을 이용하여 B를 저장할 위치 찾기
            - B보다 작지 않은 수 중에 가장 작은 수의 위치 반환하여 이 위치에 B를 덮어씀
        - 이 배열의 크기가 곧 LIS의 길이가 됨
        - 덮어쓰기라 같은 경우는 고려해주지 않아도 됨
    - 배열의 원소 범위가 -1,000,000,000 부터 시작이라 asc[0]은 `Integer.MIN_VALUE`로 초기화
    - 시간복잡도 $$ O(N\log_2 N)$$
- 이분탐색으로 LIS를 구할 때 만든 asc 배열의 크기가 곧 LIS의 길이가 되지만, 그 안에 들어있는 원소들은 LIS를 보장하지 않음
    - 위의 DP에서 구했던 것처럼 각 위치에서의 LIS 길이를 저장해둔 배열이 필요(lis)
    - 이분 탐색으로 LIS를 구할 때, lis 배열에  LIS 길이를 저장해 둠
        - 배열에 바로 추가 되는 경우는 배열에 있는 숫자들보다 더 큰 숫자인 경우이므로 lis 배열에 늘어난 asc 배열의 크기를 저장
        - 가장 큰 숫자가 아니라 비교해야 하는 경우에는 이분 탐색으로 얻은 인덱스 값이 곧 해당 위치까지의 LIS 길이가 됨
        - 배열의 가장 큰 원소와 같은 경우에는 현재 asc 크기를 똑같이 넣어주면 됨
- n-1부터 0까지 lis 배열을 탐색하며 답을 구할 수도 있지만, 좀 더 줄이기 위해 LIS의 가장 마지막 원소 위치를 maxIdx로 저장해 두고 maxIdx부터 0까지 탐색
- 위에서 했던 것과 마찬가지로 lis 배열을 돌면서 lis[i] 값이 LIS 길이와 일치하면 answer 배열에 뒤부터 차례로 저장하고 LIS 길이 값을 하나씩 빼줌

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    static int[] asc;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        int[] arr = new int[n];
        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        asc = new int[n + 1];
        asc[0] = Integer.MIN_VALUE;
        int[] lis = new int[n];
        int right = 0;//asc 배열
        int top = -1;//lis 배열
        int maxIdx = -1;

        for (int i = 0; i < n; i++) {
            if (asc[right] < arr[i]) {
                asc[++right] = arr[i];
                lis[++top] = right;
                maxIdx = i;
            } else if (asc[right] == arr[i]) {
                lis[++top] = right;
            } else if (asc[right] > arr[i]) {
                int idx = binarySearch(arr[i], right);
                asc[idx] = arr[i];
                lis[++top] = idx;
            }
        }

        int[] answer = new int[right];
        int curLIS = right;
        for (int i = maxIdx; i >= 0; i--) {
            if (lis[i] == curLIS) {
                answer[--curLIS] = arr[i];
            }
        }

        StringBuilder sb = new StringBuilder();
        sb.append(right).append("\n");

        for (int i = 0; i < right; i++) {
            sb.append(answer[i]).append(" ");
        }
        System.out.println(sb);
    }

    private static int binarySearch(int num, int right) {
        int left = 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (asc[mid] == num) {
                return mid;
            } else if (asc[mid] > num) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }
}
```
