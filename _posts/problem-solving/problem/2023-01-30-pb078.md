**문제**  
히스토그램에 대해서 알고 있는가? 히스토그램은 아래와 같은 막대그래프를 말한다.

![image](https://user-images.githubusercontent.com/90626691/215365220-3d515e8f-4144-4a2e-98ab-f2210aef90f9.png){:.align-center}


각 칸의 간격은 일정하고, 높이는 어떤 정수로 주어진다. 위 그림의 경우 높이가 각각 2 1 4 5 1 3 3이다.

이러한 히스토그램의 내부에 가장 넓이가 큰 직사각형을 그리려고 한다. 아래 그림의 빗금 친 부분이 그 예이다. 이 직사각형의 밑변은 항상 히스토그램의 아랫변에 평행하게 그려져야 한다.

![image](https://user-images.githubusercontent.com/90626691/215365234-cf39ffcb-d301-4a7b-bea2-2e89bd9a24d0.png){:.align-center}

주어진 히스토그램에 대해, 가장 큰 직사각형의 넓이를 구하는 프로그램을 작성하시오.

**입력**  
첫 행에는 $$N (1 ≤ N ≤ 100,000)$$ 이 주어진다. N은 히스토그램의 가로 칸의 수이다. 다음 N 행에 걸쳐 각 칸의 높이가 왼쪽에서부터 차례대로 주어진다. 각 칸의 높이는 1,000,000,000보다 작거나 같은 자연수 또는 0이다.

**출력**  
첫째 줄에 가장 큰 직사각형의 넓이를 출력한다. 이 값은 20억을 넘지 않는다.

**예제 입력**

```
7
2
1
4
5
1
3
3
```

**예제 출력**

```
8
```

## 나의 풀이

### 분할 정복

- 더 이상 나눌 수 없을 때까지 분할
    - 마지막엔 자기 자신의 크기(높이) 반환
- getMax는 아래의 세 가지 크기 중에 가장 큰 크기를 반환
    - 분할한 왼쪽의 가장 큰 크기
    - 분할한 오른쪽의 가장 큰 크기
    - 분할한 것들을 합쳤을 때 가장 큰 크기
- getMidMax는 분할한 것을 합쳤을 때 가장 큰 크기 구함
    - 가운데에서부터 왼쪽 혹은 오른쪽으로 넓혀가며 최대 크기 구함
    - 왼쪽과 오른쪽 중 더 큰 쪽으로 넓혀감
    - 높이는 현재 높이와 넓히려는 쪽 높이 중 더 작은 값으로 설정
    - 폭은 오른쪽 위치 - 왼쪽 위치 + 1
    - 한 쪽이 먼저 끝에 다다르면 첫 번째  while 문을 빠져나오는데, 다른 한쪽도 잊지 말고 다 확인하고 끝내야 함
- 최댓값이 20억을 넘지 않는다고 문제에 나와있으므로 int로 해도 됨
- 시간 복잡도 $$ O(N\log N)$$
    - 전체 과정을 T로 둘 때, 두 개의 서브 리스트로 분할하여 ($$  2T(\frac{N}{2}) $$)
    - 각 재귀 단계마다 중간 면적을 구하는데, 이 때 중간 면적 탐색은 현재 리스트의 길이만큼만 수행 $$(F(N))$$
    - 즉 $$ T(N) = 2T(\frac{N}{2}) + O(N) → O(N \log N) $$

```java
class Solution {
    static int[] arr;

    public int solution(int[] arr) {
        this.arr = arr;
        return getMax(0, arr.length - 1);
    }

    private int getMax(int left, int right) {
        if (left == right) {
            return arr[left];
        }

        int mid = left + (right - left) / 2;
        int maxLeft = getMax(0, mid);
        int maxRight = getMax(mid + 1, right);
        return Math.max(Math.max(maxLeft, maxRight), getMidMax(left, mid, right));
    }

    private int getMidMax(int left, int mid, int right) {
        int toLeft = mid;
        int toRight = mid;

        int height = arr[mid];
        int maxSize = height;

        while (left < toLeft && toRight < right) {
            if (arr[toLeft - 1] < arr[toRight + 1]) {
                toRight++;
                height = Math.min(height, arr[toRight]);
            } else {
                toLeft--;
                height = Math.min(height, arr[toLeft]);
            }
            maxSize = Math.max(maxSize, height * (toRight - toLeft + 1));
        }

        while (left < toLeft) {
            toLeft--;
            height = Math.min(height, arr[toLeft]);
            maxSize = Math.max(maxSize, height * (toRight - toLeft + 1));
        }

        while (toRight < right) {
            toRight++;
            height = Math.min(height, arr[toRight]);
            maxSize = Math.max(maxSize, height * (toRight - toLeft + 1));
        }
        return maxSize;
    }
}
```

### 스택

- 오름차순으로 스택에 <b>인덱스</b> 저장
    - 높이는 `arr[인덱스]`로 찾을 수 있고 폭을 구할 때 `현재 위치-인덱스` 값이 필요하여 인덱스를 저장함
- 현재 스택에 들어가 있는 최댓값 A보다 같거나 작은 값 B가 들어오려고 하는 경우에는 스택에서 B보다 작거나 같은 수들을 모두 빼줌(스택에 저장 되어 있는 건 인덱스 값이므로 그 인덱스 값을 이용해 실제 값을 비교해야 하는 것 주의)
    - 스택에서 값을 뺄 때마다 크기 계산
    - 오름차순으로 정렬함으로써 현재 높이로 최대 어디까지 확장할 수 있는지 바로 구할 수 있음
        - 현재 빼려는 값(top 위치에 있는 값)으로 계산할 수 있는 최대 폭은 현재 위치에서 스택에 저장된 그 이전 값(인덱스)을 빼주면 됨( 그 이전 값은 현재 값보다 작으므로 현재 높이로 더 이상 갈 수 없기 때문에)
            - 현재 위치 i 
            - 그 이전 값 stack[top]  → left 변수에 저장  
                - 여기서  top은 가장 위의 값을 빼고 하나 줄어든 위치
                - top이 -1이면 (스택에 원소가 하나도 없으면) left 값을 -1로 계산    
                (인덱스가 0부터 시작했기 때문에 0이 아닌 -1)
- 구현된 스택을 쓸 수도 있지만 배열로 구현했음
- 시간 복잡도 $$ O(N) $$

```java
class Solution {

    public int solution(int n, int[] arr) {
        int maxSize = 0;
        int[] stack = new int[n];
        int top = -1;

        for (int i = 0; i < n; i++) {
            while (top >= 0 && arr[stack[top]] >= arr[i]) {
                int idx = stack[top--];
                int left = top < 0 ? -1 : stack[top];
                maxSize = Math.max(maxSize, (i - left - 1) * arr[idx]);
            }
            stack[++top] = i;
        }

        while (top >= 0) {
            int idx = stack[top--];
            int left = top < 0 ? -1 : stack[top];
            maxSize = Math.max(maxSize, (n - 1 - left) * arr[idx]);
        }
        return maxSize;
    }
}
```
