**문제**  
세준이는 양수와 +, -, 그리고 괄호를 가지고 식을 만들었다. 그리고 나서 세준이는 괄호를 모두 지웠다.

그리고 나서 세준이는 괄호를 적절히 쳐서 이 식의 값을 최소로 만들려고 한다.

괄호를 적절히 쳐서 이 식의 값을 최소로 만드는 프로그램을 작성하시오.

**입력**  
첫째 줄에 식이 주어진다. 식은 ‘0’~‘9’, ‘+’, 그리고 ‘-’만으로 이루어져 있고, 가장 처음과 마지막 문자는 숫자이다. 그리고 연속해서 두 개 이상의 연산자가 나타나지 않고, 5자리보다 많이 연속되는 숫자는 없다. 수는 0으로 시작할 수 있다. 입력으로 주어지는 식의 길이는 50보다 작거나 같다.

**출력**  
첫째 줄에 정답을 출력한다.

**예제 입력1**

```
55-50+40
```

**예제 출력1**

```
-35
```

**예제 입력2**

```
10+20+30+40
```

**예제 출력2**

```
100
```

**예제 입력3**

```
00009-00009
```

**예제 출력3**

```
0
```

## 나의 풀이
- +, -로 문자열을 나눠서 숫자들만 뽑아낸 배열 number 만듦
    - split으로 바로 배열을 만들 수 있는데 String 배열로 만들어져서 나중에 숫자로 바꿈
- 맨 처음 숫자는 무조건 답에 더할 수밖에 없으므로 answer를 맨 처음 숫자로 초기화
- idx로 원래 주어진 문자열에서 다음 연산자 위치 계산
- 연산자가 빼기라면 answer가 아닌 part라는 변수를 두어 따로 저장하고 다음 빼기가 나올 때까지 전부 더함
    - 최댓값을 빼려고 part에 저장을 해두고 한 번에 빼려는 것 (괄호)
    - 다음 빼기가 나오면 현재까지 더한 것을 answer에서 모두 빼고 part는 0으로 초기화한 후 다시 그다음값 part에 저장 반복
    - 끝까지 다음 빼기가 나오지 않는다면 마지막에 part가 0인지 확인해서 그 값을 빼줌

```java
public class Solution {
    public int solution(String s) {
        String[] number = s.split("\\+|-");
        int idx = 0;
        int answer = Integer.parseInt(number[0]);
        int part = 0;
        boolean isMinus = false;
        for (int i = 1; i < number.length; i++) {
            idx += number[i - 1].length();
            char oper = s.charAt(idx);
            idx++;
            int cur = Integer.parseInt(number[i]);
            if (oper == '-') {
                if (isMinus) {
                    answer -= part;
                    part = 0;
                }
                isMinus = true;
                part += cur;
            } else {
                if (isMinus) {
                    part += cur;
                } else {
                    answer += cur;
                }
            }
        }
        if (part != 0) {
            answer -= part;
        }
        return answer;
    }
}
```

## 최종 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s = br.readLine();
        String[] plus = s.split("-");


        int answer = 0;
        String[] first = plus[0].split("\\+");
        for (int i = 0; i < first.length; i++) {
            answer += Integer.parseInt(first[i]);
        }

        for (int i = 1; i < plus.length; i++) {
            String[] number = plus[i].split("\\+");
            for (int j = 0; j < number.length; j++) {
                answer -= Integer.parseInt(number[j]);
            }
        }
        System.out.println(answer);
    }
}
```
