**문제**  
N개의 도시가 있다. 그리고 한 도시에서 출발하여 다른 도시에 도착하는 M개의 버스가 있다. 우리는 A번째 도시에서 B번째 도시까지 가는데 드는 버스 비용을 최소화 시키려고 한다. A번째 도시에서 B번째 도시까지 가는데 드는 최소비용을 출력하여라. 도시의 번호는 1부터 N까지이다.

**입력**  
첫째 줄에 도시의 개수 N(1 ≤ N ≤ 1,000)이 주어지고 둘째 줄에는 버스의 개수 M(1 ≤ M ≤ 100,000)이 주어진다. 그리고 셋째 줄부터 M+2줄까지 다음과 같은 버스의 정보가 주어진다. 먼저 처음에는 그 버스의 출발 도시의 번호가 주어진다. 그리고 그 다음에는 도착지의 도시 번호가 주어지고 또 그 버스 비용이 주어진다. 버스 비용은 0보다 크거나 같고, 100,000보다 작은 정수이다.

그리고 M+3째 줄에는 우리가 구하고자 하는 구간 출발점의 도시번호와 도착점의 도시번호가 주어진다. 출발점에서 도착점을 갈 수 있는 경우만 입력으로 주어진다.

**출력**  
첫째 줄에 출발 도시에서 도착 도시까지 가는데 드는 최소 비용을 출력한다.

**예제 입력**

```
5
8
1 2 2
1 3 3
1 4 1
1 5 10
2 4 2
3 4 1
3 5 1
4 5 3
1 5
```

**예제 출력**

```
4
```

## 나의 풀이

기본적인 다익스트라 문제

- 버스 비용이 0보다 클 수 있음
    - 인접 행렬로 그래프를 만들 때 -1로 초기화
- 양방향 아님
- 도착지에 방문했으면 바로 종료해도 됨

### 인접리스트

```java
import java.util.ArrayList;
import java.util.PriorityQueue;

public class Solution {
    static final int INF = 1_000_000_000;
    static ArrayList<Node>[] graph;
    static int[] dist;
    static boolean[] visited;

    public int solution(int n, int m, int[][] arr, int start, int end) {
        graph = new ArrayList[n + 1];
        dist = new int[n + 1];
        visited = new boolean[n + 1];

        for (int i = 1; i < n + 1; i++) {
            graph[i] = new ArrayList<>();
            dist[i] = INF;
        }

        for (int i = 0; i < m; i++) {
            graph[arr[i][0]].add(new Node(arr[i][1], arr[i][2]));
        }

        dijkstra(start, end);
        return dist[end];
    }

    private void dijkstra(int from, int end) {
        PriorityQueue<Node> pq = new PriorityQueue<>();
        pq.offer(new Node(from, 0));
        dist[from] = 0;

        while (!pq.isEmpty()) {
            Node cur = pq.poll();

            if (visited[cur.to]) {
                continue;
            }
            visited[cur.to] = true;

            if (dist[cur.to] < cur.cost) {
                continue;
            }

            if (cur.to == end) {
                break;
            }
            
            for (Node adj : graph[cur.to]) {
                int newCost = cur.cost + adj.cost;
                if (!visited[adj.to] && dist[adj.to] > newCost) {
                    dist[adj.to] = newCost;
                    pq.offer(new Node(adj.to, newCost));
                }
            }
        }
    }

    class Node implements Comparable<Node> {
        int to;
        int cost;

        public Node(int to, int cost) {
            this.to = to;
            this.cost = cost;
        }

        @Override
        public int compareTo(Node n) {
            return this.cost - n.cost;
        }
    }
}
```

### 인접행렬
```java
import java.util.Arrays;
import java.util.PriorityQueue;

public class Solution {
    static final int INF = 1_000_000_000;
    static int[][] graph;
    static int[] dist;
    static boolean[] visited;

    public int solution(int n, int m, int[][] arr, int start, int end) {
        graph = new int[n + 1][n + 1];
        dist = new int[n + 1];
        visited = new boolean[n + 1];

        for (int i = 1; i < n + 1; i++) {
            dist[i] = INF;
            Arrays.fill(graph[i], -1);
        }

        for (int i = 0; i < m; i++) {
            int a = arr[i][0];
            int b = arr[i][1];
            int cost = arr[i][2];
            if (graph[a][b] == -1 || graph[a][b] > cost) {
                graph[a][b] = cost;
            }
        }
        dijkstra(start, end);
        return dist[end];
    }

    private void dijkstra(int start, int end) {
        PriorityQueue<Node> pq = new PriorityQueue<>();
        pq.offer(new Node(start, 0));
        dist[start] = 0;

        while (!pq.isEmpty()) {
            Node cur = pq.poll();

            if (visited[cur.to]) {
                continue;
            }
            visited[cur.to] = true;

            if (dist[cur.to] < cur.cost) {
                continue;
            }

            if (cur.to == end) {
                break;
            }

            for (int adjTo = 1; adjTo < graph.length; adjTo++) {
                int adjCost = graph[cur.to][adjTo];
                if (adjCost == -1) {
                    continue;
                }

                int newCost = cur.cost + adjCost;
                if (!visited[adjTo] && dist[adjTo] > newCost) {
                    dist[adjTo] = newCost;
                    pq.offer(new Node(adjTo, newCost));
                }
            }
        }
    }

    class Node implements Comparable<Node> {
        int to;
        int cost;

        public Node(int to, int cost) {
            this.to = to;
            this.cost = cost;
        }

        @Override
        public int compareTo(Node n) {
            return this.cost - n.cost;
        }
    }
}
```
