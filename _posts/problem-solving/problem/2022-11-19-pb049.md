**문제**  
n × n의 크기의 대나무 숲이 있다. 욕심쟁이 판다는 어떤 지역에서 대나무를 먹기 시작한다. 그리고 그 곳의 대나무를 다 먹어 치우면 상, 하, 좌, 우 중 한 곳으로 이동을 한다. 그리고 또 그곳에서 대나무를 먹는다. 그런데 단 조건이 있다. 이 판다는 매우 욕심이 많아서 대나무를 먹고 자리를 옮기면 그 옮긴 지역에 그 전 지역보다 대나무가 많이 있어야 한다.

이 판다의 사육사는 이런 판다를 대나무 숲에 풀어 놓아야 하는데, 어떤 지점에 처음에 풀어 놓아야 하고, 어떤 곳으로 이동을 시켜야 판다가 최대한 많은 칸을 방문할 수 있는지 고민에 빠져 있다. 우리의 임무는 이 사육사를 도와주는 것이다. n × n 크기의 대나무 숲이 주어져 있을 때, 이 판다가 최대한 많은 칸을 이동하려면 어떤 경로를 통하여 움직여야 하는지 구하여라.

**입력**  
첫째 줄에 대나무 숲의 크기 n(1 ≤ n ≤ 500)이 주어진다. 그리고 둘째 줄부터 n+1번째 줄까지 대나무 숲의 정보가 주어진다. 대나무 숲의 정보는 공백을 사이로 두고 각 지역의 대나무의 양이 정수 값으로 주어진다. 대나무의 양은 1,000,000보다 작거나 같은 자연수이다.

**출력**  
첫째 줄에는 판다가 이동할 수 있는 칸의 수의 최댓값을 출력한다.

**예제 입력**

```
4
14 9 12 10
1 11 5 4
7 15 2 13
6 3 16 8
```

**예제 출력**

```
4
```

## 나의 풀이

### 완전 탐색 (시간 초과)

- 당연히 시간 초과가 날 줄은 알았지만 일단 풀어보고 최적화하자는 생각으로 먼저 다 탐색해 봤다

```java
public class Solution {

    int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    int n;
    int[][] map;

    public int solution(int n, int[][] map) {
        int answer = 1;
        this.n = n;
        this.map = map;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                answer = Math.max(answer, dfs(i, j));
            }
        }
        return answer;
    }

    private int dfs(int r, int c) {

        int max = 1;
        
        for (int[] dir : dirs) {
            int cnt = 1;
            int nr = r + dir[0];
            int nc = c + dir[1];

            if (nr < 0 || nr >= n || nc < 0 || nc >= n) {
                continue;
            }

            if (map[r][c] > map[nr][nc]) {
                cnt += dfs(nr, nc);
            }
            max = Math.max(cnt, max);
        }
        return max;
    }
}
```

### dp

- 한 번 다녀간 곳의 깊이를 저장해두면 나중에는 거길 직접 방문하지 않고 그 값에 +1만 하면 된다는 생각이 들었다
- 한 번이라도 지나간 곳은 dp 배열 값이 최소 1이 되므로 이 배열로 방문 체크도 동시에 진행
- 일반 dfs에서처럼 연결된 곳의 개수를 전부 세는 게 아니라 어느 특정 경로의 깊이를 구해야 해서 방향별로 cnt 초기화
- 다음에 갈 곳이 현재 값보다 더 큰 경우 (더 작은 경우로 가게 해도 상관없음)
    - 이미 방문한 적이 있다면(`dp[nr][nc]>0`) 그 값에 +1 (현재 칸을 포함하니까 +1 되는 것)
    - 방문한 적이 없다면 그 칸으로 이동해서 반복
- 현재 있는 곳에서 4가지 방향으로 갈 수 있으니 그 네 번을 각각 구하고 가장 큰 값을 dp에 저장

```java
public class Solution {

    int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    int n;
    int[][] map;
    int[][] dp;

    public int solution(int n, int[][] map) {
        int answer = 1;
        this.n = n;
        this.map = map;
        dp = new int[n][n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dp[i][j] == 0) {
                    answer = Math.max(answer, dfs(i, j));
                }
            }
        }
        return answer;
    }

    private int dfs(int r, int c) {
        for (int[] dir : dirs) {
            int cnt = 1;
            int nr = r + dir[0];
            int nc = c + dir[1];

            if (nr < 0 || nr >= n || nc < 0 || nc >= n) {
                continue;
            }

            if (map[r][c] < map[nr][nc]) {
                if (dp[nr][nc] > 0) {
                    cnt = dp[nr][nc] + 1;
                } else {
                    cnt += dfs(nr, nc);
                }
            }
            dp[r][c] = Math.max(cnt, dp[r][c]);
        }
        return dp[r][c];
    }
}
```

## 최종 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;


public class Main {

    static int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    static int n;
    static int[][] map;
    static int[][] dp;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        n = Integer.parseInt(br.readLine());
        map = new int[n][n];
        dp = new int[n][n];
        for (int i = 0; i < n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int j = 0; j < n; j++) {
                map[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        int answer = 1;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dp[i][j] == 0) {
                    answer = Math.max(answer, dfs(i, j));
                }
            }
        }
        System.out.println(answer);
    }

    private static int dfs(int r, int c) {
        for (int[] dir : dirs) {
            int cnt = 1;
            int nr = r + dir[0];
            int nc = c + dir[1];

            if (nr < 0 || nr >= n || nc < 0 || nc >= n) {
                continue;
            }

            if (map[r][c] < map[nr][nc]) {
                if (dp[nr][nc] > 0) {
                    cnt = dp[nr][nc] + 1;
                } else {
                    cnt += dfs(nr, nc);
                }
            }
            dp[r][c] = Math.max(cnt, dp[r][c]);
        }
        return dp[r][c];
    }
}
```
