**문제**  
오아시스의 재결합 공연에 N명이 한 줄로 서서 기다리고 있다.

이 역사적인 순간을 맞이하기 위해 줄에서서 기다리고 있던 백준이는 갑자기 자기가 볼 수 있는 사람의 수가 궁금해 졌다.

두 사람 A와 B가 서로 볼 수 있으려면, 두 사람 사이에 A 또는 B보다 키가 큰 사람이 없어야 한다.

줄에 서있는 사람의 키가 주어졌을 때, 서로 볼 수 있는 쌍의 수를 구하는 프로그램을 작성하시오.

**입력**  
첫째 줄에 줄에서 기다리고 있는 사람의 수 N이 주어진다. (1 ≤ N ≤ 500,000)

둘째 줄부터 N개의 줄에는 각 사람의 키가 나노미터 단위로 주어진다. 모든 사람의 키는 231 나노미터 보다 작다.

사람들이 서 있는 순서대로 입력이 주어진다.

**출력**  
서로 볼 수 있는 쌍의 수를 출력한다.

**예제 입력**

```
7
2
4
1
2
2
5
1
```

**예제 출력**

```
10
```

## 나의 풀이
### 틀린 풀이

![image](https://user-images.githubusercontent.com/90626691/213099942-658ebe0b-4e67-4705-866d-21882dc546ff.png)

- 아래의 코드는 위의 이미지처럼 동작한다 (실제 답은 17이 되어야 함)
    - 위 이미지에서 `count`는 현재 턴에서 최종 답 `sum`에 추가되는 개수를 의미
    - count = stack size = top
- 스택은 내림차순으로 만들어서 개수 체크
    - 중간에 큰 숫자가 나오면 그전은 더 이상 볼 수 없기 때문에 더 큰 숫자가 나오면 그전을 다 빼서 계산하고 큰 숫자부터 다시 시작하는 것
    - 같은 수는 빼지않고 포함했음
- arr 원소를 하나씩 돌면서 현재 원소를 기준으로 될 수 있는 경우를 모두 생각해서 일단 더하고 나중에 해당되지 않는 것을 빼주는 방식
    - 더하는 수는 현재 스택에 들어있는 데이터의 개수를 더해주면 됨
    - 위 그림에서 (괄호)에 들어있는 것들이 현재 위치에서는 다음 숫자가 어떤 숫자가 올지 모르지만 일단 추가한 수
    - 뺄 때는 스택의 top 위치에 있는 원소보다 새로 들어올 수가 작으면 이 경우는 전 단계에서 포함했던 경우들이 바로 인접한 두 개 말고는 전부 안 되는 것이므로(top이 가장 작은 원소인데 새로 들어온 건 그것보다 더 작다는 거니까) top-1개를 답에서 뺌
- 이런 방식으로 했을 때의 문제점은 위의 그림에서 파란색으로 칠한 부분이 포함되면 안 되는데 된다는 것이다
    - 새로 들어올 원소가 top보다는 크지만 스택 중간에 있는 원소보다 작은 경우에는 답이 될 수 없음
    - 하지만 아래 코드에서는 top이랑만 비교해서 이 경우를 제외하지 못함
    - top이랑만 비교하지 말고 새로 들어올 원소보다 큰 값이 스택 중간에 있는지 검사해야 함
    - 일일이 검사하면 O(N^2)이 되어 시간초과 발생

→ 현재 숫자를 왼쪽이 아닌 오른쪽으로 정했을 때 몇 개가 가능한지 계산하는 식으로 바꿔보자  

```java
public class Solution {
    public long solution(int n, int[] arr) {
        int top = 0;
        int[] stack = new int[n + 1];
        long cnt = 0;
        for (int i = 0; i < n; i++) {

            if (top > 1 && stack[top] > arr[i]) {
                cnt -= top - 1;
            }

            while (top > 0 && stack[top] < arr[i]) {
                top--;
            }

            stack[++top] = arr[i];
            cnt += top;
        }
        return cnt - top;
    }
}
```

### 스택에 번호와 개수 함께 저장

![image](https://user-images.githubusercontent.com/90626691/213101494-1649084f-e3dd-4bf1-8eab-97d71f638039.png)

- count는 아래 코드에는 따로 변수를 만들어두진 않았지만 현재 턴에서 추가되는 개수를 의미
- 스택을 내림차순으로 만드는 것은 동일하나 이번엔 같은 수도 만나면 빼고 개수를 따로 저장
    - 빼서 따로 계산해 두지 않으면 같은 수가 여러 개 있는 경우 제대로 계산할 수 없음 (ex - 3333)  
    → Person 클래스를 만들어 숫자(`num`) 뿐만 아니라 같은 수 체크한 값(`same`)도 같이 넣음
    - `same` 기본값은 본인을 나타내는 1이고 같은 수를 만날  때마다 +1
- `top > 1`이라는 것은 스택에 최소 2개가 있다는 것 → 1가지 경우의 수 추가
- 내림차순으로 넣으면서 더 큰 수가 나오면 현재 숫자를 오른쪽으로 했을 때 몇 개의 경우가 가능한지 계산하여 더함
    - 스택에 들어있는 현재의 숫자보다 작거나 같은 값들의 `same` 값을 더함
    - 같은 숫자는 뺀 후에 기존 same 값에 +1 하여 다시 넣음

```java
public class Solution {
    public long solution(int n, int[] arr) {
        Person[] stack = new Person[n + 1];
        long sum = 0;
        int top = 0;
        for (int i = 0; i < n; i++) {
            int same = 1;
            while (top > 0 && stack[top].num <= arr[i]) {
                if (stack[top].num == arr[i]) {
                    same += stack[top].same;
                }
                sum += stack[top--].same;
            }
            stack[++top] = new Person(arr[i], same);
            if (top > 1) {
                sum++;
            }
        }
        return sum;
    }

    class Person {
        int num;
        int same;

        public Person(int num, int same) {
            this.num = num;
            this.same = same;
        }
    }
}
```

                sum += stack[top--].same;
            }
            stack[++top] = new Person(num, same);
            if (top > 1) {
                sum++;
            }
        }
        System.out.println(sum);
    }

    static class Person {
        int num;
        int same;

        }
    }
