**문제**  
<그림 1>과 같이 정사각형 모양의 지도가 있다. 1은 집이 있는 곳을, 0은 집이 없는 곳을 나타낸다. 철수는 이 지도를 가지고 연결된 집의 모임인 단지를 정의하고, 단지에 번호를 붙이려 한다. 여기서 연결되었다는 것은 어떤 집이 좌우, 혹은 아래위로 다른 집이 있는 경우를 말한다. 대각선상에 집이 있는 경우는 연결된 것이 아니다. <그림 2>는 <그림 1>을 단지별로 번호를 붙인 것이다. 지도를 입력하여 단지수를 출력하고, 각 단지에 속하는 집의 수를 오름차순으로 정렬하여 출력하는 프로그램을 작성하시오.

![image](https://user-images.githubusercontent.com/90626691/198834745-84646eab-a2d7-4d55-b07f-7436d9e81eee.png)


**입력**  
첫 번째 줄에는 지도의 크기 N(정사각형이므로 가로와 세로의 크기는 같으며 5≤N≤25)이 입력되고, 그 다음 N줄에는 각각 N개의 자료(0혹은 1)가 입력된다.

**출력**  
첫 번째 줄에는 총 단지수를 출력하시오. 그리고 각 단지내 집의 수를 오름차순으로 정렬하여 한 줄에 하나씩 출력하시오.

**예제 입력**

```
7
0110100
0110101
1110101
0000111
0100000
0111110
0111000
```

**예제 출력**

```
3
7
8
9
```

## 나의 풀이

### BFS

```java
import java.util.*;

public class Solution {
    static final int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    static int n;

    public int[] solution(int n, int[][] arr) {

        boolean[][] visited = new boolean[n][n];
        this.n = n;

        List<Integer> complex = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (arr[i][j] == 1 && !visited[i][j]) {
                    complex.add(bfs(arr, visited, new int[]{i, j}));
                }
            }
        }

        Collections.sort(complex);
        int num = complex.size();
        int[] answer = new int[num + 1];
        answer[0] = num;
        for (int i = 0; i < num; i++) {
            answer[i + 1] = complex.get(i);
        }
        return answer;
    }


    private int bfs(int[][] arr, boolean[][] visited, int[] start) {

        Queue<int[]> queue = new LinkedList<>();
        queue.offer(start);
        visited[start[0]][start[1]] = true;

        int size = 0;
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            size++;

            for (int[] dir : dirs) {
                int nr = cur[0] + dir[0];
                int nc = cur[1] + dir[1];

                if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                    if (arr[nr][nc] == 1 && !visited[nr][nc]) {
                        visited[nr][nc] = true;
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
        }
        return size;
    }
}
```

```java
import java.util.Collections;
import java.util.List;

public class Solution {
    static final int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    static int n;

    public int[] solution(int n, int[][] arr) {

        boolean[][] visited = new boolean[n][n];
        this.n = n;

        List<Integer> complex = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (arr[i][j] == 1 && !visited[i][j]) {
                    visited[i][j] = true;
                    complex.add(dfs(arr, visited, new int[]{i, j}, 1));
                }
            }
        }

        Collections.sort(complex);
        int num = complex.size();
        int[] answer = new int[num + 1];
        answer[0] = num;
        for (int i = 0; i < num; i++) {
            answer[i + 1] = complex.get(i);
        }
        return answer;
    }


    private int dfs(int[][] arr, boolean[][] visited, int[] cur, int size) {

        for (int[] dir : dirs) {
            int nr = cur[0] + dir[0];
            int nc = cur[1] + dir[1];

            if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                if (arr[nr][nc] == 1 && !visited[nr][nc]) {
                    visited[nr][nc] = true;
                    size = dfs(arr, visited, new int[]{nr, nc}, size + 1);
                }
            }
        }

        return size;
    }
}
```
