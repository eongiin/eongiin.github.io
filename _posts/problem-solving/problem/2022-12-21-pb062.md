## 문제

<https://school.programmers.co.kr/learn/courses/30/lessons/49189>{:target="_blank"}

**문제 설명**  
n개의 노드가 있는 그래프가 있습니다. 각 노드는 1부터 n까지 번호가 적혀있습니다. 1번 노드에서 가장 멀리 떨어진 노드의 갯수를 구하려고 합니다. 가장 멀리 떨어진 노드란 최단경로로 이동했을 때 간선의 개수가 가장 많은 노드들을 의미합니다.

노드의 개수 n, 간선에 대한 정보가 담긴 2차원 배열 vertex가 매개변수로 주어질 때, 1번 노드로부터 가장 멀리 떨어진 노드가 몇 개인지를 return 하도록 solution 함수를 작성해주세요.

**제한사항**  
노드의 개수 n은 2 이상 20,000 이하입니다.
간선은 양방향이며 총 1개 이상 50,000개 이하의 간선이 있습니다.
vertex 배열 각 행 [a, b]는 a번 노드와 b번 노드 사이에 간선이 있다는 의미입니다.

## 나의 풀이

### 풀이1
- 인접 리스트로 그래프 구현
- 깊이별로 노드가 몇 개씩 있는지 구별하기 위해 하나의 큐에 다 집어넣지 않고 큐 배열을 만들어서 깊이별로 큐를 나눔
- 모든 노드를 다 방문했을 때 마지막 큐에 있던 노드의 개수가 답이 됨

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.Queue;

class Solution {
    ArrayList<Integer>[] graph;
    boolean[] visited;

    public int solution(int n, int[][] edge) {
        graph = new ArrayList[n + 1];
        visited = new boolean[n + 1];

        for (int i = 1; i < n + 1; i++) {
            graph[i] = new ArrayList<>();
        }

        for (int i = 0; i < edge.length; i++) {
            graph[edge[i][0]].add(edge[i][1]);
            graph[edge[i][1]].add(edge[i][0]);
        }

        return bfs(1, n);
    }

    private int bfs(int start, int n) {
        Queue<Integer>[] q = new Queue[n];
        int visit = 1;
        q[0] = new LinkedList<>();
        q[0].offer(start);
        visited[start] = true;

        for (int i = 0; i < n - 1; i++) {
            q[i + 1] = new LinkedList<>();
            for (int node : q[i]) {
                for (int adj : graph[node]) {
                    if (visited[adj]) {
                        continue;
                    }
                    visited[adj] = true;
                    visit++;
                    q[i + 1].offer(adj);
                }
            }

            if (visit == n) {
                return q[i + 1].size();
            }
        }
        return q[n - 1].size();
    }
}
```

###  풀이2

- 인접 리스트로 그래프 구현
- 큐에 노드의 번호와 그 노드까지의 거리를 같이 저장
- 모든 간선의 가중치가 1이므로 처음 도착했을 때의 값이 최솟값이고 visited 표시를 해서 중복 방문 막기
- 1에서 시작해서 다른 노드까지의 거리를 담아두는 dist 배열에 각각의 거리를 담고 마지막에 한 번 돌면서 최댓값과 그 개수를 찾음

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.Queue;

class Solution {
    ArrayList<Integer>[] graph;
    int[] dist;
    boolean[] visited;

    public int solution(int n, int[][] edge) {
        graph = new ArrayList[n + 1];
        dist = new int[n + 1];
        visited = new boolean[n + 1];

        for (int i = 1; i < n + 1; i++) {
            graph[i] = new ArrayList<>();
        }

        for (int i = 0; i < edge.length; i++) {
            graph[edge[i][0]].add(edge[i][1]);
            graph[edge[i][1]].add(edge[i][0]);
        }

        bfs(1);

        int max = 0;
        int cnt = 1;
        for (int i = 1; i < dist.length; i++) {
            if (max < dist[i]) {
                max = dist[i];
                cnt = 1;
            } else if (max == dist[i]) {
                cnt++;
            }
        }
        return cnt;
    }

    private void bfs(int start) {
        dist[start] = 0;

        Queue<int[]> q = new LinkedList<>();
        q.offer(new int[]{start, 0});
        visited[start] = true;

        while (!q.isEmpty()) {
            int[] cur = q.poll();

            for (int adj : graph[cur[0]]) {
                if (!visited[adj]) {
                    visited[adj] = true;
                    dist[adj] = cur[1] + 1;
                    q.offer(new int[]{adj, dist[adj]});
                }
            }
        }
    }
}
```
