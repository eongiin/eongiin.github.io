**문제**  
개똥벌레 한 마리가 장애물(석순과 종유석)로 가득찬 동굴에 들어갔다. 동굴의 길이는 N미터이고, 높이는 H미터이다. (N은 짝수) 첫 번째 장애물은 항상 석순이고, 그 다음에는 종유석과 석순이 번갈아가면서 등장한다.

아래 그림은 길이가 14미터이고 높이가 5미터인 동굴이다. (예제 그림)

![image](https://user-images.githubusercontent.com/90626691/203448290-9f5b5e7b-61f4-4b5e-83d1-bb8d1fce2a35.png)

이 개똥벌레는 장애물을 피하지 않는다. 자신이 지나갈 구간을 정한 다음 일직선으로 지나가면서 만나는 모든 장애물을 파괴한다.

위의 그림에서 4번째 구간으로 개똥벌레가 날아간다면 파괴해야하는 장애물의 수는 총 여덟개이다. (4번째 구간은 길이가 3인 석순과 길이가 4인 석순의 중간지점을 말한다)

![image](https://user-images.githubusercontent.com/90626691/203448305-e77cf8ef-f55d-4e2f-84da-77d001fbeddf.png)

하지만, 첫 번째 구간이나 다섯 번째 구간으로 날아간다면 개똥벌레는 장애물 일곱개만 파괴하면 된다.

동굴의 크기와 높이, 모든 장애물의 크기가 주어진다. 이때, 개똥벌레가 파괴해야하는 장애물의 최솟값과 그러한 구간이 총 몇 개 있는지 구하는 프로그램을 작성하시오.

**입력**  
첫째 줄에 N과 H가 주어진다. N은 항상 짝수이다. (2 ≤ N ≤ 200,000, 2 ≤ H ≤ 500,000)

다음 N개 줄에는 장애물의 크기가 순서대로 주어진다. 장애물의 크기는 H보다 작은 양수이다.

## 나의 풀이

### 시간초과

- 장애물을 하나씩 확인하면서 해당 위치에 걸리는 것들을 모두 +1 해주는 방식
- O(NH)이고 N<=200,000 , H<=500,000라 시간 초과가 날줄 알면서도 일단 해봤다
    - 1억 정도가 1초라고 한다
    - 보통 1초가 걸릴 때 입력의 최대 크기
        - O(N) : 약 1억
        - O(N^2) : 약 1만
        - O(N^3) : 약 500
        - O(2^N) : 약 20
        - O(N!) : 10

```java
public class Solution {
    public int[] solution(int n, int h, int[] arr) {

        int[] barrier = new int[h + 1];

        for (int i = 0; i < n; i += 2) {
            int len = arr[i];
            for (int j = 1; j <= len; j++) {
                barrier[j]++;
            }
        }

        for (int i = 1; i < n; i += 2) {
            int len = arr[i];
            for (int j = h; j > h - len; j--) {
                barrier[j]++;
            }

        }

        int min = n + 1;
        int count = 0;
        for (int i = 1; i < h + 1; i++) {
            if (min > barrier[i]) {
                min = barrier[i];
                count = 1;
            } else if (min == barrier[i]) {
                count++;
            }
        }

        return new int[]{min, count};
    }
}
```
### 누적 합

- 석순(아래)과 종유석(위)을 구분하는 것은 동일
- bottom, top 배열을 높이를 기준으로 잡고 개수 체크
- bottom[i], top[i]에 각각 높이가 h 이하인 장애물 모두 더함
    - `bottom[i]+=bottom[i-1]`
    - 나중에 특정 높이 이하인 장애물을 바로 뺄 수 있도록
- 높이 1부터 h까지 돌면서 충돌 횟수 구함
    - bottom은 그냥 i 보다 작은 장애물들의 합(bottom[[i-1])을 빼주면 됨
    - top은 거꾸로 매달려 있으니 top[h-i]를 빼줌

```java
public class Solution {
    public int[] solution(int n, int h, int[] arr) {

        int[] bottom = new int[h + 1];
        int[] top = new int[h + 1];

        for (int i = 0; i < n; i += 2) {
            bottom[arr[i]]++;
        }

        for (int i = 1; i < n; i += 2) {
            top[arr[i]]++;
        }

        for (int i = 1; i < h + 1; i++) {
            bottom[i] += bottom[i - 1];
            top[i] += top[i - 1];
        }

        int min = n;
        int count = 0;
        for (int i = 1; i < h + 1; i++) {
            int collision = 0;
            collision += bottom[h] - bottom[i - 1];
            collision += top[h] - top[h - i];

            if (min > collision) {
                min = collision;
                count = 1;
            } else if (min == collision) {
                count++;
            }
        }
        return new int[]{min, count};
    }
}
```

## 최종 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int h = Integer.parseInt(st.nextToken());

        int[] bottom = new int[h + 1];
        int[] top = new int[h + 1];

        for (int i = 0; i < n / 2; i++) {
            bottom[Integer.parseInt(br.readLine())]++;
            top[Integer.parseInt(br.readLine())]++;
        }

        for (int i = 1; i < h + 1; i++) {
            bottom[i] += bottom[i - 1];
            top[i] += top[i - 1];
        }

        int min = n;
        int count = 0;
        for (int i = 1; i < h + 1; i++) {
            int collision = 0;
            collision += bottom[h] - bottom[i - 1];
            collision += top[h] - top[h - i];

            if (min > collision) {
                min = collision;
                count = 1;
            } else if (min == collision) {
                count++;
            }
        }

        StringBuilder sb = new StringBuilder();
        sb.append(min).append(" ").append(count);
        System.out.println(sb);
    }
}
```
