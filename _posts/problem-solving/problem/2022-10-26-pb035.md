**문제**  
수열 S가 어떤 수 Sk를 기준으로 S1 < S2 < ... Sk-1 < Sk > Sk+1 > ... SN-1 > SN을 만족한다면, 그 수열을 바이토닉 수열이라고 한다.

예를 들어, {10, 20, **30**, 25, 20}과 {10, 20, 30, **40**}, {**50**, 40, 25, 10} 은 바이토닉 수열이지만,  {1, 2, 3, 2, 1, 2, 3, 2, 1}과 {10, 20, 30, 40, 20, 30} 은 바이토닉 수열이 아니다.

수열 A가 주어졌을 때, 그 수열의 부분 수열 중 바이토닉 수열이면서 가장 긴 수열의 길이를 구하는 프로그램을 작성하시오.

**입력**  
첫째 줄에 수열 A의 크기 N이 주어지고, 둘째 줄에는 수열 A를 이루고 있는 Ai가 주어진다. (1 ≤ N ≤ 1,000, 1 ≤ Ai ≤ 1,000)

**출력**  
첫째 줄에 수열 A의 부분 수열 중에서 가장 긴 바이토닉 수열의 길이를 출력한다.

**예제 입력**

```
10
1 5 2 1 4 3 4 5 2 1
```

**예제 출력**

```
7
```

## 나의 풀이
- 답이 될 수 있는 경우는 아래 세 가지
  - LIS (Longest Increasing Subsequence)
  - LDS (Longset Decreasing Subsequence)
  - 한 번 증가했다가 감소하는 부분 수열
- 한 번 증가했다가 감소하는 부분 수열은 LIS를 구한 배열, LDS를 구한 배열을 합쳐서 구할 수 있다
  - 단, 원소 1개씩 중복되어 있어서 -1 필요

```java
public class Solution {

    public int solution(int n, int[] arr) {
        int[] lis = new int[n];
        int[] lds = new int[n];

        int max = 1;

        lis[0] = lds[n - 1] = 1;

        for (int i = 1; i < n; i++) {
            lis[i] = 1;
            for (int j = 0; j < i; j++) {
                if (arr[j] < arr[i]) {
                    lis[i] = Math.max(lis[j] + 1, lis[i]);
                }
            }
        }

        for (int i = n - 2; i >= 0; i--) {
            lds[i] = 1;
            for (int j = n - 1; j > i; j--) {
                if (arr[j] < arr[i]) {
                    lds[i] = Math.max(lds[j] + 1, lds[i]);
                }
            }
        }

        for (int i = 0; i < n; i++) {
            max = Math.max(lis[i] + lds[i], max);
        }
        return max - 1;
    }
}
```

## 최종 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        int[] arr = new int[n];
        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }
        System.out.println(solution(n, arr));
    }

    private static int solution(int n, int[] arr) {
        int[] lis = new int[n];
        int[] lds = new int[n];

        int max = 1;

        lis[0] = lds[n - 1] = 1;

        calcLIS(n, arr, lis);
        calcLDS(n, arr, lds);

        for (int i = 0; i < n; i++) {
            max = Math.max(lis[i] + lds[i], max);
        }
        return max - 1;
    }

    private static void calcLDS(int n, int[] arr, int[] lds) {
        for (int i = n - 2; i >= 0; i--) {
            lds[i] = 1;
            for (int j = n - 1; j > i; j--) {
                if (arr[j] < arr[i]) {
                    lds[i] = Math.max(lds[j] + 1, lds[i]);
                }
            }
        }
    }

    private static void calcLIS(int n, int[] arr, int[] lis) {
        for (int i = 1; i < n; i++) {
            lis[i] = 1;
            for (int j = 0; j < i; j++) {
                if (arr[j] < arr[i]) {
                    lis[i] = Math.max(lis[j] + 1, lis[i]);
                }
            }
        }
    }
}
```
