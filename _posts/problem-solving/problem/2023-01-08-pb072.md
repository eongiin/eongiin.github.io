**문제**  
크기가 N인 수열 A = A1, A2, ..., AN이 있다. 수열의 각 원소 Ai에 대해서 오큰수 NGE(i)를 구하려고 한다. Ai의 오큰수는 오른쪽에 있으면서 Ai보다 큰 수 중에서 가장 왼쪽에 있는 수를 의미한다. 그러한 수가 없는 경우에 오큰수는 -1이다.

예를 들어, A = [3, 5, 2, 7]인 경우 NGE(1) = 5, NGE(2) = 7, NGE(3) = 7, NGE(4) = -1이다. A = [9, 5, 4, 8]인 경우에는 NGE(1) = -1, NGE(2) = 8, NGE(3) = 8, NGE(4) = -1이다.

**입력**  
첫째 줄에 수열 A의 크기 N (1 ≤ N ≤ 1,000,000)이 주어진다. 둘째 줄에 수열 A의 원소 A1, A2, ..., AN (1 ≤ Ai ≤ 1,000,000)이 주어진다.

**출력**  
총 N개의 수 NGE(1), NGE(2), ..., NGE(N)을 공백으로 구분해 출력한다.

**예제 입력1**

```
4
3 5 2 7
```

**예제 출력1**

```
5 7 7 -1
```

**예제 입력2**

```
4
9 5 4 8
```

**예제 출력2**

```
-1 8 8 -1
```

## 나의 풀이
- 바로 다음 수와 비교하여 다음 수가 더 크면 현재 값을 다음 값으로 갱신
  - 크지 않으면 해당 idx 값을 stack에 넣어둠
- 다음 수가 더 컸을 때, stack이 비어있지 않다면 stack에서 peek을 확인하여 그 값보다도 큰지 확인
  - 크다면 값 갱신하고 작을 때까지 확인
  - 작다면 넘어감
    - stack에는 작은 값이 나중에 들어갈 거니까 peek 값이 가장 작은 값이므로 peek보다 작다면 그전 값들은 확인할 필요 없음
      - stack에 실제로 들어가는 값은 인덱스 값이지만, 해당 인덱스의 데이터 값이 작다는 의미
- stack에 남아있는 값은 더 큰 값이 없는 값들의 idx
- 마지막 값은 다음 값이 없으므로 무조건 -1

```java
import java.util.Stack;

public class Solution {
    public int[] solution(int[] arr) {
        Stack<Integer> stack = new Stack<>();

        for (int idx = 1; idx < arr.length; idx++) {
            if (arr[idx - 1] < arr[idx]) {
                arr[idx - 1] = arr[idx];
                while (!stack.isEmpty() && arr[stack.peek()] < arr[idx]) {
                    arr[stack.pop()] = arr[idx];
                }
            } else {
                stack.push(idx - 1);
            }
        }

        while (!stack.isEmpty()) {
            arr[stack.pop()] = -1;
        }

        arr[arr.length - 1] = -1;
        return arr;
    }
}
```
### 개선

- stack에 직접 넣고 빼지 않고 그냥 배열로 만들어서 top위치를 계산하여 stack처럼 쓰면 더 빠르게 계산 가능

```java
public class Solution {
    public int[] solution(int[] arr) {
        int[] stack = new int[arr.length];
        int top = -1;

        for (int idx = 1; idx < arr.length; idx++) {
            if (arr[idx - 1] < arr[idx]) {
                arr[idx - 1] = arr[idx];
                while (top != -1 && arr[stack[top]] < arr[idx]) {
                    arr[stack[top--]] = arr[idx];
                }
            } else {
                stack[++top] = idx - 1;
            }
        }

        while (top != -1) {
            arr[stack[top--]] = -1;
        }

        arr[arr.length - 1] = -1;
        return arr;
    }
}
```

## 최종 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        int[] arr = new int[n];
        int[] stack = new int[arr.length];
        int top = -1;

        StringTokenizer st = new StringTokenizer(br.readLine());
        arr[0] = Integer.parseInt(st.nextToken());

        for (int idx = 1; idx < n; idx++) {
            arr[idx] = Integer.parseInt(st.nextToken());

            if (arr[idx - 1] < arr[idx]) {
                arr[idx - 1] = arr[idx];
                while (top != -1 && arr[stack[top]] < arr[idx]) {
                    arr[stack[top--]] = arr[idx];
                }
            } else {
                stack[++top] = idx - 1;
            }
        }

        while (top != -1) {
            arr[stack[top--]] = -1;
        }

        arr[arr.length - 1] = -1;
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            sb.append(arr[i]).append(" ");
        }
        System.out.println(sb);
    }
}
```
