## 문제

<https://school.programmers.co.kr/learn/courses/30/lessons/43163>{:target="_blank"}

**문제 설명**  
두 개의 단어 begin, target과 단어의 집합 words가 있습니다. 아래와 같은 규칙을 이용하여 begin에서 target으로 변환하는 가장 짧은 변환 과정을 찾으려고 합니다.

1. 한 번에 한 개의 알파벳만 바꿀 수 있습니다.
2. words에 있는 단어로만 변환할 수 있습니다.

예를 들어 begin이 "hit", target가 "cog", words가 ["hot","dot","dog","lot","log","cog"]라면 "hit" -> "hot" -> "dot" -> "dog" -> "cog"와 같이 4단계를 거쳐 변환할 수 있습니다.

두 개의 단어 begin, target과 단어의 집합 words가 매개변수로 주어질 때, 최소 몇 단계의 과정을 거쳐 begin을 target으로 변환할 수 있는지 return 하도록 solution 함수를 작성해주세요.

**제한사항**  
- 각 단어는 알파벳 소문자로만 이루어져 있습니다.
- 각 단어의 길이는 3 이상 10 이하이며 모든 단어의 길이는 같습니다.
- words에는 3개 이상 50개 이하의 단어가 있으며 중복되는 단어는 없습니다.
- begin과 target은 같지 않습니다.
- 변환할 수 없는 경우에는 0를 return 합니다.

## 나의 풀이

### 완전 탐색
- 일단 Set에 단어들을 넣어 넣고 앞으로 만들 단어가 포함되어 있는지 확인
- 몇 번 바꾼 건지 함께 체크하기 위해 단어와 cnt를 갖는 Word 클래스를 만듦
- 단어를 한자리씩 바꾸면서 그게 set에 있으면  queue에 집어넣음
    - 현재 문자를 기준으로 a 쪽으로 내려가고 z 쪽으로 올라가면서 모두 확인
- 프로그래머스의 테스트 케이스가 별로 없어 통과는 했지만 시간이 너무 느리다

```java
import java.util.*;

public class Solution {

    public int solution(String begin, String target, String[] words) {
        int len = begin.length();

        Set<String> set = new HashSet<>();
        Collections.addAll(set, words);

        if (!set.contains(target)) {
            return 0;
        }

        Queue<Word> q = new LinkedList<>();
        q.offer(new Word(begin, 0));

        while (!q.isEmpty()) {
            Word cur = q.poll();
            String word = cur.word;
            int cnt = cur.change;

            if (word.equals(target)) {
                return cnt;
            }

            for (int i = 0; i < len; i++) {
                char alpha = word.charAt(i);
                char tmp = alpha;
                while (tmp > 'a') {
                    String next = word.substring(0, i) + (char) (tmp - 1) + word.substring(i + 1);
                    if (set.contains(next)) {
                        q.offer(new Word(next, cnt + 1));
                    }
                    tmp--;
                }

                tmp = alpha;

                while (tmp < 'z') {
                    String next = word.substring(0, i) + (char) (tmp + 1) + word.substring(i + 1);
                    if (set.contains(next)) {
                        q.offer(new Word(next, cnt + 1));
                    }
                    tmp++;
                }
            }
        }

        return 0;
    }

    class Word {
        String word;
        int change;

        public Word(String word, int change) {
            this.word = word;
            this.change = change;
        }
    }
}
```
### 개선
- words 배열을 돌면서 다음 단어 선택하다가 target 발견하면 그때의 카운트 리턴
- 다음 단어 선택할 때 방문한 적이 없는 단어여야 하고 현재 단어에서 한 글자만 바꿔서 그 단어가 될 수 있는지 확인해야 함
    - isNext 함수를 만들어 단어의 문자들을 하나씩 확인해 보며 딱 한 개만 다를 때만 true 리턴

```java
import java.util.LinkedList;
import java.util.Queue;

public class Solution {

    public int solution(String begin, String target, String[] words) {

        int n = words.length;
        boolean[] visited = new boolean[n];

        Queue<Word> q = new LinkedList<>();
        q.offer(new Word(begin, 0));

        while (!q.isEmpty()) {
            Word cur = q.poll();
            if (cur.word.equals(target)) {
                return cur.change;
            }

            for (int i = 0; i < n; i++) {
                if (!visited[i] && isNext(cur.word, words[i])) {
                    visited[i] = true;
                    q.offer(new Word(words[i], cur.change + 1));
                }
            }
        }
        return 0;
    }

    private boolean isNext(String word, String next) {
        boolean differ = false;
        for (int i = 0; i < word.length(); i++) {
            if (word.charAt(i) != next.charAt(i)) {
                if (differ) return false;
                differ = true;
            }
        }
        return differ;
    }

    class Word {
        String word;
        int change;

        public Word(String word, int change) {
            this.word = word;
            this.change = change;
        }
    }
}
```
