## 문제

<https://school.programmers.co.kr/learn/courses/30/lessons/42898>{:target="_blank"}

**문제 설명**  
계속되는 폭우로 일부 지역이 물에 잠겼습니다. 물에 잠기지 않은 지역을 통해 학교를 가려고 합니다. 집에서 학교까지 가는 길은 m x n 크기의 격자모양으로 나타낼 수 있습니다.

아래 그림은 m = 4, n = 3 인 경우입니다.

![image](https://user-images.githubusercontent.com/90626691/209279109-070e0afa-4ef5-4d57-bd5c-7a6b87014038.png)

가장 왼쪽 위, 즉 집이 있는 곳의 좌표는 (1, 1)로 나타내고 가장 오른쪽 아래, 즉 학교가 있는 곳의 좌표는 (m, n)으로 나타냅니다.

격자의 크기 m, n과 물이 잠긴 지역의 좌표를 담은 2차원 배열 puddles이 매개변수로 주어집니다. 오른쪽과 아래쪽으로만 움직여 집에서 학교까지 갈 수 있는 최단경로의 개수를 1,000,000,007로 나눈 나머지를 return 하도록 solution 함수를 작성해주세요.

**제한사항**  
- 격자의 크기 m, n은 1 이상 100 이하인 자연수입니다.
    - m과 n이 모두 1인 경우는 입력으로 주어지지 않습니다.
- 물에 잠긴 지역은 0개 이상 10개 이하입니다.
- 집과 학교가 물에 잠긴 경우는 입력으로 주어지지 않습니다.

## 나의 풀이

- 처음에 단순하게 BFS로 풀다가 시간 초과
- 이 문제는 오른쪽, 아래쪽으로만 갈 수 있다는 조건이 있었고 그래서 DP로 풀 수 있다
    - `dp[i][j]+=dp[i][j-1]+dp[i-1][j]`
    - 단, 왼쪽이나 위쪽이 존재해야 하고 물웅덩이면 안 됨
- 먼저 왼쪽 혹은 위쪽이 없는 첫 번째 행이나 첫 번째 열을 따로 계산해 줌
    - 1로 전부 채우다가 가는 길에 물웅덩이를 만나면 그다음으로 진행할 수 없으므로 break
- 이중 포문으로 각 자리를 확인하면서 물웅덩이면 패스하고, 왼쪽과 위쪽도 물웅덩이가 아닌 경우에 해당 자릿값을 더함
    - (1,1)부터 검사하므로 왼쪽, 위쪽은 무조건 존재하고 그곳이 물웅덩이가 아닌지만 확인하면 됨
- 주의해야 하는 포인트
    - m*n이라길래 행이 m인 줄 알았는데 그냥 순서만 바뀐것
    - 장애물 좌표도 (행, 열)이 아닌 (열, 행)으로 들어옴
    - 큰 수로 나누는 작업은 DP 배열에 무엇을 더할 때마다 해줘야 범위 벗어나는 걸 방지할 수 있음

```java
public class Solution {
    static final int BIG = 1_000_000_007;

    public int solution(int m, int n, int[][] puddles) {
        int dp[][] = new int[n][m];

        for (int[] puddle : puddles) {
            dp[puddle[1] - 1][puddle[0] - 1] = -1;
        }

        for (int i = 0; i < m; i++) {
            if (dp[0][i] == -1) {
                break;
            }
            dp[0][i] = 1;
        }
        for (int i = 0; i < n; i++) {
            if (dp[i][0] == -1) {
                break;
            }
            dp[i][0] = 1;
        }


        for (int i = 1; i < n; i++) {
            for (int j = 1; j < m; j++) {
                if (dp[i][j] == -1) {
                    continue;
                }
                int top = dp[i - 1][j];
                int left = dp[i][j - 1];
                if (top != -1) {
                    dp[i][j] = (dp[i][j] + top) % BIG;
                }
                if (left != -1) {
                    dp[i][j] = (dp[i][j] + left) % BIG;
                }
            }
        }

        return dp[n - 1][m - 1];
    }
}
```

### 다른 풀이

- 첫 번째 행과 첫 번째 열을 따로 계산하지 않고 시작점만 1로 설정해둔 채 나중에 검사
    - 첫 번째 행인 경우(i=0)는 위쪽 값 건너뜀
    - 첫 번째 열인 경우(j=0)는 왼쪽 값 건너뜀
- 물웅덩이를 만나면 0으로 바꿔서 나중에 물웅덩이인 경우를 따로 제외하지 않아도 되도록 처리

```java
public class Solution {
    static final int BIG = 1_000_000_007;

    public int solution(int m, int n, int[][] puddles) {
        int dp[][] = new int[n][m];

        for (int[] puddle : puddles) {
            dp[puddle[1] - 1][puddle[0] - 1] = -1;
        }

        dp[0][0] = 1;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (dp[i][j] == -1) {
                    dp[i][j] = 0;
                    continue;
                }

                if (i != 0) dp[i][j] = (dp[i][j] + dp[i - 1][j]) % BIG;
                if (j != 0) dp[i][j] = (dp[i][j] + dp[i][j - 1]) % BIG;
            }
        }

        return dp[n - 1][m - 1];
    }
}
```
