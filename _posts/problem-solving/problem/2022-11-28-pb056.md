**문제**  
미세먼지를 제거하기 위해 구사과는 공기청정기를 설치하려고 한다. 공기청정기의 성능을 테스트하기 위해 구사과는 집을 크기가 R×C인 격자판으로 나타냈고, 1×1 크기의 칸으로 나눴다. 구사과는 뛰어난 코딩 실력을 이용해 각 칸 (r, c)에 있는 미세먼지의 양을 실시간으로 모니터링하는 시스템을 개발했다. (r, c)는 r행 c열을 의미한다.

![image](https://user-images.githubusercontent.com/90626691/204201666-bbbbe69f-d1ff-4b46-812d-b80cc132e182.png)


공기청정기는 항상 1번 열에 설치되어 있고, 크기는 두 행을 차지한다. 공기청정기가 설치되어 있지 않은 칸에는 미세먼지가 있고, (r, c)에 있는 미세먼지의 양은 Ar,c이다.

1초 동안 아래 적힌 일이 순서대로 일어난다.

1. 미세먼지가 확산된다. 확산은 미세먼지가 있는 모든 칸에서 동시에 일어난다.
- (r, c)에 있는 미세먼지는 인접한 네 방향으로 확산된다.
- 인접한 방향에 공기청정기가 있거나, 칸이 없으면 그 방향으로는 확산이 일어나지 않는다.
- 확산되는 양은 Ar,c/5이고 소수점은 버린다.
- (r, c)에 남은 미세먼지의 양은 Ar,c - (Ar,c/5)×(확산된 방향의 개수) 이다.
2. 공기청정기가 작동한다.
- 공기청정기에서는 바람이 나온다.
- 위쪽 공기청정기의 바람은 반시계방향으로 순환하고, 아래쪽 공기청정기의 바람은 시계방향으로 순환한다.
- 바람이 불면 미세먼지가 바람의 방향대로 모두 한 칸씩 이동한다.
- 공기청정기에서 부는 바람은 미세먼지가 없는 바람이고, 공기청정기로 들어간 미세먼지는 모두 정화된다.

다음은 확산의 예시이다.

![image](https://user-images.githubusercontent.com/90626691/204217206-eaa45cd9-1bb0-4670-b588-f7397c9f09b6.png)

왼쪽과 오른쪽에 칸이 없기 때문에, 두 방향으로만 확산이 일어났다.

![image](https://user-images.githubusercontent.com/90626691/204201777-34e34726-36d0-442c-9c27-b69894f96488.png)

## 나의 풀이

신경 써야 하는 부분
- 내가 있는 위치에서 확산되는 양은 기존에 있던 양에서 계산해야 함
    - 다른 곳으로부터 확산된 것이 포함되면 x
    - 이것을 해결하기 위해 원본 배열(room)과, 확산되는 양의 배열(plus)을 따로 두고 전체를 다 계산한 다음에 원본 배열에 더했다
    - plus 배열은 1초마다  모든 값을 0으로 초기화해 주어야 한다
- 먼지 이동
    - → 이렇게 이동한다고 치면 오른쪽에서부터 하나씩 왼쪽으로 이동하면서 왼쪽의 값을 오른쪽으로 넣어주면 된다
        - `for (int c = m - 1; c > 1; c--) {room[top][c] = room[top][c - 1];}`
    - 청소기에서 나오는 값은 0이고 마지막으로 청소기로 들어가는 값은 사라지므로 어느 방향을 먼저 계산할 것인지도 중요
        - 청소기 바람이 시계방향으로 나온다고 치면 청소기로 부터 반시계방향 계산해주면 된다 (↑←↓→)

```java
public class Solution {

    static final int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    int n, m;
    int[][] room;
    int[][] plus;

    public int solution(int r, int c, int t, int[][] room) {
        n = r;
        m = c;
        this.room = room;

        int[] vaccum = new int[2];

        for (int i = 0; i < r; i++) {
            for (int j = 0; j < c; j++) {
                if (room[i][j] == -1) {
                    if (vaccum[0] == 0) {
                        vaccum[0] = i;
                    } else {
                        vaccum[1] = i;
                    }
                }
            }
        }

        for (int i = 0; i < t; i++) {
            spread();
            wind(vaccum);
        }

        return calcDust();
    }

    private void spread() {
        plus = new int[n][m];
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < m; c++) {
                if (room[r][c] < 5) {
                    continue;
                }

                int size = room[r][c] / 5;
                int cnt = 0;
                for (int[] dir : dirs) {
                    int nr = r + dir[0];
                    int nc = c + dir[1];

                    if (!isValid(nr, nc)) {
                        continue;
                    }

                    plus[nr][nc] += size;
                    cnt++;
                }
                room[r][c] -= size * cnt;
            }
        }

        for (int r = 0; r < n; r++) {
            for (int c = 0; c < m; c++) {
                if (plus[r][c] != 0) {
                    room[r][c] += plus[r][c];
                }
            }
        }
    }

    private boolean isValid(int r, int c) {
        if (r < 0 || r >= n || c < 0 || c >= m) {
            return false;
        }

        if (room[r][c] == -1) {
            return false;
        }

        return true;
    }

    private void wind(int[] vaccum) {
        int top = vaccum[0];
        int down = vaccum[1];

        for (int r = top - 1; r > 0; r--) {
            room[r][0] = room[r - 1][0];
        }

        for (int c = 0; c < m - 1; c++) {
            room[0][c] = room[0][c + 1];
        }

        for (int r = 0; r < top; r++) {
            room[r][m - 1] = room[r + 1][m - 1];
        }

        for (int c = m - 1; c > 1; c--) {
            room[top][c] = room[top][c - 1];
        }

        room[top][1] = 0;

        for (int r = down + 1; r < n - 1; r++) {
            room[r][0] = room[r + 1][0];
        }

        for (int c = 0; c < m - 1; c++) {
            room[n - 1][c] = room[n - 1][c + 1];
        }

        for (int r = n - 1; r > down; r--) {
            room[r][m - 1] = room[r - 1][m - 1];
        }

        for (int c = m - 1; c > 1; c--) {
            room[down][c] = room[down][c - 1];
        }
        room[down][1] = 0;
    }

    private int calcDust() {
        int sum = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (room[i][j] == 0 || room[i][j] == -1) {
                    continue;
                }
                sum += room[i][j];
            }
        }
        return sum;
    }
}
```

## 최종 코드

- plus배열을 매번 new 연산을 이용해 초기화하는 부분에서 시간이 좀 걸리는 것 같아서 그렇게 배열을 나누지 말고 원본 배열(origin)과, 바로 더한 배열(room)로 나누고 원본 배열에 1초가 지난 뒤 바로 더한 배열을  복사하는 식으로 바꿔봤다
    - 확산되는 양 구할 때는 원본 배열 이용
    - 복사를 빠르게 하기 위해 아래와 같이 복사
    ```java
    for (int i = 0; i < n; i++) {
        System.arraycopy(room[i], 0, origin[i], 0, m);
    }
    ```
- `System.arraycopy(src, srcPos, dest, destPos, length)`

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    static final int[][] dirs = { {-1, 0}, {1, 0}, {0, -1}, {0, 1} };
    static int n, m;
    static int[][] room;
    static int[][] origin;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());
        room = new int[n][m];
        int t = Integer.parseInt(st.nextToken());

        int[] vaccum = new int[2];

        for (int i = 0; i < n; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < m; j++) {
                int cur = Integer.parseInt(st.nextToken());
                room[i][j] = cur;
                if (cur == -1) {
                    if (vaccum[0] == 0) {
                        vaccum[0] = i;
                    } else {
                        vaccum[1] = i;
                    }
                }
            }
        }

        origin = new int[n][m];

        for (int i = 0; i < t; i++) {
            spread();
            wind(vaccum);
        }

        System.out.println(calcDust());
    }

    private static void spread() {

        for (int i = 0; i < n; i++) {
            System.arraycopy(room[i], 0, origin[i], 0, m);
        }

        for (int r = 0; r < n; r++) {
            for (int c = 0; c < m; c++) {
                if (room[r][c] < 5) {
                    continue;
                }

                int size = origin[r][c] / 5;
                int cnt = 0;
                for (int[] dir : dirs) {
                    int nr = r + dir[0];
                    int nc = c + dir[1];

                    if (!isValid(nr, nc)) {
                        continue;
                    }

                    room[nr][nc] += size;
                    cnt++;
                }
                room[r][c] -= size * cnt;
            }
        }
    }

    private static boolean isValid(int r, int c) {
        if (r < 0 || r >= n || c < 0 || c >= m) {
            return false;
        }

        return room[r][c] != -1;
    }

    private static void wind(int[] vaccum) {
        int top = vaccum[0];
        int down = vaccum[1];

        for (int r = top - 1; r > 0; r--) {
            room[r][0] = room[r - 1][0];
        }

        System.arraycopy(room[0], 1, room[0], 0, m - 1);

        for (int r = 0; r < top; r++) {
            room[r][m - 1] = room[r + 1][m - 1];
        }


        System.arraycopy(room[top], 1, room[top], 2, m - 1 - 1);

        room[top][1] = 0;

        for (int r = down + 1; r < n - 1; r++) {
            room[r][0] = room[r + 1][0];
        }

        System.arraycopy(room[n - 1], 1, room[n - 1], 0, m - 1);

        for (int r = n - 1; r > down; r--) {
            room[r][m - 1] = room[r - 1][m - 1];
        }

        System.arraycopy(room[down], 1, room[down], 2, m - 1 - 1);
        room[down][1] = 0;
    }

    private static int calcDust() {
        int sum = 2;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                sum += room[i][j];
            }
        }
        return sum;
    }
}
```
