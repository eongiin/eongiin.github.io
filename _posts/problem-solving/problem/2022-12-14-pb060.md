## 문제

<https://school.programmers.co.kr/learn/courses/30/lessons/42895>{:target="_blank"}

**문제 설명**  
아래와 같이 5와 사칙연산만으로 12를 표현할 수 있습니다.

12 = 5 + 5 + (5 / 5) + (5 / 5)  
12 = 55 / 5 + 5 / 5  
12 = (55 + 5) / 5  

5를 사용한 횟수는 각각 6,5,4 입니다. 그리고 이중 가장 작은 경우는 4입니다.
이처럼 숫자 N과 number가 주어질 때, N과 사칙연산만 사용해서 표현 할 수 있는 방법 중 N 사용횟수의 최솟값을 return 하도록 solution 함수를 작성하세요.

**제한사항**  
- N은 1 이상 9 이하입니다.
- number는 1 이상 32,000 이하입니다.
- 수식에는 괄호와 사칙연산만 가능하며 나누기 연산에서 나머지는 무시합니다.
- 최솟값이 8보다 크면 -1을 return 합니다.

## 나의 풀이

- `Set<Integer>[] dp = new HashSet[9];`
    - dp[i]는 N을 i번 사용해서 만들 수 있는 수의 집합
    - 8번까지만 계산하고 그 이상이 필요하면 -1을 리턴하면 되므로 크기를 9로 설정
- 첫 번째 for : N을 1~8개 사용하는 경우 각각 확인
    - 먼저 i번째 집합에 i개를 연달아서 쓴 경우를 집어넣음(ex i:4, N:5 ->5555)
- 두 번째 for : N을 i개 쓴다고 했을 때, 피연산자 두 개가 각각 몇 개씩 쓸 것인지 결정
    - 피연산자가 1개인 경우(한쪽이 0개 쓰는 경우)는 처음에 고려했으므로 최소 개수는 1부터 시작
    - 피연산자 1 - j
    - 피연산자 2 - other (i-j)
- 세 번째 for : 피연산자 1(j)의 개수에 해당하는 수의 집합에서 하나씩 
- 네 번째 for : 피연산자 2(other)의 개수에 해당하는 수의 집합에서 하나씩
- 계산할 때 피연산자 2가 0 이되는 경우는 넘김
- 첫 번째 for문 돌면서 각 단계를 확인할 때 해당 집합에 number와 일치하는 것이 있으면 바로 리턴

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int solution(int N, int number) {
        Set<Integer>[] dp = new HashSet[9];
        int num = 0;
        for (int i = 1; i < dp.length; i++) {
            dp[i] = new HashSet<>();
            num = num * 10 + N;
            dp[i].add(num);
            for (int j = 1; j < i; j++) {
                int other = i - j;
                for (Integer x : dp[j]) {
                    for (Integer y : dp[other]) {
                        if (y == 0) {
                            continue;
                        }
                        dp[i].add(x + y);
                        dp[i].add(x - y);
                        dp[i].add(x * y);
                        dp[i].add(x / y);
                    }
                }
            }

            if (dp[i].contains(number)) {
                return i;
            }
        }
        return -1;
    }
}
```
