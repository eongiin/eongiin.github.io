**문제**  
월드피자 원주 지점에서 N개의 피자 반죽을 오븐에 넣고 구우려고 한다. 그런데, 월드피자에서 만드는 피자 반죽은 지름이 제각각이다. 그런가하면, 월드피자에서 사용하는 오븐의 모양도 몹시 오묘하다. 이 오븐은 깊은 관처럼 생겼는데, 관의 지름이 깊이에 따라 들쭉날쭉하게 변한다. 아래는 오븐의 단면 예시이다.

![image](https://user-images.githubusercontent.com/90626691/167841145-63d1827e-5778-4500-b216-a8d9e8d00094.png){:.align-center}

피자 반죽은 완성되는 순서대로 오븐에 들어간다. 이렇게 N개의 피자가 오븐에 모두 들어가고 나면, 맨 위의 피자가 얼마나 깊이 들어가 있는지가 궁금하다. 이를 알아내는 프로그램을 작성하시오.

**입력**  
첫째 줄에 오븐의 깊이 D와 피자 반죽의 개수 N이 공백을 사이에 두고 주어진다. (1 ≤ D, N ≤ 300,000) 둘째 줄에는 오븐의 최상단부터 시작하여 깊이에 따른 오븐의 지름이 차례대로 주어진다. 셋째 줄에는 피자 반죽이 완성되는 순서대로, 그 각각의 지름이 주어진다. 오븐의 지름이나 피자 반죽의 지름은 10억 이하의 자연수이다.

**출력**  
첫째 줄에, 마지막 피자 반죽의 위치를 출력한다. 오븐의 최상단이 1이고, 최하단 가장 깊은 곳이 D이 된다. 만약 피자가 모두 오븐에 들어가지 않는다면, 0을 출력한다.

**예제 입력**
```
7 3
5 6 4 3 6 2 3
3 2 5
```

**예제 출력**
```
2
```

## 나의 풀이

- 처음에 문제를 제대로 이해하지 않고 Stack으로 풀다가 현재 반죽 크기보다 오븐의 크기가 작으면 더 밑으로 내려가지 못한다는 것을 깨닫고.. 다시 고민했다  
- 이진 탐색 문제를 풀어보려고 선택한 거라 이진 탐색으로 풀어야 할 것 같은데 여기서 왜 이진 탐색이 나오는지 잘 모르겠다.. 이진 탐색은 정렬된 데이터에서 할 수 있는 것이 아닌가? 여기 데이터는 뒤죽박죽인데.. 정렬할 수도 없고..  하다가 든 생각!  
- 어떤 층까지 내려갈 수 있다면 그 층은 위의 층들의 최솟값을 거쳐야만 갈 수 있는 것이니까 <b>그 층을 위의 층들의 최솟값으로 해주면 되겠다</b>는 생각이 들었다  
그렇게 되면 가장 아래가 가장 작은 값을 가질 것이고 그 위의 층들은 그것보다 같거나 큰 값을 가지게 되므로 <b>자동으로 정렬도 된다!  →  이진 탐색 가능</b>
- 피자 배열 크기만큼 for 문을 돌면서 정렬된 데이터를 이용하여 이진 탐색으로 어디에 들어갈지 찾아주고 해당 idx를 반환하여 다음에는 right=idx-1로 하여 다시 이진 탐색 진행  
- 내림차순 정렬이니 반대로 되지 않게 주의
- 중복 값이 여럿 있을 수 있으니 최대한 오른쪽(아래쪽)으로 이동

```java
public class Solution {

    public int solution(int d, int n, long[] ovenSize, long[] pizzaSize) {

        long min = Long.MAX_VALUE;
        for (int i = 0; i < d; i++) {
            if (ovenSize[i] < min) {
                min = ovenSize[i];
            } else {
                ovenSize[i] = min;
            }
        }
        // 정렬 완료 (내림차순)

        int rIdx = d;
        for (int i = 0; i < n; i++) {
            if (rIdx <= 0) {
                return 0;
            }
            rIdx = binarySearch(ovenSize, pizzaSize[i], rIdx - 1);
        }
        return rIdx + 1;
    }

    public int binarySearch(long[] ovenSize, long target, int rIdx) {
        int left = 0;
        int right = rIdx;

        while (left <= right) {
            int mid = (left + right) / 2;
            long cur = ovenSize[mid];

            if (cur >= target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return right;
    }
}
```

## 최종 코드

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        StringTokenizer st = new StringTokenizer(br.readLine(), " ");
        int d = Integer.parseInt(st.nextToken());
        int n = Integer.parseInt(st.nextToken());

        long[] ovenSize = new long[d];
        st = new StringTokenizer(br.readLine(), " ");
        for (int i = 0; i < d; i++) {
            ovenSize[i] = Integer.parseInt(st.nextToken());
        }

        long[] pizzaSize = new long[n];
        st = new StringTokenizer(br.readLine(), " ");
        for (int i = 0; i < n; i++) {
            pizzaSize[i] = Integer.parseInt(st.nextToken());
        }

        long min = Long.MAX_VALUE;
        for (int i = 0; i < d; i++) {
            if (ovenSize[i] < min) {
                min = ovenSize[i];
            } else {
                ovenSize[i] = min;
            }
        }

        int rIdx = d;
        for (int i = 0; i < n; i++) {
            if (rIdx <= 0) {
                System.out.println(0);
                System.exit(0);
            }
            rIdx = binarySearch(ovenSize, pizzaSize[i], rIdx - 1);
        }

        System.out.println(rIdx + 1);
    }

    public static int binarySearch(long[] ovenSize, long target, int rIdx) {
        int left = 0;
        int right = rIdx;

        while (left <= right) {
            int mid = (left + right) / 2;
            long cur = ovenSize[mid];

            if (cur >= target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return right;
    }
}
```
