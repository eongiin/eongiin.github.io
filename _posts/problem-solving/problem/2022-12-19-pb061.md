## 문제

<https://school.programmers.co.kr/learn/courses/30/lessons/43238>{:target="_blank"}

**문제 설명**  
n명이 입국심사를 위해 줄을 서서 기다리고 있습니다. 각 입국심사대에 있는 심사관마다 심사하는데 걸리는 시간은 다릅니다.

처음에 모든 심사대는 비어있습니다. 한 심사대에서는 동시에 한 명만 심사를 할 수 있습니다. 가장 앞에 서 있는 사람은 비어 있는 심사대로 가서 심사를 받을 수 있습니다. 하지만 더 빨리 끝나는 심사대가 있으면 기다렸다가 그곳으로 가서 심사를 받을 수도 있습니다.

모든 사람이 심사를 받는데 걸리는 시간을 최소로 하고 싶습니다.

입국심사를 기다리는 사람 수 n, 각 심사관이 한 명을 심사하는데 걸리는 시간이 담긴 배열 times가 매개변수로 주어질 때, 모든 사람이 심사를 받는데 걸리는 시간의 최솟값을 return 하도록 solution 함수를 작성해주세요.

**제한사항**  
- 입국심사를 기다리는 사람은 1명 이상 1,000,000,000명 이하입니다.
- 각 심사관이 한 명을 심사하는데 걸리는 시간은 1분 이상 1,000,000,000분 이하입니다.
- 심사관은 1명 이상 100,000명 이하입니다.

## 나의 풀이

- 이분 탐색 문제라는 것을 알아서 더 쉽게 풀 수 있었지만 범위를 충분히 고려하지 못해 자꾸 틀렸던 문제
- 전체 시간이 최소가 되는 경우를 구해야 하는데, 특정 시간에 각 심사관이 해결할 수 있는 최대(특정 시간/심사 시간)를 구해서 다 더하면 그 시간에 심사할 수 있는 최대 개수가 나오므로, 이 개수가 n보다 크거나 같으면 됨
    - 최솟값을 구해야 하므로 이 조건에 통과되면 시간을 계속 줄여나가면서 조건 통과하는지 확인(isPossible)
- 전체 시간을 기준으로 이분 탐색
    - 최솟값(left)은 가장 심사 시간이 적은 심사관의 한 타임,   
    최댓값(right)은 가장 심사 시간이 긴 심사관의 한 타임 *  (n / times.length + 1)로 설정함(모든 심사관에게 균일하게 심사를 받는 경우, 딱 안 떨어지는 경우를 대비한 +1) 
    - 최솟값 최댓값은 적당히 정해주면 되는데 최댓값의 경우 너무 크게 하면 범위 벗어남 주의
- cnt 구할 때 이 값도 int 범위를 넘어갈 수 있어서 long으로 처리해야 함

```java
import java.util.Arrays;

public class Solution {
    public long solution(int n, int[] times) {
        Arrays.sort(times);
        return binarySearch(n, times);
    }
    private long binarySearch(int n, int[] times) {
        long left = times[0];
        long right = (long) times[times.length - 1] * (n / times.length + 1);

        while (left <= right) {
            long mid = left + (right - left) / 2;

            if (isPossible(n, mid, times)) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    private boolean isPossible(int n, long limit, int[] times) {
        long cnt = 0;
        for (int time : times) {
            cnt += limit / time;
        }
        return cnt >= n;
    }
}
```
